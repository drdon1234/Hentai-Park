## English

### Fixes
- Fixed blank subframes being blocked in online games and web playback, preventing some short-link verification flows from completing.
- Fixed the default game list failing after signing in to Cycg. Browsing now defaults to popular games, with the latest list and pagination retained.
- Improved browser verification so an input sent before a challenge is ready does not permanently stop further verification attempts.
