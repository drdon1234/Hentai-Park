## 中文

### 新功能
- 新增 Windows 桌面客户端，提供 x64 与 ARM64 安装包和便携包。
- 站内搜索和栏目可分别记住筛选条件，并按日期范围查看作品。

### 改进
- Android 站内多语言搜索移入搜索栏，Web 结果页可直接调整筛选并保留关键词。
- 改进移动端阅读和播放时的系统栏、屏幕方向恢复，以及 iOS 分享体验。

### 修复
- Android 下载多选可通过返回键退出，切换标签时清除勾选，并减少后台下载进度引起的界面刷新。
- 修复移动端书库写入失败后影响后续保存，以及后台下载中断影响其他任务的问题。

### 插件更新
- E-Hentai 0.0.22：可拖动最低评分滑块，精确到 0.01 星。
- itch.io 0.0.4、鲲 Galgame 0.0.11：itch.io 搜索支持作者和游戏类型筛选，鲲 Galgame 搜索支持资源平台和语言筛选。
- 黄豆短剧 0.0.13、91短剧 0.0.13、黄果短剧 0.0.16：改进站点连接。

## English

### New
- Add a Windows desktop client with installers and portable packages for x64 and ARM64.
- Remember filters separately for each site search and feed, and filter works by date range.

### Improvements
- Move multilingual search into the Android site search bar and let Web users adjust filters directly on the results page while keeping their query.
- Improve system bars and orientation restoration during mobile reading and playback, along with sharing on iOS.

### Fixes
- Let Android users exit download selection with Back, clear selections when switching tabs, and reduce screen updates caused by background downloads.
- Fix library write failures blocking later saves and interrupted background downloads affecting other tasks on mobile.

### Plugin updates
- E-Hentai 0.0.22: Set the minimum rating with a slider in increments of 0.01 stars.
- itch.io 0.0.4 and KUN Galgame 0.0.11: Filter itch.io search results by author and genre, and KUN Galgame search results by resource platform and language.
- Huangdou Drama 0.0.13, 91 Drama 0.0.13 and Huangguo Drama 0.0.16: Improve site connectivity.
