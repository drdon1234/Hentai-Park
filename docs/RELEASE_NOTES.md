## 中文

### 新功能
- JAV 作品显示原站标注的字幕和版本差异，可切换原站提供的其他版本，或按番号在站内、跨站查找；各版本的收藏、进度与下载独立保存。
- FANZA 排行榜新增简体中文标签词包，筛选选项支持翻译和原文切换。

### 改进
- 调整视频进度条、时间和屏幕控制按钮的位置，改善窄屏与大字体布局，进度条随播放控制层共同显示或隐藏。
- 启动失败时可重试并复制诊断信息；更改保存失败时持续提示并自动重试。
- 下载记录恢复失败时保留原始记录和本地文件，支持重试恢复或仅移除损坏记录。

### 修复
- 修复删除下载失败后任务丢失、章节移除无法继续重试的问题。
- 修复清除站点登录状态后，较早发出的请求重新写入旧登录信息的问题。
- 修复应用锁定后键盘仍可操作隐藏页面的问题。
- 修复阿拉伯语等从右向左书写的小说分页和阅读方向。
- 改善长验证页面和多语言人机验证提示的识别，避免页面尚未就绪时提前完成验证。

### 插件更新
- MissAV 0.0.7、JableTV 0.0.6、SupJav 0.0.6、123AV 0.0.7：补充作品番号、明确版本标记及原站提供的版本入口。

## English

### New
- JAV titles show subtitle and edition labels provided by the source, with links to available editions and code-based searches within or across sites; favorites, progress and downloads remain separate for each edition.
- Add a Simplified Chinese tag pack for FANZA rankings, with translated filter options and an option to show the original text.

### Improvements
- Reposition video progress, time and screen controls for narrow screens and larger text; the progress bar now appears and hides with the playback controls.
- Retry failed startup and copy diagnostic information; show persistent notices and retry automatically when changes cannot be saved.
- Preserve original records and local files when download recovery fails, with options to retry recovery or remove only the damaged record.

### Fixes
- Fix download tasks disappearing after failed deletion and unfinished chapter removals not being retryable.
- Fix earlier requests restoring old login information after a site's login state has been cleared.
- Fix keyboard input reaching hidden pages while the app is locked.
- Fix pagination and reading direction for Arabic and other right-to-left novels.
- Improve detection of long verification pages and localized challenges to prevent confirmation before the page is ready.

### Plugin updates
- MissAV 0.0.7, JableTV 0.0.6, SupJav 0.0.6 and 123AV 0.0.7: add work codes, explicit edition labels and edition links provided by the source.
