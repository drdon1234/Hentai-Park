# 界面设计

本文是修改界面的唯一依据。令牌与组件在 `lib/ui/theme.dart` 和 `lib/ui/kit/` 中实现；`tools/check_styles.mjs`（`tools/check.ps1` 的一部分）会拒绝绕过令牌的写法。

## 原则

1. **内容优先**：封面、标题和正文是主角。界面本身保持安静：暖中性底色、细线分隔、少量阴影，不用渐变背景和大面积色块。
2. **一个强调色，只用在该用的地方**：主操作（继续、阅读、播放）、进度、未读与选中状态。不给背景、芯片和输入框上色。
3. **衬线是阅读的声音**：页面大标题、作品标题和小说正文用衬线；按钮、标签、元数据和设置用无衬线。
4. **含义明确**：通用图标（返回、搜索、播放、下载、关闭、设置、更多）可以只用图标并提供 tooltip；含义不明的图标改成文字按钮（例如“全部暂停”“倒序”“订阅”）。
5. **不打扰**：不弹不必要的确认；但代替用户对外发出的动作（在站点上回复、发帖）、不可撤销的删除必须先确认，并写清楚会发生什么。
6. **布局稳定**：显示/隐藏横幅、切换分段、加载完成都不应让已有内容跳动；控制层叠加在内容上，不重排内容。

## 令牌

### 颜色

颜色全部来自 `ColorScheme`（由 `ParkTheme` 手写），界面代码只用角色名（`surface`、`onSurfaceVariant`、`primary`…），不写色值。

| 角色 | 暗色（默认） | 亮色 |
| --- | --- | --- |
| 背景 `surface` | `#141312` | `#FAF9F6` |
| 表面（逐级） | `#1C1B19` / `#242320` / `#2E2C29` | `#FFFFFF` / `#F0EEE9` / `#E3E0D9` |
| 正文 `onSurface` | `#ECE9E3` | `#1F1E1C` |
| 次要文字 `onSurfaceVariant` | `#A39E94` | `#6B6760` |
| 细线 `outlineVariant` | `#34322E` | `#E2DFD8` |

- 强调色默认“陶土”（亮 `#C96442`，暗 `#D97757`），用户可在“我的 → 外观”中换成琥珀、青苔、靛蓝、梅紫、樱粉。`ParkTheme` 会自动调整 `primary` / `onPrimary`，保证按钮文字对比度达到 WCAG AA（4.5:1）。
- 不属于配色方案的颜色只有两类，定义在 `kit/tokens.dart`：`Scrims`（图片与视频上的遮罩，以及遮罩上的白色文字）和 `ReaderPalette`（阅读器背景、护眼暖光、小说主题）。
- `Colors.black`、`Colors.white`、`Colors.transparent` 只用于图片遮罩和沉浸式阅读器。

### 文字

- 字号只用 `TextTheme` 的样式（`headlineSmall`、`titleMedium`、`bodyMedium`、`labelSmall`…），不写 `fontSize`。小说正文的字号来自阅读设置，通过 `ParkText.novel(...)` 生成。
- 字重最高 600，不用 bold / w700 以上。
- `ParkText.serif(style)`：页面大标题（`PageHeader`）、作品标题、空状态标题等。中日韩字符回退到 Noto Serif CJK / 思源宋体。
- `ParkText.mono(style)`：日志、Cookie、校验值。
- 按钮、页签、筛选项、菜单项和有独立长按操作的列表项使用 `SelectionContainer.disabled` 排除文字选择；简介、正文、日志和输入框保留复制能力。
- 默认页面不创建全页文字选择区；仅在详情简介、帖子详情正文、小说及日志等确有复制需求的内容边界内创建选择区。使用 `TextSelectionGuard` 限制起选位置，仅从实际文字行框开始选择，空白处和行尾空白不得吸附到其他区域；起选后保留内容区域内的跨行、跨段拖选。

### 间距、圆角、动效

| 令牌 | 值 |
| --- | --- |
| `Gap.xs` / `s` / `m` / `l` / `xl` / `xxl` | 4 / 8 / 12 / 16 / 24 / 32 |
| `Gap.page` | 16：页面左右边距 |
| `Radii.small` / `medium` / `large` | 8（封面、按钮、输入框）/ 12（面板、卡片）/ 20（底部弹层、对话框） |
| `Motion.short` / `medium` | 150 / 250 ms，曲线 `Motion.curve` |

动效时长通过 `Motion.of(context, …)` 取得，系统开启“移除动画”时为零。

## 组件

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 一级页面的标题栏：衬线大标题 + 右侧动作。需要附加信息时放在 `bottom` 里，不要改变标题行的位置 |
| `HeaderTabs` | 标题位置的分段（如书架的 收藏 · 更新 · 下载），可带未读数 |
| `SectionHeader` | 区块标题，右侧可放“更多”“全部”等文字按钮 |
| `ListRow` / `RowGroup` | 设置和列表的行；`RowGroup` 给一组行加标题并用细线分隔，不用卡片 |
| `HairlineItem` | 可拖动排序列表中的一行（带细线） |
| `CoverTile` / `CoverTileSkeleton` | 作品封面：封面上最多一层角标，标题与元数据在封面下方；有进度时显示进度条 |
| `Tag` | 小标签（分类、状态） |
| `EmptyState` | 空状态与错误状态：图标 + 衬线标题 + 说明 + 可选操作；`compact` 用于页面中的区块 |
| `ParkSearchField` | 发现页和搜索页共用的搜索框；只读时作为入口 |
| `confirmAction` | 确认对话框；删除等不可撤销操作用 `destructive: true` |
| `showChoiceSheet` | 从一组选项中选一个的底部弹层（清晰度、倍速、设置项的取值） |
| `ParkRefresh` | 下拉刷新，开始刷新时轻触感 |
| `ReaderChrome` | 漫画、小说、视频共用的沉浸控制层：点中间显示，顶部标题与动作，底部进度；叠加在内容上，不重排正文。视频用 `fade` 让控制条从屏幕边缘渐隐，不用整块实色条遮住画面 |
| `ReaderProgress` / `ReaderBadge` / `ReaderChapterEnd` | 阅读器底部进度、页码角标、章节末尾 |

## 按钮

- **主按钮**（`FilledButton`，强调色）：每屏最多一个，用于最主要的动作（继续/阅读/播放、保存）。
- **次级按钮**：描边、无底色，激活时图标用强调色（详情页的收藏、下载、更多）。
- **文字按钮**（`TextButton`）：标题栏和区块中的次要操作，以及所有含义不明、需要文字说明的操作。
- 带勾选标记的文字选项统一使用 `SelectionChip`，为勾号始终保留空间，切换状态时不得改变按钮尺寸或使同组选项换行。
- **图标按钮**：只用于通用图标，必须提供 `tooltip`。
- 破坏性操作的确认按钮用错误色。

## 页面结构

- 一级导航五项：发现 / 书架 / 下载 / 历史 / 我的。宽屏（≥ 840 dp）改用左侧导航栏；作品详情通过完整路由打开，宽屏下封面、元信息和正文按可用空间重新排版。
- 一级页面用 `PageHeader`，二级页面用普通 `AppBar` 或页面自己的头部（详情页）。
- 列表优先用细线分隔的行，网格用 `CoverTile`；不要在列表外再套卡片。
- 图片反搜服务按通用、里番、JAV、美图纵向分组，分组标题和服务选项直接展开，允许跨分类多选。小说使用无封面的统一作品行，依次显示标题、作者、简介和日期、分类标签，缺失字段不占位。
- “我的”及设置表单统一使用 `SettingsBody`，内容居中且最大宽度为 760 dp；作品网格和阅读区域按各自内容布局。设置入口名称允许完整换行，摘要可以省略。
- 页面左右边距统一 `Gap.page`。窄屏、大字体、文本展开和长列表滚动都要检查。
- 同页的说明、区块标题、筛选项和列表使用同一内容边界；外层已设置页面边距时，内部列表行不再重复叠加页面边距。控件内部间距和图标触摸区域独立处理。

## 触感

- 只在确认用户动作已生效时给轻触感：切换导航、分段与多选（`selectionClick`），收藏（`lightImpact`），下拉刷新开始（`mediumImpact`）。
- 不给滚动、普通点击和自动发生的变化加触感。

## 无障碍

- 图标按钮必须有 `tooltip`（读屏也会读出）；纯装饰的图片和图标排除在语义树之外。
- `CoverTile` 等复合组件提供合并后的语义标签（标题、站点、角标、进度）；封面角标用 `CoverBadge` 同时给出读屏文字。
- 文字与背景的对比度至少 4.5:1；不要只用颜色传达状态。
- 尊重系统的字体缩放和“移除动画”设置。
- 触控区域至少 48 × 48 dp；强调色色块保留 36 dp 视觉尺寸，外侧留出可点击区域。
- 仅展示当前平台已实现的设备能力；切换设备或恢复备份时保留配置，但不显示无效果的开关。
