# Web 全端 UX 对齐与优化方案

## 文档定位

本文是待实施的工作方案，覆盖移动浏览器、平板浏览器和桌面浏览器。移动 Web 的任务、信息层级、操作语义及状态行为以当前 Android 手机为对照基线；桌面端从同一移动任务模型扩展，允许使用适合鼠标、键盘和宽屏的呈现。颜色和动效允许不同，浏览器或操作系统客观能力导致的实现差异需要逐项说明并提供可完成任务的路径。

公共约束以[公共设计准则](../DESIGN.md)为准，Android 基线见[安卓设计准则](../design/ANDROID.md)，当前 Web 有效规范见 [Web 设计准则](../design/WEB.md)。本文提出的目标不代表已经实现或已经验收。实施并确认后的长期规则应修订对应主文档，本文用于组织工作，不维护另一套永久设计规范。

### 证据与边界

- 已针对工作区代码核对根导航、收藏、短视频触摸入口、酒馆消息和部分设置。相关源码可能含未提交修改，实施前必须重新核对。
- 除明确标注的代码发现外，下列条目是目标或待核验事项，不能直接认定当前功能缺失。
- 本文不宣称已逐行审查全部实现，也不代表已进行 Android 真机、移动浏览器或桌面浏览器视觉与操作验收。
- “对齐”指用户能以相同概念完成相同任务，并得到等价反馈与状态连续性；不要求复制平台控件、源码、配色和动效。额外的 Web 实例认证与服务部署能力保留其真实语义。

## 1. 目标与交付原则

1. 统一四个根任务：发现、收藏、下载、我的。相同目的地、操作、内容类型和状态使用一致名称。
2. 先完成移动端整条任务路径，再将其展开为桌面侧栏、多栏、快捷键或右键等形式；桌面增强不能成为核心功能的唯一入口。
3. 从进入、浏览、执行、反馈、失败、取消、返回和恢复定义每项功能；收藏、订阅、原站互动、下载和历史互不隐式替代。
4. 保留浏览器真实链接、复制链接、直接访问、前进后退和新标签行为；以浏览器或服务端事实决定状态，不伪装原生平台能力。
5. 逐功能核实差距和平台约束；Android 已有实现存在缺陷时，修复共同任务的根因，不机械复制。
6. 遵守现有隐私、站点隔离、媒体授权、内容过滤和数据完整性要求；不以 UX 简化绕开权限、丢弃用户数据或虚构成功。

## 2. 全局交互契约

### 2.1 信息架构与导航

- 手机根页面显示“发现 / 收藏 / 下载 / 我的”，选中态、未读或更新提示、页面标题和入口关系与 Android 对照。二级页面返回明确的实际上级；根页面内切换保留各自可恢复的范围与位置。
- 域页、站点、搜索、详情、阅读和管理保持真实链接；已提交的查询、筛选和可分享的导航状态进入 URL，输入草稿和未确认面板不进入可分享状态。
- 移动端抽屉及顶部导航先与 Android 任务清单核对：有价值的额外入口可作为浏览器导航增强，但不能让同一功能出现不同归属或使一级导航含义变化。
- 桌面侧栏采用相同名称与层次，可常驻、折叠；宽屏并排显示的列表和详情仍保留独立 URL、可达的返回路径、焦点顺序及窄屏同等功能。
- 没有可信站内来路时返回实际父级；浏览器后退、前进、刷新和外部直接打开均须定义行为。弹层关闭优先于离开页面，未经确认的变更不静默丢弃。
- 现有 [Web 设计准则](../design/WEB.md)将第四项写为“设置”，而两端代码的移动根导航为“我的”；确认落地后修正规范，并统一页面标题与可访问名称。

### 2.2 布局、控件和反馈

- 移动端以单手操作和内容阅读为中心，标题、常用动作、筛选及正文遵循一致内容边界；长标题自然换行，窄屏和大字体下操作可重排或进入具名菜单。
- 桌面按内容和任务增加列数或并列面板，控制最大阅读宽度；不将移动页面简单拉宽，也不因悬停隐藏唯一操作。
- 相同动作统一图标、名称、选中与禁用语义。导航用链接，命令用按钮，互斥选项用单选控件，二元设置用开关；图标操作提供可访问名称和桌面提示。
- 初次加载、保留旧内容刷新、空结果、部分失败、完全失败、结束及取消分别表达。重试就近出现；提交中防重复，成功以服务端或实际文件操作完成为准。
- 破坏性操作说明对象和影响范围并要求确认；取消保持原状态。长任务展示真实进度、可取消性和后台行为，不能因关闭页面误称取消。
- 所有界面文案同步八种语言，远端标题、标签和用户输入保留原文身份；长文、RTL、系统字体缩放和安全区域纳入布局。

### 2.3 状态、并发与资源

- 服务端为收藏、进度、下载、订阅和共享设置的事实来源；浏览器本地仅保存明确属于当前设备或标签页的偏好与草稿。跨标签页更新采用失效后重读，草稿冲突可见且不覆盖。
- 页面切换、后台、应用锁、弹层和完整页面覆盖分别处理媒体与请求。迟到结果不得覆盖新查询、站点或作品；取消应传播到可取消的请求。
- 无痕状态下不写入约定范围内的历史和进度，不改变用户明确提交的收藏、下载和订阅；需要逐项核对其作用范围和多标签页行为。
- 删除、导入和批量操作报告完整成功、部分成功或失败的实际结果，允许重试失败项；跨页面状态更新后保留有效上下文。

## 3. 功能域实施方案

### 3.1 首次访问、认证和应用锁

- 对照 Android 梳理年龄确认、隐私偏好、首页兴趣、完成和返回。Web 实例认证位于内容访问之前，认证失败保留当前地址和用户输入中允许保留的部分。
- 应用锁区分实例身份与站点账号；明确锁定范围、失效、解锁失败、恢复上下文和媒体释放。浏览器后台与设备锁屏不可假定等价。
- 无可用站点时给出真实的站点管理入口；失败和空数据分别表达。首启流程的保存失败应有就近提示和重试，不因跳页丢失选择。

### 3.2 发现、域和站点

- 对齐内容范围、媒体类型、域顺序、订阅入口、全部站点、首页站点显隐与顺序。筛选变更后同步发现范围与聚合搜索范围；外部链接进入被隐藏域时按 Android 的恢复规则处理。
- 主页和域页按真实来源展示货架和卡片；保留站点进入、展开、加载失败、隐藏及恢复。站内使用插件声明的网格、文字列表、文章流、帖子流或目录层级。
- 桌面横向货架支持滚轮、键盘和明显的边界控制；手机支持触摸滑动。切换布局不应重新提交筛选或丢失滚动位置。
- 验收多源部分失败、未启用站点、省流量、长标题、缺封面和受屏蔽内容；不以空结果掩盖站点错误。

### 3.3 搜索、筛选、反搜和排行榜

- 对齐聚合搜索、站内搜索、作品资料搜索的范围及入口；输入法组词不提交，搜索建议防抖并可取消，失败不阻止正常搜索。
- 筛选面板区分草稿、应用、恢复默认和取消，保留原站层级及动态选项；多语言搜索翻译与内容翻译分开，保留原始搜索值。
- 图片反搜覆盖选择、替换、裁剪、跨服务选择、提交、分站部分失败、更多结果与历史；新图准备失败保留旧图及结果，上传前准确提示目标和影响。
- 排行榜核对域、筛选、站点配置、详情、独立搜索、原站、评论与多候选选择；不将不同来源的 ID 当作同一个作品。
- 桌面增加键盘操作和宽屏结果布局，保留移动端同一筛选语义和操作结果；返回搜索时恢复查询、范围和位置。

### 3.4 作品详情和章节

- 按漫画、小说、视频、音声、文章、游戏及资料分别核对封面比例、标题、元数据、简介、标签、主操作和能力驱动入口。手机优先使阅读、播放或获取资源可见，宽屏将信息放在封面旁。
- 应用内收藏、原站收藏、订阅、下载、分享和外部链接各自表达；屏蔽内容默认隐藏，临时显示不修改永久规则。
- 章节提供真实顺序、已读、进度、更新与批量下载；支持更多章节时不能把当前已加载范围误称全部。单页图片、音声目录和游戏资源按各自任务处理。
- 推荐、评论、翻译、原站互动和资源链接分别加载和报错；局部失败保留正文。任何向原站发送的互动先明确对象和动作。

### 3.5 漫画、小说、文章与相册

- 漫画核对滚动、单页、双页、方向、缩放、目录、跳页、章节切换、单页重试、进度恢复及阅读设置；工具覆盖内容时不改变分页几何。
- 小说核对分页与滚动、字体、行距、主题、目录、书签、标注、朗读和翻译；上章末页、恢复位置、翻译中断与原文保留均需验证。
- 文章保持文本、图片和视频的原站顺序及可选择文本，媒体失败就近重试；标签使用真实来源分页。
- 相册保持图片与视频的真实顺序、类型和日期筛选，任一附件打开后仍能访问同组附件；关闭或切换视频释放播放资源并恢复焦点。
- 手机检查点击、滑动、双指缩放和系统返回；桌面检查方向键、滚轮、焦点与选中文本。输入框、菜单和系统快捷键不能误触翻页。

### 3.6 视频、音声、直播与短视频

- 点播核对播放/暂停、进度、选集、线路、字幕、倍速、音量、全屏、浏览器可用的画中画、恢复和结束重播；选集和设置弹层打开时保持既定播放意图。
- 音声核对目录层级、分页、已加载同级播放列表、关联字幕、继续播放和下载；后台播放与系统媒体控制仅按浏览器实际支持提供，明确失败与恢复。
- 直播核对直播状态、录制、弹幕及退出播放后的录制状态；不显示没有意义的点播进度和倍速。录制任务与播放器分别管理。
- 短视频核对上下切换、上一条/下一条、边界分页、双击、长按、简介、收藏、下载、预加载和返回列表。当前 [Web 短视频](../../clients/web/apps/web/src/short-video.tsx)将 `video` 排除在触摸切换目标外，从该元素开始的滑动不会触发页面切换；应重新设计舞台命中与控件手势的竞争规则，并在真实触屏上验证。
- 自动播放、方向锁定、亮度和画中画受浏览器或设备限制时提供用户手势、系统控件或明确说明；不将受限接口显示为已生效。

### 3.7 收藏、历史、下载与订阅

- 收藏按 Android 对照分类、搜索、筛选、排序、网格/列表、更新、批量分类、已读、迁移与取消收藏。当前 [Web 收藏页](../../clients/web/apps/web/src/main.tsx)的批量工具仅有移除，选择列表和作品网格重复呈现，分类筛选显示 ID；批量移除也缺少确认。调整为直接在作品项上选择、显示分类名称，并补齐真实能力、确认和部分失败处理。
- 历史核对按内容类型进入、继续阅读、位置、筛选、批量删除和无痕；不可用内容保留可识别记录与恢复路径。
- 下载核对作品与章节分组、状态、进度、暂停、恢复、取消、重试、删除、导入、导出和离线打开。明确浏览器下载到设备与服务端后台下载的差别；删除提示文件影响，任务状态以服务端为准。
- 订阅核对新增、编辑、目标和筛选、启停、检查、未读、通知及删除；首次基线与已有更新区分，单个站点失败不清空已有内容。
- 桌面批量操作可以增加全选和快捷入口，手机同样能完成相同操作；多标签页和页面关闭不改变已提交后台任务。

### 3.8 酒馆、游戏与资源

- 酒馆核对角色卡、世界书、收藏、导入导出、连接、会话选择与用户人格。消息展示发送时身份和头像，提供编辑、删除及分支，最后回复提供续写和重生成。
- 当前 [Web 会话](../../clients/web/apps/web/src/tavern-chat.tsx)没有消息级菜单；生成中断已有部分内容时同时恢复输入，可能使用户再次发送相同文本；新会话会清空当前草稿。明确已提交消息、部分回复、输入草稿和保存状态，切换或离开时保护未保存内容，并为删除说明范围。
- 游戏区分在线运行与获取资源，保留链接、提取码、复制及明确的外部发送确认；在线游戏核对加载、验证、全屏、虚拟按键、存档和切后台释放按键。浏览器不能支持的操作需展示真实限制。
- 桌面聊天区与资源资料可并列，移动端按同样任务顺序进入；消息回看时流式生成不能强制滚到底部。

### 3.9 我的、设置、站点管理与诊断

- “我的”页面和分组名称、摘要及操作顺序与 Android 对照；核对外观、阅读、短视频、书架与下载、搜索与翻译、网络、隐私、订阅、过滤、站点、存储、备份和关于。
- 对照[Android 存储页](../../lib/ui/settings/storage_page.dart)补齐可统计、可清理项目；将服务器缓存、服务端下载和浏览器缓存的作用范围写清。设备权限、服务器路径及部署参数按实际权限提供等价管理或说明。
- 站点安装、更新、启停、账号、验证和插件设置展示真实进度、权限变化及失败恢复；站点业务规则不写死在 Web 通用 UI。
- 备份和恢复明确分区、敏感数据、未加密风险、预览、冲突、确认与导入结果；失败保留现有数据。诊断和日志按白名单脱敏，补核版本与许可证等关于信息。
- 设置区分即时生效项与待保存项，导航离开、重读、跨标签页更新和版本冲突时保护草稿；相同设置在不同入口只维护一个真实值。

## 4. 已确认事项与待核验清单

| 项目 | 当前证据 | 实施时必须补充 |
| --- | --- | --- |
| 根导航 | 两端代码均为发现、收藏、下载、我的；Web 设计文档使用“设置” | 检查全部子路由、返回和未读提示 |
| 收藏 | Web 批量操作及分类展示与 Android 不同，移除缺确认 | 核对服务端批量、迁移和部分失败契约 |
| 短视频 | `video` 目标被排除在 Web 触摸切换之外 | 真机验证舞台、控件、滚动和手势冲突 |
| 酒馆 | Web 缺消息菜单；中断和新建会话存在草稿处理风险 | 核对持久化、失败恢复、分支和并发 |
| 设置与存储 | 两端页面结构及存储操作不同 | 按设置项逐项比较实际生效、可用范围和数据位置 |
| 其余功能域 | 已识别入口与相关模块，未逐条完成双端操作验证 | 按第 5 节矩阵补充证据后确定具体缺口 |

代码检查只能证明相应分支存在或不存在，不能代替实际布局、触屏、外站或设备能力验证。任何未核验事项不得在实施记录中标记为已对齐。

## 5. 验收矩阵与证据

每个功能域建立逐项记录，至少包含：任务及入口、Android 行为、移动 Web 行为、桌面 Web 行为、适用能力、差距、源文件和接口、目标、负责人或实施批次、验证方式、结果与未验证范围。以任务为单位而不是以页面截图数量计数。

| 场景 | 必须覆盖 |
| --- | --- |
| 常规任务 | 进入、主要操作、成功反馈、返回、再次进入和位置恢复 |
| 状态与数据 | 首次加载、空、部分失败、全部失败、重试、取消、处理中重复点击、无痕和跨标签页 |
| 视口 | 正常屏幕加正常字号；窄屏加大字号；横屏和宽屏。检查首屏、滚动中段与末尾 |
| 设备输入 | Android 真机与移动浏览器触摸；桌面键盘、鼠标；焦点、屏幕阅读语义、缩放与减少动画 |
| 浏览器 | 直接访问、刷新、前进后退、新标签、复制链接、断网恢复、后台和页面关闭 |
| 媒体 | 手势竞争、加载失败、切集、进度、全屏、资源释放和恢复；真实站点或受控素材标注来源 |
| 有副作用操作 | 收藏、下载、删除、订阅、导入和对外发送的确认、完成状态及部分失败 |
