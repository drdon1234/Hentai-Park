## 平台支持

提供 Android、Windows、macOS 和 Linux 客户端；iOS/iPadOS 目前仅提供模拟器包，Web 暂不支持。安装方法与平台限制见 [平台说明](docs/PLATFORMS.md)。

桌面支持 Ctrl+滚轮、Ctrl/Cmd 加减键缩放界面，Ctrl/Cmd+0 恢复默认，也可在外观设置中调整。Windows 托盘图标可恢复窗口或退出；关闭窗口时可选择收起到托盘或退出。

## 下载

在 **[最新版本](https://github.com/drdon1234/Hentai-Park/releases/latest)** 下载对应平台的安装包。Android 多数手机和平板选 `arm64-v8a`，模拟器一般选 `x86_64`。桌面包需完整解压，详细安装方法见 [平台说明](docs/PLATFORMS.md)。

## 三步上手

1. **发现**：打开「发现」，选一个分类，或在搜索框里输入关键词、粘贴链接或车号。
2. **阅读与播放**：打开作品，点主按钮开始；喜欢的加入「书架」。
3. **接着看**：「发现」顶部的「继续看」和「历史」会带你回到上次的位置；追更的作品在「书架 → 更新」。

需要登录或代理的站点，在「我的 → 站点」和「我的 → 网络」中设置。

支持匿名浏览的站点若推荐需要登录，会默认展示可匿名访问的排行榜；登录或完成网页验证后，主页和站点内容自动刷新。

## 功能

| 功能 | 说明 |
| --- | --- |
| 发现与搜索 | 主页与分类页共享推荐内容，支持分页的站点可向右继续浏览；多站同时搜索，可用多种语言的关键词扩大范围；粘贴链接或车号直达作品 |
| 排行榜 | 在「发现」顶部打开本子、里番、JAV 榜单，分市场榜与站点榜；JAV 可看作品、女优和可筛选的分类榜 |
| 阅读与观看 | 漫画滚动、翻页或双页；视频选集、倍速与续播；小说排版、书签、标注与朗读。三种阅读器用同一套控制层 |
| 书架 | 收藏分组、更新提醒；订阅作者、频道或关键词的新内容 |
| 下载 | 独立主导航入口，管理漫画、视频、小说与游戏下载；导入、导出 CBZ；在作品菜单按已完成章节导出 PDF，动图仅保留第一帧 |
| 游戏资源 | 查看游戏介绍、版本与下载链接 |
| 翻译与过滤 | 翻译标题、简介与标签；按标签屏蔽内容 |
| 隐私与备份 | 应用锁、无痕模式、封面模糊、防截屏；备份收藏、进度与设置 |

在「我的 → 网络 → 省流量模式」选择：普通省流仅在主页和域页显示紧凑站点入口，进入站点后再加载作品；超级省流在站点页也不自动加载，提交搜索后才获取作品。不支持搜索的站点会显示说明。

小说阅读页「更多 → 全文翻译」可翻译完整正文，并随阅读继续翻译后续章节，支持切回原文。

浏览页与详情页可先显示本机缓存；媒体链接过期时需要刷新。返回主页会保留滚动位置。长按作品卡片可屏蔽作品或作者，在内容过滤设置中取消屏蔽。排行榜保留筛选条件，每次进入获取最新榜单。短视频默认使用 RedGifs。

Reddit 和 X 的站点主页、Reddit 社区及 X 社群支持开启「短视频模式」，上下滑动播放当前范围内帖子的视频。Reddit 支持自托管视频和 RedGifs 外链视频。同帖多个视频分别播放；X 社群可从站点页的「社群」入口输入链接或选择已加入的社群，访问权限取决于原站。

短视频支持提前加载和保留最近看过的视频及缓冲，默认各 2 条；在「我的 → 短视频」或播放页「更多 → 短视频设置」分别调整，设为 0 可关闭。缓存仅在当前播放页有效，数量越多占用的内存和流量越多。

应用内收藏只保存在本地书库；“原站互动”使用当前登录账号，按站点能力分别提供点赞、收藏/书签和评分。X 的书签归入原站收藏；Pixiv、X、哔咔支持原站点赞和收藏，MissAV 支持收藏，EH 支持收藏和评分。可登录站点在工具栏下显示登录或账号管理入口。Pixiv 匿名和登录状态均默认进入推荐，支持连续加载、作者其他作品和相关推荐；Pixiv 与 EH 的站内搜索支持关键词联想。搜索框可粘贴作品或分享链接，识别后直接打开应用内作品。

GalgameX 支持原站收藏：新增收藏保存到原站的第一个收藏夹，没有收藏夹时请先在原站创建；取消收藏会从各收藏夹移除该作品。

JAV 作品可查看原站标注的字幕与版本差异，切换原站提供的版本，或按番号在站内、跨站查找；各版本的收藏、进度与下载独立保存。

亮色与暗色主题，八种界面语言。每个站点可用的功能以应用内显示为准。

## 常见问题

**站点打不开，或图片、视频加载失败？**
先检查网络。部分站点在中国大陆可能需要 VPN 或代理，可在「我的 → 网络」设置代理。站点验证会在后台自动尝试；暂未完成时可在应用内重试。

首次使用需确认成年并阅读免责声明，确认保存在本机。支持的站点年龄确认与 Cloudflare 验证由应用后台处理，只有登录需要操作原站页面。Windows 支持标准 Cloudflare 复选框的后台模拟点击；其他平台会尝试自动验证，无法完成时在应用内提示重试。

JM 和哔咔支持自动探测可用线路。只有确认出口 IP 与上次相同时才复用线路；出口变化或无法确认时重新探测。探测不使用第三方公共 IP 查询服务，仍可手动选择分流。

**需要站点账号吗？**
大多数不需要。需要登录的站点会在站点页顶部提示，也可在「我的 → 站点」打开该站点的设置登录。Pixiv、X、StoriesOnline 的网页登录支持 Google、Apple 等第三方账号授权，是否放行内嵌浏览器由第三方平台决定。

**会替我在站点上发帖或回复吗？**
不会自动这样做。次元茶馆的部分资源需要回复才能解锁，应用会先显示将要发送的内容，经你确认后才发送。

**换手机怎样保留收藏和进度？**
在「我的 → 备份」导出备份，在新设备上恢复。离线下载不在备份中，站点账号可能需要重新登录。

**翻译会上传什么？**
翻译标题、简介、标签、搜索词、选中文字或小说全文时，相应内容会发给 Google 翻译；不会发送账号、Cookie 或阅读记录。目标语言跟随应用语言。

**怎样反馈问题？**
在 [Issues](https://github.com/drdon1234/Hentai-Park/issues) 写明应用版本、站点名称和复现步骤；截图前请隐藏账号和私人内容。

请勿在公开反馈中附上账号密码、Cookie、Token、会话导出、应用备份、抓包文件或带签名参数的完整链接；日志只使用应用内导出的脱敏报告。
