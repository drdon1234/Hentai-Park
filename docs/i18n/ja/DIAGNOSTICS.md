# 実行ログと不具合報告

通常ログにはエラー、自動再試行、サイト呼び出し結果、アプリの状態変化を記録します。設定の実行ログを更新・エクスポートし、再現手順とともに Issue に添付できます。

難しい問題には debug ログを有効にします。「今回のみ」は今すぐ再現する場合、「次回起動のみ」は起動から記録する場合に使います。予約が有効になると起動後に通知されます。debug は終了時に無効になり、予約は一度だけ有効です。

長期ログは初期状態では無効で、起動ごとに直近の実行記録を上書きします。有効にすると起動をまたいで追記し、100 MiB に達してから古い記録を削除します。無効にすると実行履歴を直ちに上書きします。独立したクラッシュ履歴には影響しません。

debug では要求時間、再試行、キャッシュ、再生状態も記録します。アカウント、Cookie、Token、本文、ローカルパス、完全な署名付きリンクは記録しません。画面は最近の記録、エクスポートは保持中の全実行ログを含みます。匿名化モードではホスト名と OS 詳細版も隠します。共有前に内容を確認してください。
