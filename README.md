## 快速上手

1. 在「发现」选择内容分类，浏览站点，或搜索作品、标签、链接与番号。
2. 打开作品阅读或播放；将作品加入「收藏」，需要离线时选择下载。
3. 从主页「继续看 → 全部」接着看，在「收藏 → 更新」查看新章节。

需要登录或代理的站点，可在「我的 → 站点」与「我的 → 网络」中设置。

## 必要限制与常见问题

酒馆需要自行配置兼容 OpenAI 的 AI 服务；消息、角色设定、用户人格与匹配的世界书内容会发送给所选服务，可能产生费用。支持的世界书规则与导入导出方式见[站点与服务](docs/SITES.md)。已保存资源与会话进入未加密书库备份，AI 服务配置和密钥不进入备份。

不同站点提供的阅读、播放、评论、订阅和下载能力各不相同，以应用内实际显示为准。站点更新可能要求先升级应用。

图片反搜会将图片发送至所选服务；本机反搜历史未加密。手动登录时密码与 Cookie 可见，请留意屏幕分享。

**站点打不开或内容不可用？**

先检查网络，再按应用提示登录、完成年龄确认或站点验证。部分地区可能需要 VPN 或代理；内容与权限由原站决定。 可自动处理的生日验证只在本机已确认成年后填写固定日期 1999-12-31，不读取真实生日。

**评论和弹幕可以发送吗？**

评论、回复与直播弹幕仅供阅读。部分游戏资源站需要回复解锁时，会先显示回复内容，经你确认后才发送。

**如何保留收藏和进度？**

在「我的 → 备份」导出或恢复 .parkbak。恢复会合并数据，不包含下载文件；可选择携带 Cookie 等站点登录与确认状态，供其他设备复用，过期或绑定设备的会话可能需要重新验证。备份未加密，请妥善保管。 在线游戏存档不包含在 .parkbak 中；游戏内单独导入导出仅覆盖 localStorage，不含 IndexedDB，导出文件未加密。

**如何反馈问题？**

通过 Issues 提供应用版本、站点名称和复现步骤。请隐藏账号、Cookie、Token、备份文件与完整签名链接。
