## 中文

- 日志脱敏改为直接开关，与 debug 日志、长效日志使用统一设置样式。
- 统一备份、订阅间隔和阅读点击区域的设置选择方式。
- 统一阅读、小说、翻译、筛选与订阅中的开关样式。

### 修复
- 修复日志正文左右留白不足的问题，滚动后仍保持统一页面边界。
- 修复相册、章节多选、订阅、历史、下载与排行榜部分内容或操作的左右边距不一致。

## English

### Fixes
- Fixed insufficient horizontal margins in log content, keeping the page boundaries consistent while scrolling.
- Fixed inconsistent horizontal margins for content and actions in albums, chapter selection, subscriptions, history, downloads and rankings.
