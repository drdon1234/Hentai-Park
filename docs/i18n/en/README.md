## Download

Get the package for your platform from the **[latest release](https://github.com/drdon1234/Hentai-Park/releases/latest)**. For Android, most phones and tablets need `arm64-v8a`; emulators usually need `x86_64`. Extract desktop packages in full. See [installation and platform limits](../../PLATFORMS.md).

Clients are available for Android, Windows, macOS and Linux. iOS/iPadOS currently has a simulator package only; Web is unavailable. See [installation and platform limits](../../PLATFORMS.md). Live playback and recording support TS and fMP4 streams.

On desktop, use Ctrl+mouse wheel or Ctrl/Cmd plus/minus to scale the interface, and Ctrl/Cmd+0 to reset; scaling is also available in Appearance settings. The Windows tray icon restores the window or exits the app. When closing the window, choose to hide it to the tray or exit.

## Get started in three steps

1. **Discover**: open Discover and pick a category, or type a keyword, paste a link or a video code into the search box.
2. **Read and watch**: open a work and tap the main button. Add the ones you like to Favorites.
3. **Pick up where you left off**: use Continue → All on Discover to browse your history; followed series appear under Favorites → Updates.

Sites that need an account or a proxy are set up in More → Sites and More → Network.

Plugin update prompts show how many plugins can update now and how many require a newer app, grouped by minimum app version. Incompatible plugins keep their installed version. Choose “Don’t remind me” for an app or plugin update to ignore that version; manual checks still show it, and newer versions prompt again.

On Windows, macOS and Debian-based Linux, confirming an update downloads and verifies the installer, opens it, and exits the app. Follow the system prompts to finish installation. On other Linux distributions, download the archive manually. Portable Windows ZIP and Linux tar.gz archives contain a fixed `HentaiPark` directory; macOS ZIP archives contain `HentaiPark.app`.

## FAQ

**A site won't open, or images and videos fail to load?**
Check your connection first. Some sites may need a VPN or proxy in mainland China; set a proxy in More → Network. Site verification is attempted automatically in the background; retry in the app if it does not complete.

On first use, confirm adulthood and read the disclaimer; confirmation stays on this device. Supported age gates and Cloudflare checks run in the background; only sign-in requires using the site page. Windows supports background clicks on standard Cloudflare checkboxes. Other platforms attempt automatic checks and offer an in-app retry if unsuccessful.

JM and PicACG can probe available routes automatically. A saved route is reused only after confirming the same outbound IP; a changed or unknown IP triggers a new probe. No third-party public IP lookup service is used. Manual server selection remains available.

**Do I need site accounts?**
Mostly not. Sites that need one say so at the top of the site page, and you can sign in from that site's settings in More → Sites. Web sign-in for Pixiv, X and StoriesOnline supports third-party accounts such as Google and Apple; whether they allow the embedded browser is up to them.

**Will the app post or reply on my behalf?**
Never on its own. Some Dimension Tea House resources only unlock after a reply; the app shows you exactly what will be posted and sends it only after you confirm.

**How do I keep favorites and progress on a new phone?**
Export and restore `.parkbak` files under **More → Backup**. Select **Site sign-in and verification data** when creating a backup to include cookies, tokens and site verification state. Backup files are not encrypted; keep them safe. Downloads are not included, and expired or device-bound sessions may require verification again.

**What does translation send?**
When translating titles, descriptions, tags, search terms, selected text or a full novel chapter, that content is sent to Google Translate. Accounts, cookies and reading history are not sent. The target follows the app language.

**How do I report a problem?**
Open an [issue](https://github.com/drdon1234/Hentai-Park/issues) with the app version, site name and steps to reproduce. Hide accounts and private content in screenshots.

Do not include passwords, cookies, tokens, session exports, app backups, network captures or full signed links in public reports. Share only the redacted log report exported by the app.
