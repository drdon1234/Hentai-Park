## 下载与平台

从 **[最新版本](https://github.com/drdon1234/Hentai-Park/releases/latest)** 下载对应平台的安装包。支持 Android、Windows、macOS 和 Linux；iOS/iPadOS 当前仅提供模拟器包，Web 暂不支持。Android 多数手机和平板选择 arm64-v8a，桌面包需要完整解压。平台限制和安装步骤见 [平台说明](docs/PLATFORMS.md)。

## 三步上手

1. 打开「发现」，选择分类，或搜索关键词、粘贴作品链接/番号。
2. 打开作品开始阅读或播放，喜欢的内容加入「书架」。
3. 从「继续看」「历史」或「书架 → 更新」回到上次进度。

需要登录或代理的站点，在「我的 → 站点」和「我的 → 网络」设置。站点更新会提示是否需要先升级应用；每个站点实际可用的功能以应用内显示为准。

## 常见问题

**站点打不开或媒体加载失败？**
先检查网络；部分站点可能需要 VPN、代理、登录或在站点页面完成验证。应用内提示失败时可重试。

**需要账号吗？**
大多数站点不需要。需要登录的站点会在应用内提示；原站账号权限仍由原站决定。

**应用会替我发帖或回复吗？**
不会自动操作。次元茶馆等站点需要回复解锁资源时，会先显示内容，确认后才发送。

**如何保留收藏和进度？**
在「我的 → 备份」导出和恢复 .parkbak。下载文件不在备份内，含登录状态的备份未加密。

**如何反馈问题？**
在 [Issues](https://github.com/drdon1234/Hentai-Park/issues) 提供应用版本、站点名称和复现步骤。请隐藏账号、Cookie、Token、备份文件和完整签名链接。
