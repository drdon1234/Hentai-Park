**[تنزيل](https://github.com/drdon1234/Hentai-Park/releases/latest)**

يدعم **Android 7.0+ وWindows**. تستخدم معظم أجهزة Android حزمة `arm64-v8a`؛ فك ضغط أرشيفات ZIP المحمولة لـ Windows بالكامل.

يستهدف المشروع Android وWindows وWeb فقط. إصدار Web مخطط له، لكنه غير متاح للاستخدام بعد.

على Windows، يؤدي تأكيد التحديث إلى تنزيل برنامج التثبيت والتحقق منه وفتحه وإغلاق التطبيق. اتبع تعليمات النظام لإكمال التثبيت. تحتوي أرشيفات ZIP المحمولة على مجلد ثابت باسم `HentaiPark`.

## البدء

1. من «استكشاف»، اختر فئة وموقعاً أو ابحث بالعمل أو الوسم أو الرابط أو الرمز.
2. افتح العمل للقراءة أو المشاهدة. أضفه إلى «المفضلة» أو نزله للاستخدام دون اتصال.
3. تابع من الرئيسية ← متابعة ← الكل، وراجع الفصول الجديدة في المفضلة ← التحديثات.

عند الحاجة، اضبط تسجيل الدخول في المزيد ← المواقع والوكيل في المزيد ← الشبكة.

## القيود والأسئلة الشائعة

تختلف إمكانات القراءة والتشغيل والتعليقات والاشتراكات والتنزيل حسب الموقع. راجع ما يعرضه التطبيق. قد تتطلب تحديثات المواقع ترقية التطبيق.

**الموقع أو المحتوى غير متاح؟**

تحقق من الاتصال ثم سجل الدخول أو أكد عمرك أو أكمل تحقق الموقع حسب التعليمات. قد تتطلب بعض المناطق VPN أو وكيلاً؛ يحدد الموقع الأصلي المحتوى والصلاحيات.

**هل يمكن إرسال التعليقات والدردشة؟**

التعليقات والردود ودردشة البث للقراءة فقط. إذا تطلب مورد لعبة رداً لفتح الرابط، يُعرض النص أولاً ولا يُرسل إلا بعد تأكيدك.

**كيف أحفظ المفضلة والتقدم؟**

صدّر أو استعد .parkbak من المزيد ← النسخ الاحتياطي. تدمج الاستعادة البيانات ولا تشمل الملفات المنزلة. يمكنك اختيار تضمين حالة الدخول والتأكيد وملفات Cookie لاستخدامها على جهاز آخر. قد تتطلب الجلسات المنتهية أو المرتبطة بالجهاز تحققاً جديداً. النسخ غير مشفرة؛ احتفظ بها بأمان.

**كيف أبلغ عن مشكلة؟**

استخدم Issues مع إصدار التطبيق والموقع وخطوات التكرار. أخفِ الحسابات وCookie وToken والنسخ الاحتياطية والروابط الموقعة الكاملة.
