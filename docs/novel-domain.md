# 小说阅读

本次接入中文与英文常规线性文字小说，不包含 AI 生成服务、互动分支、有声站或 TXT/EPUB 导入导出。小说源使用独立的 `novel` 类型与分类，站点规则保留在插件内。

## 已接入源站

| 源站 | 默认入口 | 范围与限制 |
| --- | --- | --- |
| Book18 | 推荐 | 中文长篇与短篇；目录沿站点顺序 |
| Cool18 | 精华 | 仅禁忌书屋；每个主帖独立作品，不自动合并回复或同名帖子；部分内容需要账号权限 |
| Canovel | 最新 | 支持文章内部正文分页 |
| Literotica | 排行 | 英文；搜索排除非英文、有声、教程、评论与随笔分类；每篇独立读取 |
| Lush Stories | 推荐 | 英文；排除有声与诗歌分类，单篇独立读取 |
| StoriesOnline | 作者推荐 | 英文；匿名正文截断时提示登录，不把预览保存为完整章节 |
| 69story | 最新 | 中文；支持分类、搜索、目录及分章阅读 |

小说作品使用纯文字列表与详情，不构造封面或请求虚构图片。大陆访问可能需要 VPN 或代理。

## 阅读界面与书库

- 阅读模式：上下滚动、左右翻页、原文位置续读、章节前后切换、下一章预取。
- 排版：字号、系统／衬线／等宽字体、粗体、行距、字距、首行缩进、段间距、页边距、两端对齐；配置独立于漫画阅读器。
- 显示：纸张、白色、护眼绿、夜间、跟随系统主题，独立亮度或系统亮度、遮罩、阅读状态、沉浸、屏幕常亮与方向锁定。
- 操作：点击、滑动、音量键与键盘翻页，翻页动画、进度拖动、自动滚动、系统朗读和速度设置。
- 定位与标注：目录搜索／倒序、章节已读和下载状态、本章搜索、跨行选字复制、书签、标注高亮、备注编辑／删除及跨章节定位。
- 书库：小说筛选，复用收藏分类、排序、连载追更、批量已读、历史与继续阅读、按章下载及备份恢复。删除正文下载保留书签与标注。

进度和标注基于原文 UTF-16 字符位置，重排不修改正文。正文按章原子写入，未完成或受限预览不能作为完整离线章节使用。请求支持取消，旧章节响应不能覆盖新章节。

源插件的正文与章节协议见 [源插件开发指南](SOURCE_API.md)。
