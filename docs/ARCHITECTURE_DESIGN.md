# HentaiPark 跨端重构设计

**首个里程碑 M1 是 Android 覆盖升级后从原位置继续使用。** 在装有 v0.15.1 且已积累数据的设备上，用户覆盖安装 Compose 客户端，从原入口找到旧作品和下载，回到原章节、页码或播放秒数，继续使用后再次启动仍能恢复。先以这条路径验证 Rust、平台绑定、磁盘布局与原生 UI 的组合，再冻结跨端接口。实施顺序与准出证据见[任务清单](TASK.md)。

## 对照版本与工程取舍

唯一行为基线为标签 `v0.15.1`，提交 `beaeff7dde1041663e5e695d5627bc1fbdec8b5f`。下文的仓库链接用于定位文件，复核历史行为以该提交中的文件内容为准。基线包含 101 个官方 JS 脚本、7 种类型、17 个分区，使用插件 API v2、SQLite Schema v7、流式 Gzip JSON 备份 .parkbak v1。审查时主工作区另有未提交的 v9 数据层变更，须单列差异。两个历史工作树各自包含未提交的原型，仅用于评估进度接口、平台装载和壳工程。Windows 在基线已有 51 个跟踪文件，Web 已有独立服务、数据目录与 JSON 备份；替换前盘点其入口与用户数据。[公共契约](../assets/public-contract.json) · [平台说明](PLATFORMS.md)

采用 Rust 的依据是同一份网络、插件、媒体、存储和领域实现可链接进 Kotlin、Swift、C# 宿主及服务端。KMP 有 Android 集成优势，仍需处理 Windows 绑定和媒体库；C++ 可覆盖相同目标，但会增加不可信二进制解析和跨语言所有权的维护成本；继续嵌入 Dart 可保留现有逻辑，却会把 Dart 运行时带进每个原生宿主。保留旧 Dart/Kotlin 实现作为差分裁判。启动耗时、内存、帧时间和 seek 延迟均按旧版与候选版在同设备、同输入下实测；记录冷暖状态、峰值、分位数及测量范围。

## Android 原地接管

1. 比对已安装 APK 与候选包的 applicationId、签名身份、实际分 ABI versionCode。正式包名为 `com.hentaipark.hentai_park`；探索壳的后缀 `.native` 只适合并排调试。覆盖前在旧版留下可辨认的收藏分类、阅读／播放进度、离线文件和作品级游戏存档。[Android 构建配置](../android/app/build.gradle.kts)
2. 由宿主提供与旧版相同的应用支持目录。数据库在 `getApplicationSupportDirectory()/park/park.db`；设置、源登记、插件状态及 Cookie 分区按旧根定位。内部下载根为支持目录下的 `downloads/`，外部目录可承载下载与备份，已有任务保留其选择的路径。先识别新装或升级、访问权限、库版本与恢复日志，再决定是否创建文件。旧库不可读、版本高于支持范围或外部卷离线时保留原件并报告具体状态。[旧路径解析](../lib/core/storage.dart) · [打开数据库](../lib/main.dart)
3. 按原目录打开 SQLite，包括尚未 checkpoint 的已提交 WAL。前台入口与后台任务均先完成未结束的恢复事务，再启动设置、下载、订阅及插件。保留既有 WebView Profile、设备密钥访问、外部目录授权与下载任务引用。仅在确需高风险写入不可重建资产时做最小必要备份。
4. 用旧版记录的作品与章节身份比较升级前后页码、秒数、UTF-16 锚点和离线资源；继续操作、关闭再打开，比较新进度是否持久化。卸载重装、手工搬库、导入备份另属其他流程。

## 模块、接口与运行时所有权

以下名称同时用于设计和实施清单。领域规则可先作为一个模块维护；拆 crate 应有独立依赖或部署理由。

| 模块 | 职责与依赖边界 |
| --- | --- |
| park-contract | 从原公共资产读取其实际声明的类型、媒体种类、分区、语言和仓库信息。独立描述内部命令、事件、错误、空值与单位；原资产没有声明的 DTO 不从该文件推导。无网络、UI 和存储依赖。 |
| park-net | rustls 传输、代理、实际连接地址校验、重定向、源分区 Cookie 与 generation。提供受限的浏览器会话请求接口；由宿主执行系统浏览器操作。 |
| park-runtime | rquickjs 引擎池、每源执行上下文、DOM 与 Web API 宿主、Promise、插件状态落盘及清单缓存。仅经受控能力访问网络、持久化与诊断。 |
| park-media | 会话级媒体路由、Range 稀疏缓存、HLS、图片调度／变换、字幕、录制及导出。经 park-net 获取上游数据，以受限句柄或媒体路由向 UI 提供内容。 |
| park-storage | rusqlite、磁盘布局、单写者、只读连接、原子文件、备份编解码与恢复事务。负责写入的原子性及故障恢复。 |
| park-domain | 编排书库、双时间戳合并、下载、双轨更新、小说锚点、酒馆与筛选。复用原八语言资源、PluginCopy 和繁简映射；平台排版器决定实际分页。 |
| park-ffi | 嵌入式控制接口，负责类型转换、句柄、请求取消、订阅与释放；由领域服务提供实际行为。 |
| park-daemon | 直接链接同一领域服务，负责单用户实例、鉴权、HTTP/SSE、同源媒体与浏览器 worker 生命周期。数据库由服务端实例持有。 |

**控制接口。** Kotlin 和 Swift 优先验证 UniFFI 生成绑定；Android 平台 API 留在宿主，仅在选定绑定确需 JNI 时维护对应胶水。Windows 实测 C# 生成器的异步、回调与 GC 生命周期，再择定单一实现；必要时用窄 C ABI 和 SafeHandle。Apple 交付设备、模拟器和 macOS 可装载的二进制与匹配的 Swift 绑定。Web 只消费 HTTP/SSE。先定义身份、整数宽度与单位、UTF-8 标识长度、错误、取消和释放语义；冻结前用非 ASCII 长标识、取消后迟到响应和关闭中回调走通各绑定。历史原型的固定长度标识字段须通过往返验证。

**事件与数据面。** 每个请求有可取消句柄；取消传到底层网络、JS 或媒体任务。下载进度可合并，持久化提交与最终失败携带修订号；酒馆文本增量按会话有序。慢订阅者或 SSE 重连发现缺口时重新取快照。订阅与页面、窗口、宿主寿命绑定。音视频不经 FFI 复制，原生端经随机端口的 127.0.0.1 会话路由消费，每会话生成 24 字节随机令牌并在结束时撤销；NAS 用户的浏览器使用 daemon 同源媒体 URL。封面优先交付原格式文件或受限路由；共享像素须先测复制成本并规定所有者、最大容量和释放线程。

**PlatformHost。** 按浏览器会话、密钥存储、系统调度／通知、文件访问拆分能力。逐项声明线程、是否需要可见窗口、后台可用性、取消及宿主销毁后的结果。调用宿主前释放数据库事务与引擎锁。宿主只回传本源、本用途、本代数的结果，核心裁决 Cookie 写入。验证与登录限制在声明域；游戏使用持久作品 Profile，键为 source、NUL、storageId 的 UTF-8 字节串的 SHA-256；网页视频使用 UUID 临时 Profile 并在结束后清理。受支持的无感交互限定于已隔离 WebView 的局部输入；平台能力受限时保留同一会话的用户验证入口。按原请求的同源、只读、可重放条件恢复并验证业务结果。[运行时](../assets/runtime/park_runtime.js) · [游戏标识](../lib/ui/game/online_game_target.dart) · [网页视频 Profile](../android/app/src/main/kotlin/com/hentaipark/hentai_park/WebVideoProfiles.kt)

## 兼容契约与故障判定

### 插件、网络和诊断

- 固定基线 101 份脚本、索引、park_runtime.js、public-contract.json 的摘要，原样运行。对每个插件按所声明能力比较旧宿主与新引擎在同一脱敏输入上的有序结果、错误和副作用次数。覆盖 URL／URLSearchParams、HTML 选择器与节点操作、编解码、定时器、微任务、密码学与 Cookie 桥、取消及异常。逐源隔离，限制执行时间、内存和池容量，检测晚到回调；`persist(..., true)` 完成意味着状态已经落盘。
- 对照原运行时已实施的浏览器回退，给每次重试指定唯一所有者；登录、反搜上传、原站发送和资源回复解锁保持用户确认语义。源业务规则全部留在插件。保护 TLS 主机名、SNI、connectAddress 的主机绑定、重定向后的凭据剥离、禁止 HTTPS 降级；在实际连接及跳转上验证公网地址，覆盖 Fake-IP、NAT64 和禁止的本地地址。Cookie 保留域、路径、属性及原有效期；清除会话递增代数，使在途旧响应失效。[插件协议](SOURCE_API.md) · [地址判定](../lib/engine/public_media_address.dart)
- 索引区分 sources、reverse-search、metadata 三类插件与 tag-translations 词表。核对来源、版本、摘要、撤回记录、安装中断和同名第三方插件保护。以共享运行时执行离线差分，再用真实请求记录分页、搜索、详情、图片实际解码或媒体播放；外站不可用单列原因。
- 八语言界面资源、占位符、插件固定文案与远端内容分别处理。繁简表在 [assets/search](../assets/search/TSCharacters.txt)。屏蔽沿用旧作用域、regex:、通配符、标题边界、预设与别名，比较同一批旧规则的命中集合。[屏蔽规则](../lib/core/block_rule.dart)
- 自动诊断沿用固定模板和字段白名单，覆盖 Rust、宿主、媒体代理、HTTP 日志和 worker 默认输出。用演示敏感值检查无账号、Cookie、令牌、原始异常、内容、签名 URL 或本机路径泄漏。[诊断实现](../lib/core/diagnostics.dart)

### 数据与恢复

| 操作 | 可观察结果 |
| --- | --- |
| 原地覆盖 | 既有库、JSON、Cookie、游戏 Profile、任务和本机文件继续从旧身份与旧路径访问。区分已过期凭据与升级导致的会话丢失。 |
| 默认手动／自动 .parkbak | 旧新两端互读 v1 Gzip JSON，保留书库、进度、标注、订阅、设置、酒馆资源原字节和会话引用。默认排除站点凭据，自动备份排除凭据；离线媒体、游戏浏览器数据、设备成年确认及 AI 配置／密钥均排除。文件未加密。 |
| 显式含凭据备份 | 按旧选项恢复站点 Cookie、Token、插件私有数据与站点验证状态。校验声明域，保留未安装源的配置和有效期。远端设备／IP 绑定可能要求重新验证。设备本地导出目录保留本机选择。 |
| 单作品游戏存档 | 仅传输 localStorage。导入前校验站点、游戏与 origin，保存现有数据，实际写入前再次核对页面 origin；写入失败恢复原值。IndexedDB 与游戏缓存留在作品 Profile。 |

数据库比较主键、空值、单位、原始资源字节、索引和关联；备份做旧→新→旧及反向往返，验证同 ID 酒馆冲突副本及引用重映射。原样资产用摘要比对，SQLite 页布局及 Gzip 压缩表示允许不同。漫画页和视频位置各自比较时间戳，仅严格较新时覆盖；已读状态比较两组时间戳中的最近动作。覆盖空值、相等、一新一旧、主动回退、重复导入。[合并实现](../lib/library/progress_merge.dart) · [备份范围](DEVELOPMENT.md)

恢复先验证日志路径与数据，写入 backup_restore.json，保存集合内的 JSON 与 Cookie，再提交库内 restore_checkpoints 标记。中断后标记匹配只清日志，防止覆盖提交后的新设置；未提交恢复 before。磁盘满、访问被拒、WAL 未合并和恢复中再次中断均需验证。区分格式损坏与 I/O 失败；删除下载保留待处理范围和可重试状态。[恢复事务](../lib/library/restore_transaction.dart)

### 媒体与资源生命周期

- 直链按 Range 缓存缺口，测试 seek、取消、上游忽略 Range 与会话撤销。HLS 处理主／媒体清单、独立音轨、初始化段、内联密钥、AES-128、roUd 解包及解压限额、CDN 回退和签名刷新。离线内容缺失反馈到具体资源。
- 纯 Rust TS→fMP4 以原 Media3 输出和旧窗口算法为对照。基线窗口并行上限 2、最多前视 4 窗、约 20 秒、热缓存 24 MiB。检查关键帧、初始化段、PTS/DTS、音画同步、远跳后首帧、取消旧窗口及离线 MP4 正常完结。样本包括时间戳回绕／不连续、缺音轨、独立音轨、密钥变更和坏段。分别在 ExoPlayer、AVPlayer、Windows 和浏览器验证播放与 seek。[窗口调度](../lib/video/hls_windows.dart) · [旧封装器](../android/app/src/main/kotlin/com/hentaipark/hentai_park/MediaRemuxer.kt)
- 图片按可见、预读、后台调度，复用并提升同一在途请求的优先级，最后一个消费者退出才释放共享任务。覆盖懒解析、明密文混合、AES、条带重组、切边、缓存分区和解码失败。CBZ 保留页序与 ComicInfo.xml，PDF 验证分卷；离线包检查身份与文件完整性。

每项按真实入口、取消、失败、返回及再次进入验收。所属分区逐个登记；排行榜、资料、反搜是专门入口。完整尺寸和手势以[Android 准则](design/ANDROID.md)为准，共同行为见[设计准则](DESIGN.md)。

| 分区 | 必须保持的任务与状态 |
| --- | --- |
| feed、other | 文章／帖子按原序混排文字、图和视频；访问任一附件可浏览其余附件，切出停止视频，保留正文选择与原站操作确认。 |
| gallery、illustration、doujin | 主页与站内布局分开，保留 LTR／RTL、双页、条漫整体缩放、音量键、翻页热区、离线缺页反馈及分卷导出。 |
| anime、jav、adult、recording | 换集／线路保留音量及静音。菜单保留播放，完整页面覆盖后释放并恢复；长按临时倍速，亮度、音量、进度手势与网页兜底分别验证。 |
| shortvideo、aiDrama | 清屏保留实例与进度，快速滑动将准备和销毁中的资源计入额度。漫剧吸附后切集，新集稳定播放两秒后释放旧集，缓冲、暂停或后台期间不计时。 |
| live | 无点播倍速和 seek；弹幕只读，尊重显示区域及减少动态效果。离页／后台继续录制，停止后可分卷回放。 |
| asmr | 只拼接点击时已加载的同级曲目；后续分页失败可局部重试。按曲读取时长与 LRC/VTT/SRT，全部时长已知才允许精确总轴；跨曲保留暂停意图，锁屏通知遵守隐私与应用锁。 |
| novel | 原文 UTF-16 偏移跨字号恢复书签、批注和进度；覆盖代理对、组合字符、RTL、原文／译文／双语、TTS 和字体变化。 |
| tavern | CCv2／CCv3 PNG 与 JSON、角色快照、候选、分支、部分生成和滚动意图。世界书默认一轮，开启递归最多 32 轮；核对深度、概率、预算、优先级和最终顺序。AI 请求使用独立客户端和安全密钥存储。 |
| onlineGame、game | 区分 HTML 游戏、Ruffle、资源回复解锁和无凭据外部下载。同站两个游戏各自保留存档，离页、后台和应用锁释放按下的虚拟键。 |

跨分区检查发现会话与滚动恢复、IME 组词、多语言检索去重、动态筛选、链接／番号、榜单／元数据、反搜裁剪与后续候选、三方源安装与账号切换失效。本地收藏、原站收藏、订阅、历史和下载独立。下载支持三级并发、暂停／续传、离线包、删除失败重试；分别验收书库更新筛选与章节自动下载、订阅租约防重入及通知去重。Android 应用更新检查包名、签名、大小、版本及摘要。

| Web | TypeScript、React 19 PWA、Rust daemon 与按需浏览器 worker。桌面侧栏、移动四根状态保活、深链接和可信返回。[Web 准则](design/WEB.md) | 验证旧 Web JSON 数据接管、服务端与客户端文件边界、本机及异机浏览器同源媒体、SSE 重连、多标签登出。Service Worker 仅缓存静态资源，断线明确哪些操作可用。 |

五端遵循同一领域语义，各自记录操作结果、系统／宿主版本和已知限制。移动端全量对照存在平台缺口时保留未通过项；渲染验收同时覆盖正常屏幕＋默认字体和窄屏＋大字体，并覆盖八语言、RTL、读屏、焦点和减少动画。性能结论附目标设备与旧版对照。先签收 M1，再依次签收底座契约、Android 全量行为和其他四端；旧实现保留至用户资产接管与各端验收完成。
