# دليل تطوير المكونات الإضافية المصدر

كل أصل HentaiPark هو ملف JavaScript منفصل. تقوم التطبيقات بتحميلها في وقت التشغيل: يمكن تثبيتها وتحديثها وتمكينها/إلغاء تنشيطها من مستودع المصدر دون إعادة ترجمة التطبيق.
يقع المصدر المدمج في [`assets/sources/`](../../../assets/sources/) ويمكن استخدامه مباشرة كمرجع نموذجي.

## بيئة التشغيل

- يعمل البرنامج النصي المصدر في WebView بدون رأس داخل التطبيق (JS حديث كامل مع `DOMParser`). يتم توفير كل من الشبكات والتشفير وملفات تعريف الارتباط من خلال الطبقة الأصلية، لذلك لا توجد قيود على CORS.
- يمكن أيضًا تشغيل نفس وقت التشغيل ([`assets/runtime/park_runtime.js`](../../../assets/runtime/park_runtime.js)) في Node، ويمكنك إجراء اختبار الدخان مباشرةً على الموقع الحقيقي أثناء التطوير:

  ```bash
  cd tools/source-runner && npm install
  node ../../test/source-runner/smoke.mjs nhentai.js --keyword "tag:\"full color\""
  ```

  `smoke.mjs` ملف اختبار محلي في `test/source-runner/` ولا يُوزّع مع المستودع. يختبر كل قائمة (بما فيها الصفحة الثانية)، والبحث، والأعمال العشوائية، والتفاصيل، والأغلفة، والفصول، وتنزيل صورتي الصفحة الأولى والأخيرة.

## تسجيل المصدر

```js
Park.register({
  key: 'mysite',              // المعرف الفريد، لا يمكن تغييره بعد التثبيت
  name: 'Example Source',
  version: '0.0.1',           // عندما يكون رقم الإصدار الموجود في المستودع أعلى، سيطالبك التطبيق بالتحديث.
  type: 'comic',              // comic | video
  color: '#E5355F',           // لون العلامة التجارية: يستخدم لبطاقات الدخول المصدر وألوان موضوع الصفحة المصدر
  description: 'Example source description',
  homepage: 'https://example.com',
  domains: ['example.com'],                   // لمعرفة الموقع الذي ينتمي إليه، راجع "العزل والأمن"؛ إذا تم حذفه، فسيتم استخلاصه من عنوان مثل الصفحة الرئيسية.
  linkPatterns: ['example\\.com/g/(\\d+)'],   // يستخدم للوصول المباشر عند لصق الروابط في عمليات البحث المجمعة؛ المجموعة الأولى هي معرف العمل
  idPattern: '^(\\d+)$',                      // يستخدم للوصول المباشر عند إدخال الرقم مباشرة
  imageHeaders: { Referer: 'https://example.com/' },  // يتم حمله بشكل افتراضي عند تحميل الأغلفة والصور
  network: { mode: 'native' },                // راجع قسم "الشبكة".

  settings: [ /* option definitions */ ],
  account: { /* optional account */ },
  defaultFeed: 'ranking',                     // تم إدخال التسمية افتراضيًا عند فتح الصفحة الأصلية (ادخل في الخلاصات)
  feeds: [ /* browse tabs */ ],
  searchFilters: [ /* search filters */ ],
  searchHint: 'Search by title or tag',

  async init() {},                            // اختياري: يتم الاتصال به مرة واحدة عند التحميل (على سبيل المثال، تحديث قائمة أسماء النطاقات)
  async onSettingsChanged() {},               // اختياري: يتم استدعاؤه بعد قيام المستخدم بتعديل إعدادات المصدر

  async feed(key, { page, cursor, options }) {},
  async search({ keyword, page, cursor, filters }) {},
  async random() {},                          // إرجاع معرف العمل
  async detail(id) {},
  async chapter(id, chapterId) {},            // كاريكاتير
  async resolveImage({ id, chapterId, index, token, retry }) {},  // اختياري: تأخير تحليل الصور
  async thumbnails(id, page) {},              // اختياري: قم بتحميل الصور المصغرة للمعاينة في الصفحات
  async videos(id) {},                        // فيديو
});
```

في الطريقة، يمكنك استخدام `this` للوصول إلى:

| الأعضاء | الوصف |
|------|------|
| `this.http` | `request(opts)`, `get(url, opts)`, `post(url, opts)`, `text(url, opts)`, `json(url, opts)` |
| `this.config` | القيمة التي حددها المستخدم في إعدادات المصدر (`default` إذا لم يتم تعيينها) |
| `this.store` | تخزين قيمة المفتاح المستمر: `get(key, fallback)` / `set(key, value)`، يستخدم لحفظ الرمز المميز وقائمة أسماء النطاقات وما إلى ذلك؛ `await flush()` يؤكد نجاح الكتابة على القرص، ويعطي خطأ إذا فشلت |
| `this.cookies` | `get(url)` / `set(url, {name: value})` / `clear(url)` |
| `this.log(...)` | اكتب إلى "سجل التشغيل" الخاص بالتطبيق |

الأدوات العالمية:

| أدوات | تعليمات |
|------|------|
| `Park.html.parse(text)` | معيار الإرجاع `Document` ، يمكنك استخدام `querySelector` |
| `Park.html.text(node)` / `unescape(s)` / `strip(html)` | معالجة النصوص |
| `Park.crypto.md5Hex(text \| text[])` | MD5، يمكنك تمرير المصفوفات لحساب الدُفعات |
| `Park.crypto.sha256Hex` / `hmacSha256Hex(key, text)` / `aesEcbDecrypt(base64, key)` / `uuid()` | التنفيذ الأصلي، سريع |
| `Park.utils.rateLimiter(ms)` | إرجاع `wait()`، مما يضمن الحد الأدنى للفاصل الزمني بين طلبين |
| `Park.utils.mapLimit(items, n, fn)` / `lruMap(n)` / `parseCount('1.2万')` / `formatDate(ts)` | أدوات أخرى شائعة الاستخدام |
| `Park.error(code, message)` | يلقي خطأ مع رمز الخطأ، انظر أدناه |

### `http.request(opts)`

```js
await this.http.request({
  url, method: 'GET', headers: {}, params: { q: 'x' },   // سيتم ربط المعلمات في عنوان URL
  json: {...} | form: {...} | body: 'raw',
  timeout: 15000,
  responseType: 'text' | 'base64',
});
// → { status, headers, body, url, ok, json() }
```

`text()` / `json()` سوف يلقي خطأ تلقائيًا (404 → `NOT_FOUND`) عند مواجهة استجابة غير 2xx. يتم حفظ ملف تعريف الارتباط تلقائيًا ويستمر عند اتباع عمليات إعادة التوجيه.

## بنية البيانات

**صفحة القائمة** (قيمة الإرجاع `feed` / `search`)

```js
{
  items: [WorkItem], page: 1, totalPages: 20, total: 500,
  hasNext: true,
  cursor: '12345',        // اختياري: المواقع التي يقلب فيها المؤشر الصفحات (مثل E-Hentai) تعرض مؤشر الصفحة التالية، وسيعيدها التطبيق كما هو في المرة التالية التي يقدم فيها طلبًا.
}
// أو تخطيط القسم (عندما يكون تخطيط الخلاصة عبارة عن "أقسام"):
{ sections: [{ title: 'Latest chapters', items: [WorkItem] }], hasNext: false }
```

**عنصر العمل**: `{ id, title, subtitle?, cover, coverAspect?, pages?, rating?, likes?, views?, language?, category?, badge?, badgeColor?, duration?, uploaded?, tags? }`

- `coverAspect` (العرض / الارتفاع) يقوم بعمل تخطيط الشبكة قبل تحميل الصورة لتجنب القفز.
- `badgeColor` اللون المستخدم لتسميات الفئات (على سبيل المثال، E-Hentai نظام الألوان التقليدي لكل فئة).

**التفاصيل** (`detail`): جميع حقول عنصر العمل، بالإضافة إلى ذلك:

```js
{
  url, authors: [], description, uploader?, size?, comments?,
  tags: [{ namespace: 'artist', label: 'Author', tags: [{ name, keyword, filters?, count? }] }],
  chapters: [{ id, title }] | null,   // null يمثل فصلًا واحدًا
  singleChapterId?,                   // معرف الفصل المطلوب لعمل فصل واحد (مثل "1" لـ Bika)
  thumbnails?: [url | {url, width, height, offsetX, offsetY}],   // دعم صورة العفريت
  related?: [WorkItem], series?: [WorkItem],
}
```

عند النقر على علامة ما، يبحث التطبيق عن `keyword` و`filters` في المصدر، بحيث يمكن تعيين العلامة إلى بناء الجملة الأصلي للموقع (على سبيل المثال، `artist:"xxx"`) أو معلمات التصفية (على سبيل المثال. Hanime1 من `tags[]`).

**الفصل** (`chapter`)

```js
{ pages: [
  { url, headers?, fallbacks?: [url], width?, height?, transform? },  // العنوان معروف
  { token: '12' },                                                      // القرار المتأخر: سوف يقوم التطبيق باستدعاء ResolveImage
]}
```

- `fallbacks`: مرآة احتياطية، حاول بالتسلسل عند فشل العنوان الأساسي.
- `transform: { type: 'unscramble-strips', segments: N }`: عندما يتم قص الصورة إلى شرائح N أفقيًا وتخزينها بترتيب عكسي (JMComic)، ستتم استعادة التطبيق محليًا على وحدة معالجة الرسومات. يحفظ الملف الذي تم تنزيله دون اتصال الصورة الأصلية ويستعيدها عند عرضها.
- `resolveImage` يُرجع `{ url, headers?, width?, height?, cacheKey? }`. عندما يفشل، سيقوم التطبيق بزيادة `retry` ويتصل مرة أخرى، ويمكن للمصدر استخدام هذا لتغيير الخادم (`nl` معلمة E-Hentai).

**الفيديو** (`videos`): `[{ quality: 1080, label: '1080P', url, headers?, preferred? }]`. عادةً ما يكون لروابط الفيديو المباشرة حد زمني، وسيقوم التطبيق بإعادة الحصول عليها في كل مرة قبل التشغيل/التنزيل.

## تعريف الخيار

`feeds[].options`، `searchFilters`، `settings` استخدم نفس التنسيق:

```js
{ key: 'sort', label: 'Sort', type: 'select', default: 'date',
  values: [{ value: 'date', label: 'Latest' }, { value: 'popular', label: 'Popular', color: '#f00' }] }
// type: select (اختيار واحد) | multi (اختيارات متعددة) | number | text | password | switch
// داخل settings يمكن استخدام options بدلًا من values.
```

كل عنصر في `feeds` هو علامة تبويب في الصفحة المصدر: `{ key, label, layout?: 'grid' | 'sections', options?: [...] }`.

`defaultFeed` يحدد علامة التبويب التي سيتم ادخالها افتراضيا عند فتح الصفحة الأصلية. عندما لا يتم ملء المفتاح المقابل أو لا يمكن العثور عليه، سيحدد التطبيق تلقائيًا وفقًا للمفتاح بترتيب التوصية > التصنيف > الشائع (يتضمن المفتاح `promote` / `recommend` / `featured`، وبعد ذلك `rank` / `toplist`، ثم `popular` / `hot` / `trending`)، إذا لم يكن كذلك، أدخل الأول التسمية.

## شبكة

- `network.mode: 'native'` (افتراضي): يمكن لطلب HTTP الأصلي، باستخدام ملفات تعريف الارتباط الدائمة، المرور عبر الوكيل الذي قام المستخدم بتعيينه. إذا تم اكتشاف الاستعلام Cloudflare، فسيتم طرح `CLOUDFLARE`. سيقوم التطبيق بتوجيه المستخدم لإكمال عملية التحقق في المتصفح المدمج ومزامنة ملف تعريف الارتباط المشترك مرة أخرى مع الطلب الأصلي.
- `network.mode: 'browser'`+`network.origin`: تم الطلب بأصل `fetch()` في صفحة متصفح مخفية مفتوحة على `origin`، ببصمة متصفح حقيقية. ينطبق على Cloudflare المواقع التي تتمتع بحماية أكبر (على سبيل المثال Hanime1).

## العزلة والأمن

- يعمل كل مصدر في بيئة JS **مستقلة** (لكل منها WebView بدون واجهة)، ولا يمكن للمصادر رؤية الكائنات العامة لبعضها البعض؛ يتعرف الجسر الأصلي فقط على البيئة التي يأتي منها الاستدعاء، ولا يمكن للنصوص البرمجية انتحال صفة المصادر الأخرى.
- يحتوي كل مصدر على جرة ملفات تعريف ارتباط مستقلة: الطلب الصادر عن المصدر سيجلب ويحفظ ملف تعريف الارتباط الخاص به فقط، ولن يقرأ حالة تسجيل الدخول للمصادر الأخرى.
- `domains` يعلن عن الموقع الذي ينتمي إليه المصدر (يمكن تسجيل اسم النطاق، ويتم تضمين اسم النطاق الفرعي تلقائيًا). ستتم مزامنة ملفات تعريف الارتباط من هذه المواقع فقط مع المتصفح المدمج (مشتركة بواسطة مصادقة Cloudflare وتسجيل الدخول عبر الويب)، ويجب أن تنتمي إليها أيضًا `network.origin` في وضع المتصفح. عند الحذف، استنتج من `homepage`، `network.origin`، `account.cookieUrl/loginUrl`.
- عند تثبيت المصدر من موقع ويب أو مستودع، سيقوم التطبيق أولاً بقراءة معلومات البرنامج النصي في وضع الحماية الذي لا يمكن توصيله بالإنترنت، ويعرض الاسم والإصدار وSHA-256 والموقع المعلن وتحذير المخاطر للمستخدم، ثم تثبيته بعد التأكيد. يمكن أن يحتوي الإدخال `index.json` في المستودع المصدر على الحقل `sha256`، وسيتم رفض التثبيت إذا كان محتوى التنزيل غير متطابق.

## الحساب

```js
account: {
  type: 'password' | 'cookies',
  title, hint, required: false,
  fields: [{ key: 'email', label: 'Email' }, { key: 'password', label: 'Password', secret: true }],
  loginUrl?, cookieUrl?, requiredCookies?: ['ipb_member_id'],   // وبعد تقديمه، يمكنك تسجيل الدخول إلى صفحة الويب وسيحصل التطبيق تلقائيًا على ملف تعريف الارتباط.
  async login(values) { return { name } },
  async logout() {},
  async status() { return { loggedIn, name, configured } },
  managedAccount: true,                 // اختياري: توفير حساب صيانة تلقائي مخصص
  async enableManaged() {},             // يتم الاتصال به فقط بعد تأكيد المستخدم للتسجيل
}
```

يشير `configured` إلى أنه تم تكوين الحساب، بغض النظر عما إذا كانت عملية تسجيل الدخول الحالية ناجحة أم لا. `managedAccount: true` يعلن أن المصدر يدعم حساب صيانة تلقائية مخصص؛ تستخدم إعدادات المصدر المفتاح `managedAccount` الذي يحمل نفس الاسم. يجب على المضيف أولاً عرض تعليمات التسجيل التلقائي والحصول على تأكيد المستخدم قبل حفظ إعدادات التمكين والاتصال بالرقم `account.enableManaged()`. يجب حفظ بيانات اعتماد المرشح واستخدام `await this.store.flush()` قبل التسجيل للتأكد من إمكانية استعادة نفس الحساب بعد الفشل أو إعادة تشغيل التطبيق.

مثال PicACG يحفظ بيانات الاعتماد اليدوية والحسابات المخصصة بشكل منفصل، ويجب عدم استبدال الحسابات اليدوية الحالية بحسابات مخصصة. قم بإيقاف تشغيل المفتاح للاحتفاظ بالحساب المخصص وتشغيله مرة أخرى لإعادة استخدامه؛ إذا انتهت صلاحية الرمز، يمكنك فقط تسجيل الدخول مرة أخرى وعدم التسجيل مرة أخرى. بعد فشل التسجيل أو فقدان الاستجابة، أعد محاولة حساب المرشح الأصلي لتجنب إنشاء حسابات زائدة عن الحاجة. كلمة مرور الحساب والرمز المميز وحالة المصدر كلها بيانات محلية للمستخدم. لا تقم بإخراج بيانات الاعتماد الحقيقية في المستندات والسجلات.

## التدويل

دعم واجهة التطبيق `zh-Hans`، `zh-Hant`، `ja`، `ko`، `en`، `es`، `ru`، `ar`. تستخدم عناصر التحكم في المواد والكوبرتينو والنظام اللغات المقابلة؛ الواجهة العربية تنتقل من اليمين إلى اليسار. يصبح إعداد لغة الواجهة ساري المفعول على الفور ويتم حفظه باستمرار. وهو يتبع النظام بشكل افتراضي؛ تحدد النصوص والمناطق الصينية ما إذا كان سيتم استخدام اللغة الصينية المبسطة أو التقليدية.

تستدعي واجهة Flutter بشكل موحد `tr('已选 {count}', {'count': count})` أو `context.tr`. يتم استخدام النص الصيني الأصلي للرسالة كمفتاح المورد، والمعلمة هي `{name}`، ويقع المورد بثماني لغات في `assets/i18n/`. عند إضافة نسخة مرئية أو تعديلها، يجب تحديث جميع الموارد في وقت واحد ويجب أن تكون العناصر النائبة متسقة. يتم تعيين الاسم الثابت والوصف وتسمية التصفح والخيارات ومطالبات الخطأ الخاصة بالمكون الإضافي عند عرض التطبيق؛ يظل العنوان والمؤلف والعلامة وإدخال المستخدم ومفتاح بروتوكول الاستمرارية للعمل عن بعد هو النص الأصلي.

## رمز الخطأ

استخدم `throw Park.error(code, message)` لإلقاء خطأ، وسيوفر التطبيق إرشادات مقابلة بناءً على رمز الخطأ:

| كود | معالجة التطبيق |
|------|-----------|
| `CLOUDFLARE` | زر "الانتقال إلى التحقق": افتح المتصفح المدمج |
| `LOGIN_REQUIRED` | زر "الانتقال إلى تسجيل الدخول": افتح منطقة الحساب في إعدادات المصدر |
| `NOT_FOUND` | عرض "المحتوى غير موجود" |
| `BLOCKED` | يعرض "الوصول مقيد" (مثل IP محظور، استنفاد الحصة)، لن تتم إعادة محاولة الصورة |
| `NETWORK` / `HTTP` / `PARSE` | عرض رسالة خطأ مع زر "إعادة المحاولة" |

## مستودع المصدر

المستودع هو `index.json`، والذي يمكن وضعه على أي استضافة ثابتة (مثل GitHub الخام):

```json
{ "name": "Example source repository", "sources": [
  { "key": "mysite", "name": "Example Source", "version": "0.0.1", "type": "comic", "file": "mysite.js", "description": "…" }
] }
```

`file` هو المسار المتعلق بـ `index.json` (يمكنك أيضًا كتابة `url` بالكامل). يمكن للمستخدمين التصفح والتثبيت والتحديث عن طريق إدخال عنوان المستودع في "إدارة موقع المصدر → إضافة مصدر".

عندما يواجه حساب الصيانة التلقائية فشلاً، يجب حفظ عدد مرات الفشل ووقت إعادة المحاولة التالي وإعادة المحاولة عند الفاصل الزمني للتراجع؛ لا يُسمح بالتسجيل المتكرر أو تسجيل الدخول خلال فترة الحد الحالية. سيظل المستخدمون الذين يعيدون المحاولة بنشاط يعيدون استخدام الحساب الأصلي ولا يمكنهم تخطي الحد الحالي من جانب الخادم.
