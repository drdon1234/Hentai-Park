## 中文

### 改进
- 吃瓜、创作社区和小说的聚合搜索预览统一横向排列，小说使用书本样式。
- 搜索作品资料新增通用搜索栏，资料搜索与资源站点搜索明确分开。

### 修复
- 修复 Fake-IP 模式下 IPv6 地址被误拦截导致媒体加载失败的问题。
- 修复换源迁移中混入资料站点的问题。
- 修复大字体下小说书本占位标题显示不完整的问题。

### 插件更新
- 每日大赛、黑料网、51吃瓜网 0.0.5：完善文章标题识别，修复每日大赛部分旧作品加载失败的问题。

## English

### Improvements
- Unified aggregate search previews for gossip articles, creator communities and novels into horizontal rows, with book-style cards for novels.
- Added a shared search field for work information and separated metadata searches from resource-site searches.

### Fixes
- Fixed media loading failures caused by incorrectly blocking IPv6 addresses in Fake-IP mode.
- Fixed metadata sites appearing as targets when migrating works between resource sites.
- Fixed incomplete placeholder titles on novel book cards with large text sizes.

### Plugin updates
- MRDS, Heiliao and 51CG 0.0.5: improved article title detection, fixing loading failures for some older MRDS works.
