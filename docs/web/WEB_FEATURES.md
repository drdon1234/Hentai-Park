# HentaiPark Web 功能详细设计

> 本文是 [Web 设计准则](../design/WEB.md) 的功能细化文档。[Web 设计准则](../design/WEB.md) 负责产品边界、架构基线和跨功能原则；本文负责页面、交互状态、异常处理、权限边界、API 依赖和功能验收。

## 1. 功能设计规则

### 1.1 状态分层

所有功能至少区分以下状态：

- 初始加载；
- 空结果；
- 正常内容；
- 部分成功；
- 完全失败；
- 需要登录；
- 需要站点验证；
- 网络离线；
- 权限不足；
- 操作提交中；
- 操作成功；
- 操作失败且可重试。

页面状态来自服务端事实。浏览器本地状态只能保存输入草稿、视图偏好、滚动位置和未提交表单，不得伪造收藏、下载、订阅或任务完成状态。

### 1.2 操作反馈

- 写操作必须显示进行中状态，并防止同一控件重复提交。
- 成功状态使用可被屏幕阅读器读取的 `aria-live` 提示。
- 可重试失败必须提供重试入口，并保留用户输入和当前筛选。
- 需要登录或验证时，页面说明原因、目标站点和下一步操作。
- 危险操作需要确认，但取消确认不能改变原状态。
- 服务端拒绝必须展示稳定错误码对应的用户文案，不直接展示内部堆栈。

### 1.3 数据和权限边界

- 所有业务数据通过 `/api/v1` 访问。
- 页面不读取 SQLite、插件文件、Cookie 或下载目录。
- 临时媒体地址、验证页和反搜上传内容不进入普通持久化缓存。
- 单用户实例内多个标签页共享服务端状态，不建立第二套用户权限模型。
- 站点能力由 manifest 和 API 返回决定，页面不能按站点名称硬编码能力。

## 2. 应用壳和全局交互

### 2.1 全局导航

一级入口：发现、搜索、书架、下载、订阅、站点、设置。

每个入口必须是可复制、可新标签页打开的真实链接。当前入口通过 URL 和可访问名称表达，不能只依赖颜色或图标。

全局工具栏提供：

- 全局搜索入口；
- 当前任务摘要；
- 网络状态；
- 主题和语言入口；
- 当前实例状态；
- 移动端“我的”入口。

### 2.2 全局错误和通知

错误通知按严重程度分为：

- 页面内错误：影响当前内容读取；
- 操作错误：单次写操作失败；
- 任务错误：后台下载、订阅或安装失败；
- 实例错误：数据库、worker 或插件宿主不可用。

通知必须包含：发生了什么、是否影响已有数据、是否可重试、重试按钮或前往详情入口。

### 2.3 会话和首次启动

Local 模式首次启动显示实例初始化状态，完成数据库迁移、worker 启动和默认设置后进入发现页。

Server 模式首次访问显示认证入口。认证成功后建立 HttpOnly 会话；会话过期时保留当前 URL，完成认证后返回原页面。登录失败不泄露账号是否存在。

## 3. 发现与搜索

### 3.1 发现页

路由：`/discover`

内容顺序：

1. 全局搜索；
2. 继续阅读或观看；
3. 分类和榜单；
4. 内容货架；
5. 站点健康状态；
6. 订阅更新和下载摘要。

状态要求：

- 没有历史时显示继续探索入口；
- 单个货架失败不阻塞其他货架；
- 站点需要登录、验证、限流和停用必须分别显示；
- 失效封面使用媒体类型占位，不显示浏览器破图图标。

API 依赖：`GET /api/v1/discovery`、`GET /api/v1/sources`、`GET /api/v1/history`、`GET /api/v1/downloads`、`GET /api/v1/subscriptions`。

### 3.2 搜索

路由：`/search?q=...&scope=...&source=...&filters=...&view=...`

搜索范围：作品、标签、番号、链接、站点资料。搜索必须由用户明确提交，输入变化不自动发起完整请求。

交互要求：

- 提交后写入 URL 历史；输入草稿不写入历史；
- 支持取消当前请求；
- 新请求拥有递增请求代次，迟到结果丢弃；
- 支持网格、列表、站点分组；
- 支持清空条件和恢复最近一次搜索；
- 支持分页或游标加载；
- 无结果、部分站点失败、需要登录和需要验证分别显示。

API 依赖：`POST /api/v1/search`，响应必须包含请求代次、分页游标、来源状态和稳定错误码。

### 3.3 图片反搜

入口位于发现页和搜索页。支持拖放、文件选择和粘贴图片；不支持拖放时回退到文件选择器。

规则：

- 上传前显示文件类型和大小校验结果；
- 上传内容默认只在当前会话中使用，不进入普通缓存和诊断日志；只有用户明确点击保存查询图片时，才作为独立可删除的私有历史保存（最多20条），无痕时禁止。载回图片后仍由用户点击重新搜索；
- 上传、解析、结果加载和失败分别显示；
- 取消后释放上传请求和临时资源；
- 站点不支持反搜时隐藏入口或显示能力说明。

API 依赖：`POST /api/v1/reverse-search`。响应只返回本次请求的结果和临时资源引用，不写入普通持久化缓存。

## 4. 站点和插件管理

### 4.1 站点列表

路由：`/source/:sourceKey` 以及站点管理入口。

列表显示：名称、图标、类型、启用状态、登录状态、验证状态、能力徽章、健康状态和最近更新时间。

状态：在线、需要登录、需要验证、暂时失败、已停用、更新中、更新失败。

### 4.2 站点详情和目录

站点目录由 manifest 的 `browseLayout` 和能力声明决定：grid、list、文章流、帖子流或原站真实目录。

页面必须支持：

- 面包屑和返回；
- 站点内搜索；
- 站点筛选和排序；
- 游标分页；
- 站点能力提示；
- 原站入口；
- 部分结果失败和重试。

### 4.3 安装、启停、更新和回滚

安装流程：选择来源、显示 manifest 摘要、校验版本和 SHA-256、显示权限、确认安装、显示进度、完成或回滚。

更新流程：显示当前版本和目标版本、变更摘要、权限变化和回滚风险；更新失败必须回到上一个可用版本。

启停操作由服务端状态机决定。页面关闭不能取消已提交的安装或更新任务。

API 依赖：`GET /api/v1/sources`、`GET /api/v1/sources/:key`、`POST /api/v1/sources/:key/enable`、`POST /api/v1/sources/:key/update`、事件 SSE。

### 4.4 登录、Cookie 和验证

站点登录属于站点级状态，不等同于 Web 实例认证。页面必须显示目标站点和当前状态，不能把 Cookie 值展示给用户。

需要验证时：

- 显示验证原因和站点名称；
- 提供打开验证流程的入口；
- 验证完成后重新读取站点状态；
- 验证失败保留原页面上下文；
- 不把验证页 HTML 写入普通缓存。

API 依赖：`POST /api/v1/sources/:key/login`、`POST /api/v1/sources/:key/verify`、`GET /api/v1/sources/:key`。

## 5. 作品、章节和阅读

### 5.1 作品详情

路由：`/work/:sourceKey/:workId`

内容：封面、标题、译文、作者、标签、简介、来源、章节、收藏、下载、继续阅读和原站入口。

能力相关操作：

- 无 `chapter` 能力时不显示章节阅读入口；
- 无 `videos` 或 `webVideo` 能力时不显示视频操作；
- 无下载能力时显示原因而不是灰色无效按钮；
- 屏蔽命中默认隐藏，临时显示不修改永久过滤规则。

### 5.2 章节列表

支持按来源顺序显示章节、阅读状态、进度、更新状态和批量下载。

批量操作必须显示选中数量和任务预估。重复提交由稳定资源身份和请求幂等键去重。

### 5.3 漫画阅读器

路由：`/read/:sourceKey/:workId/:chapterId`

支持滚动、翻页、双页、缩放、目录、章节切换、页码、阅读主题、全屏和断点恢复。

状态要求：

- 图片逐页加载，单页失败可单独重试；
- 当前页和总页数可被屏幕阅读器读取；
- 进度节流写入，页面隐藏时再保存一次；
- 刷新后从 URL 和服务端进度恢复；
- 返回操作遵循浏览器历史。

API 依赖：`GET /api/v1/reader/:source/:workId/:chapterId`、`PATCH /api/v1/history/:source/:workId/:chapterId`。

### 5.4 视频和音声

路由：`/watch/:sourceKey/:workId/:chapterId`

视频支持播放、暂停、倍速、字幕、全屏、画中画、选集和播放位置恢复。音声使用紧凑播放条和文本/字幕区域。

异常流程：

- 自动播放被拒绝时显示手动播放入口；
- 签名过期时重新请求媒体，不暴露原始地址；
- Range 或 HLS 分片失败时有限重试；
- 网页视频需要验证时显示验证状态；
- 页面关闭不影响后台下载。

## 6. 书架、历史和进度

### 6.1 书架

路由：`/library`

分区：收藏、历史、继续阅读、最近更新。每个分区支持空状态、筛选、排序、网格/列表和分页。

收藏写入必须：

- 显示提交状态；
- 支持重复点击而不创建重复记录；
- 多标签页同步；
- 服务端拒绝时恢复真实状态。

收藏支持跨站迁移。迁移前搜索目标站点并确认匹配作品；服务端按章节标题或编号进行无歧义匹配，合并分类、阅读/播放进度、历史和小说笔记。存在未匹配的已读或进度记录时保留原收藏，不能报告为已完成迁移。

### 6.2 阅读和播放进度

漫画进度保存页码和页数，视频/音声保存有效时间点和媒体时长。冲突按内容类型使用服务端 `updatedAt` 和有效值规则处理。

进度保存失败不能阻塞继续阅读或播放，但必须提供可重试提示。

## 7. 下载和后台任务

### 7.1 下载列表

路由：`/downloads`

任务显示：标题、来源、章节、variant、状态、进度、速度、文件大小、错误、创建时间和操作。

状态机：

    queued -> running -> paused
    running -> completed
    running -> failed
    queued/running/paused -> cancelling -> cancelled

### 7.2 任务操作

- 暂停只影响允许暂停的任务；
- 取消先写入服务端状态，再处理 worker；
- 失败显示稳定错误码和重试入口；
- 重试创建新的请求幂等记录，但复用稳定资源身份；
- 删除先持久化 deletion intent，再删除文件和数据库状态；
- 页面刷新、关闭或浏览器崩溃不影响服务端任务。

### 7.3 多标签页行为

同一资源的多个下载请求必须在浏览器层和服务端层都去重。一个标签页取消任务，其他标签页通过 SSE 或 BroadcastChannel 收到最终状态。

API 依赖：`GET /api/v1/downloads`、`POST /api/v1/downloads`、`POST /api/v1/downloads/:id/pause`、`POST /api/v1/downloads/:id/resume`、`POST /api/v1/downloads/:id/retry`、`POST /api/v1/downloads/:id/cancel`、`DELETE /api/v1/downloads/:id`、`GET /api/v1/events`。

## 8. 订阅和更新

### 8.1 订阅列表

路由：`/subscriptions`

订阅类型：频道、作者、关键词、作品或站点更新。

列表显示启用状态、检查周期、最近检查时间、最近错误、未读数量和立即检查入口。

### 8.2 创建和编辑

创建前校验目标、站点能力和筛选条件。编辑未提交前不影响已运行订阅。删除需要确认，并说明是否保留历史事件。

### 8.3 首次检查和事件

首次检查建立 baseline，不把历史内容误报为新更新。后续事件必须带稳定 eventId，可重放、去重和标记已读。

网络失败、登录要求和解析失败必须独立显示。事件过期后由客户端执行全量同步。

API 依赖：`GET /api/v1/subscriptions`、`POST /api/v1/subscriptions`、`PATCH /api/v1/subscriptions/:id`、`DELETE /api/v1/subscriptions/:id`、`POST /api/v1/subscriptions/:id/check`、`GET /api/v1/events`、`POST /api/v1/events/read`。

## 9. 设置、备份和诊断

### 9.1 设置

路由：`/settings`

分区：外观、语言、网络、过滤、站点、账号、下载、通知、隐私、快捷键、关于。

未提交表单只保存在当前标签页。保存成功后通过事件通知其他标签页刷新；如果其他标签页有未提交修改，必须显示冲突提示，不能静默覆盖。

API 依赖：`GET /api/v1/settings`、`PATCH /api/v1/settings`。设置写入使用版本校验，冲突返回 `CONFLICT`。

### 9.2 备份和恢复

支持选择是否包含站点设置、账号/Cookie 元数据和下载元数据。临时签名 URL、运行中租约、缓存、反搜上传内容和短期验证 HTML 不进入备份。

导入流程：选择文件、校验 manifest、预览冲突、确认合并、事务导入、显示结果。失败时保留当前数据并提供错误详情和重试入口。

### 9.3 诊断

路由：`/settings/diagnostics` 或设置内嵌页面。

展示 API、数据库、worker、source-runner、browser-worker 和站点健康状态。日志脱敏，不显示 Cookie、Token、签名 URL、AI 密钥和私有内容。

API 依赖：`GET /api/v1/diagnostics`、`POST /api/v1/backup/export`、`POST /api/v1/backup/import`。

### 9.4 年龄确认、应用锁和无痕浏览

首次访问在进入内容页前完成 18+ 年龄确认；确认状态属于当前 Web 实例设置，不写入 URL。应用锁由用户在设置中启用，锁定后只保留认证入口和最小诊断信息。无痕浏览只影响本地历史、最近搜索和阅读位置的持久化，不影响已提交的收藏、下载、订阅和服务端任务。

API 依赖：年龄确认和应用锁使用 `/api/v1/settings` 保存；无痕浏览的未提交状态只保存在当前标签页。

## 10. 跨功能事件和多标签页

跨标签页同步的事件类型至少包括：收藏变化、进度变化、下载状态变化、订阅事件、站点状态变化、设置变化和主题/语言变化。

事件处理规则：

- BroadcastChannel 用于低延迟通知；
- SSE 用于服务端事实和后台任务；
- 数据版本号用于判断是否需要重新读取；
- 重复事件必须安全；
- 事件乱序时按版本和服务端时间判断；
- 关闭标签页不取消后台任务；
- 其他标签页有未提交表单时显示刷新提示。

## 文章与独立相册补齐

article类型使用文章流和顺序正文，browseLayout仍是list/grid。正文文字、解密图片与视频保持顺序；标签进入真实来源标签分页。视频点击时按稳定媒体ID取流，同一页面只保留当前播放器，关闭/切换/离页取消请求。收藏/历史保存作品摘要和块位置，重新加载恢复，不持久化正文或临时媒体URL。

有album能力的站点提供相册入口，站内目录/筛选和搜索可直接打开对应相册；频道相册另提供目标输入。相册不以漫画chapter或已加载帖子代替真实media方法。完整媒体保留原站顺序、稳定ID、work/post展示、受限公开预览、日期闭区间和图片/视频过滤；跨页补媒体合并，空页过滤最多自动继续3页，仍可手动加载，加载/错误/重试/取消与离页释放明确。公共feed-only相册不显示虚构的频道订阅。

双能力视频先原生播放，只有UNSUPPORTED进入受控网页；其他错误保留正常处理入口，下载不回退。支持边界及真实外站条件见ACCEPTANCE.md。
