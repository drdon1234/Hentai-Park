# 실행 로그와 문제 보고

일반 로그는 오류, 자동 재시도, 사이트 호출 결과와 앱 수명 주기를 기록합니다. 설정에서 실행 로그를 새로 고치거나 내보내고 재현 단계와 함께 Issue에 첨부할 수 있습니다.

어려운 문제는 debug 로그를 켜세요. 이번 실행만 켜면 즉시 재현할 수 있고, 다음 시작만 켜면 시작 과정부터 기록합니다. 예약이 적용되면 시작 후 알림이 표시됩니다. debug는 앱 종료 시 꺼지며 예약은 한 번만 적용됩니다.

장기 로그는 기본적으로 꺼져 있으며 시작할 때 최근 실행 기록을 덮어씁니다. 켜면 다음 실행에도 추가 저장하고 100 MiB에 도달한 후 가장 오래된 기록을 삭제합니다. 끄면 실행 기록을 즉시 덮어씁니다. 별도의 충돌 기록에는 영향을 주지 않습니다.

debug는 요청 시간, 재시도, 캐시와 재생 상태를 추가 기록합니다. 계정, Cookie, Token, 본문, 로컬 경로와 전체 서명 링크는 기록하지 않습니다. 화면은 최근 기록을, 내보내기는 보관된 모든 실행 로그를 포함합니다. 익명화 모드는 대상 호스트와 OS 상세 버전도 숨깁니다. 공유 전에 내용을 확인하세요.
