## 中文

### 改进
- 小说推荐改为纵向展示三部作品，改善长标题、简介和大字体下的阅读体验。
- 长视频简介支持展开与收起；短视频标题和简介默认折叠，展开后可滚动，收起按钮保持可见。
- 调整站点设置的信息与分组布局，发现页筛选按“全部、二次元、三次元”排列。

### 修复
- 修复部分图库和游戏站点的图片无法加载的问题。
- 修复 Iwara、HentaiHaven、123AV 和 SOOP 部分视频无法播放的问题。
- 修复 Tik.porn 推荐加载、连续分页和部分视频播放失败的问题。
- 修复 Fansly 登录状态读取、次元茶馆登录识别，以及部分第三方登录按钮无响应的问题。

### 插件更新
- yande.re 0.0.5、Gelbooru 0.0.5、GalgameX 0.0.8：改善图片加载。
- Iwara 0.0.3、HentaiHaven 0.0.2、123AV 0.0.10、SOOP 短视频 0.0.2、SOOP 录播 0.0.2、Tik.porn 0.0.6：修复浏览与播放。
- Fansly 0.0.4、次元茶馆 0.0.7：修复登录识别。

## English

### Improvements
- Show three novel recommendations in a vertical list, improving readability for long titles, descriptions and large text.
- Expand or collapse video descriptions; short video titles and descriptions start collapsed, with scrollable expanded text and an always-visible collapse button.
- Refine site settings information and grouping; order Discover filters as All, 2D and 3D.

### Fixes
- Fix images failing to load on some illustration and game sites.
- Fix playback failures for some videos on Iwara, HentaiHaven, 123AV and SOOP.
- Fix Tik.porn recommendation loading, continuous pagination and playback failures for some videos.
- Fix Fansly session detection, sign-in detection on 次元茶馆, and unresponsive buttons in some third-party sign-in flows.

### Plugin updates
- yande.re 0.0.5, Gelbooru 0.0.5, GalgameX 0.0.8: Improve image loading.
- Iwara 0.0.3, HentaiHaven 0.0.2, 123AV 0.0.10, SOOP Shorts 0.0.2, SOOP Recordings 0.0.2, Tik.porn 0.0.6: Fix browsing and playback.
