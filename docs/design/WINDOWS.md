# Windows 平台设计准则

本文件定义 Windows 桌面客户端（WinUI 3 / Windows App SDK）的视觉令牌、窗口结构、组件规范、键鼠与触控交互及系统集成规则，与[公共设计准则](../DESIGN.md)共同使用。工程结构、构建与持久化契约见 [Windows 开发说明](../windows/DEVELOPMENT.md)、[开发说明](../DEVELOPMENT.md) 与[插件协议](../SOURCE_API.md)。

## 视觉方向与空间材质

- **Fluent 2 骨骼 × 暖调人文表面。** 窗口底座采用暖色调调校的桌面云母材质，内容工作区保持稳定的暖中性实色表面，避免桌面壁纸颜色干扰漫画彩页、写真肤色与视频暗部。不做装饰性渐变或高饱和色块。
- **三层材质海拔：**
  - **L0 窗口底座（标题栏与左侧导航栏）：** 启用系统透明效果时使用暖基底 `Mica Alt`；窗口失焦、系统关闭透明效果或开启高对比度主题时自动回退至纯实色 `Surface`。
  - **L1 内容工作区：** 使用纯实色逐级暖中性表面与 `0.8 epx` 细线（`OutlineVariant`）划分边界。
  - **L2 瞬态浮层（菜单、筛选抽屉、任务看板、浮动阅读控制栏）：** 使用 `Desktop Acrylic` 半透明毛玻璃、细微内描边与局部阴影表达覆盖关系。
- **单一强调色体系：** 与 Android 基线保持一致，默认采用“陶土”（种子色 `#C96442`，暗色提亮为 `#D97757`），提供琥珀、青苔、靛蓝、梅紫、樱粉，以及桌面专属“跟随 Windows 系统强调色”选项。所有强调色均按表面亮度校准，确保小字与实心按钮前景对比度达到 WCAG AA（≥ 4.5:1）。站点品牌色仅用于 `SourceAvatar` 识别来源。

## 令牌

### 颜色

| 角色 | 暗色（默认） | 亮色 |
| --- | --- | --- |
| 窗口基底 `Surface` | `#11100F` | `#F5F3EF` |
| 工作区画布 `WorkspaceSurface` | `#181715` | `#FAF9F6` |
| 卡片与分组表面 `CardSurface` | `#1E1D1A` | `#FFFFFF` |
| 逐级容器（`High` / `Highest`） | `#272522` / `#312F2B` | `#EAE7E1` / `#DCD8D0` |
| 主要文字 `OnSurface` | `#ECE9E3` | `#1F1E1C` |
| 次要文字 `OnSurfaceVariant` | `#A39E94` | `#625E57` |
| 细分隔线 `OutlineVariant` | `#34322E` | `#E0DCD4` |

- 阅读器画布（`ReaderPalette`：纯黑、深灰、羊皮纸、护眼暖光）与画面遮罩（`Scrims`）独立于应用主题；阅读与播放页弹出的设置浮层仍使用应用表面令牌。
- 选中项（导航、筛选胶囊、分段按钮、下拉菜单当前值）统一使用强调色调 `SecondaryContainer` / `OnSecondaryContainer`，不额外绘制勾号或改变控件宽度。

### 字体与排版

- **UI 与元数据无衬线声部：** 使用 `Segoe UI Variable`，并按当前界面语言显式指定 CJK 字体族（简中 `Microsoft YaHei UI`、繁中 `Microsoft JhengHei UI`、日文 `Yu Gothic UI`、韩文 `Malgun Gothic`），避免拉丁字体逐字回退造成笔画混杂。字重最高 `SemiBold (600)`。
- **人文阅读衬线声部（`ParkSerif`）：** 一级页面标题、作品详情主标题、吃瓜文章标题及小说衬线模式使用对应语言的衬线字体（`Source Han Serif` / `Noto Serif CJK` 及系统衬线回退）。
- **技术等宽声部（`ParkMono`）：** 作品番号角标、SHA-256 校验值、Cookie/会话输入框及运行诊断日志使用 `Cascadia Mono` / `Consolas`。
- **文字选择边界：** 按钮、导航项、筛选胶囊与列表操作禁用文字选择；仅在详情简介、文章正文、小说内容、评论及运行日志区域开放框选复制。阿拉伯语（`ar`）界面切换为 `RightToLeft` 布局流向，小说正文方向仍由正文首个强方向字符独立决定。

### 尺寸、圆角与动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `Gap.xs` / `s` / `m` / `l` / `xl` | `4` / `8` / `12` / `16` / `24 epx` | 组件内间距与分组留白 |
| `Gap.page` | `24 epx`（紧凑窗口 `16 epx`） | 页面内容左右统一对齐边距 |
| `Radii.control` / `cover` / `card` / `flyout` | `6` / `10` / `12` / `16 epx` | 桌面按钮与小标签 / 封面缩略图 / 成组表面与卡片 / 对话框与浮动控制栏 |
| `Motion.short` / `medium` | `150` / `240 ms` | 页面淡入切换与浮层展开；系统关闭“动画效果”时归零 |

- 桌面页面切换只对新内容执行短淡入，不让宽屏工作区整体左右平移。封面卡片悬停使用 `4%` 亮度叠加与细描边高光，不作改变网格几何尺寸的缩放动画。

## 窗口外壳与导航心智

- **沉浸式自定义标题栏（44 epx）：** 内容延伸至标题栏区域，集成全局返回按钮（支持 `Alt+Left` 与鼠标返回侧键）、侧栏展开/收起按钮、品牌标识、全局快搜入口（`Ctrl+K`）、无痕模式状态胶囊（开启时常驻展示并可一键关闭）、后台下载活动环，以及保留原生 Snap Layouts 分屏菜单的最大化/还原/关闭按钮。
- **对齐 Android 四大支柱的侧栏导航：**
  - 窗口宽度 `≥ 840 epx` 使用常驻可折叠左侧栏，`＜ 840 epx` 自动收拢为紧凑图标轨（`LeftCompact`）。
  - 主导航区保留 **发现**（可展开 17 个内容域快捷列表）、**收藏**（顶部分段切换“收藏 · 更新”，带未读新章节角标，并提供完整浏览历史入口）、**下载**、**订阅**；侧栏底部固定 **站点管理** 与 **设置**（对应 Android“我的”）。
- **多工作区标签与独立窗口：**
  - 在列表、网格、搜索结果或排行榜中，`Ctrl+左键` 或鼠标中键点击作品可在后台工作区标签页打开详情，保留原列表滚动位置与筛选上下文。
  - 漫画阅读器、小说阅读器、视频/直播舞台、在线游戏与酒馆会话支持弹出为独立窗口；视频与直播额外支持无边框置顶画中画（`CompactOverlay`）。

## 页面与全品类桌面交互

### 发现、搜索、排行榜与反搜

- 发现页顶部保留等高并排的“内容范围（全部 / 二次元 / 三次元）”与“媒体类型（全部 / 图片 / 视频 / 其他）”筛选，同时约束主页域展示与聚合搜索范围；下方为支持鼠标滚轮横滑与边界翻页箭头的域胶囊条。
- 全局快搜（`Ctrl+K`）与搜索页支持粘贴原站链接或番号直达详情、资源站点聚合搜索、独立“搜索作品资料”及多语言搜索开关。输入法组词（IME Composition）期间不触发联想或提交。
- 作品卡片、站点与标签提供桌面右键上下文菜单（后台标签打开、收藏与分类、同作者搜索、屏蔽标签/作者、复制编号或原站地址），同时保留触屏长按手势。
- 图片反搜同时支持文件拖放（Drag & Drop）、`Ctrl+V` 直接粘贴剪贴板图片、文件选择与框选裁剪；图片在本地去元数据重编码（`≤ 1.8 MB`），用户点击搜索后才上传至所选的通用/本子/里番/JAV 分组服务。

### 宽屏详情与书架管理

- 宽度 `≥ 960 epx` 时详情采用双栏画廊布局：左侧按真实解码比例展示完整封面（限制最大高度，不裁剪）及主次操作组；右侧排布完整换行的衬线标题、作者、版本、命名空间标签胶囊与简介，下方衔接缩略图预览与关联作品滑轨。窗口缩窄或大字号空间不足时自动回退单列纵向排列。
- 章节、历史与下载列表支持 `Shift+点击` 范围连选与 `Ctrl+点击` 多选批量操作。下载网格沿封面圆角边框顺时针展示 1.5 epx 状态进度，语义与颜色对齐公共规范。
- 设置中心采用桌面双栏结构，右侧表单使用 `RowGroup` 成组圆角表面，最大宽度限制为 `760 epx` 并居中对齐。账号、密码、Cookie 与授权会话输入框保持明文可见并支持剪贴板智能解析。

### 阅读、播放、音声、游戏与酒馆

- **漫画与图集阅读器：** 支持条漫平滑滚动、左→右翻页、日漫右→左翻页及**桌面双页并排模式**（含首页封面单页对齐与宽幅跨页自动独占）。控制层 `ReaderChrome` 采用圆角毛玻璃浮动面板叠加，鼠标移至上下热区或单击中区显隐，不重排画面。支持方向键、`A/D`、`Space/Shift+Space`、鼠标前后侧键翻页，`Ctrl+滚轮` 焦点缩放，`F11` 全屏。输入框聚焦、弹层打开或含修饰键时不触发翻页。
- **视频、直播与短视频：** 宽屏默认采用“左自适应比例主舞台 + 右选集/推荐分栏”，提供剧场模式（`T`）、全屏（`F` / 双击中区 / `Esc` 退出）与置顶画中画。支持 `Space`/`K` 播放暂停、`←/→` 快退快进 10 秒、长按鼠标左键或长按 `→` 临时 2 倍速（松开恢复）、`↑/↓` 或播放器滚轮调节 5% 音量、`M` 静音。清晰度、倍速与选集浮层打开期间不暂停播放。短视频与 AI 短剧居中展示竖屏视口，支持滚轮吸附切集与“仅视频 / 带信息”无重建切换。
- **音声（ASMR）：** 树状目录逐页展示，支持整部、目录或单曲连带同目录关联字幕下载；开启后台播放后在主窗口呈现全局迷你播放条，并接入 Windows 系统媒体传输控制（SMTC 仅展示固定脱敏名称“音声”，不暴露作品标题与封面）。
- **小说阅读器：** 支持单栏限宽与桌面双栏书页排版，保持 UTF-16 字符偏移定位、书签与划词笔记、三种翻译模式及系统自然语音朗读。
- **在线游戏与酒馆：** 在线游戏运行于作品独占的持久化浏览器 Profile，支持物理键盘直通、手柄按键映射、触屏浮动虚拟按键及带 origin 二次校验的 `localStorage` 存档导入导出。酒馆采用“会话分支历史 · 消息主区 · 角色与世界书抽屉”三栏布局，回看历史消息时不被流式生成打断滚动。

## 隐私、系统能力与生命周期

- **硬件级防截屏：** 开启“防截屏”或处于应用锁状态时，对所有应用窗口启用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，阻止截图、录屏、屏幕共享与任务视图缩略图捕获内容。
- **Windows Hello 应用锁：** 接入系统生物识别与 PIN 验证；支持启动锁定，以及窗口最小化、失焦或系统锁屏达到设定时长后自动锁定，锁定期间遮盖全部界面并暂停媒体与游戏输入。
- **系统托盘与优雅退出：** 支持可选“关闭主窗口最小化至系统托盘”以维持后台下载、直播录制与定时订阅检查，系统通知默认隐藏作品标题。真正退出应用时按“暂停调度 → 释放页面与播放器 → 排空备份/插件/数据库写入队列 → 关闭运行时与数据库”顺序执行，未落盘前异常可恢复运行。

## Windows 界面验收边界

- 每次界面视觉与交互验收必须同时覆盖以下两组真实 Windows 运行场景并保留证据：
  1. **标准桌面＋默认字体：** `1440×900` 窗口、`100%`（或 `125%`）系统缩放、`1.0` 倍文本大小，分别检查暗色与亮色主题。
  2. **分屏窄窗＋大字体组合：** `800×720`（Windows 半屏贴靠宽度）**同时启用** `150%` 系统缩放与 `1.5` 倍文本大小。
- 额外核验 Windows 高对比度主题、系统关闭动画效果、键盘 `Tab` 焦点环可见性、快捷键防误触边界、窗口缩放重排、最小化/锁屏恢复及多窗口退出一致性。其他平台截图或仅静态编译通过不能代替 Windows 原生运行验收。
