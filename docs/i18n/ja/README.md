## ダウンロード

**[最新リリース](https://github.com/drdon1234/Hentai-Park/releases/latest)** から Android APK をダウンロードしてください。ほとんどのスマートフォンとタブレットは `arm64-v8a`、エミュレーターは通常 `x86_64` です。

Android・Windows・macOS・Linux に対応します。iOS/iPadOS は現在シミュレーター用のみで、Web 版はありません。[インストール方法と制限](../../PLATFORMS.md)をご覧ください。

デスクトップでは Ctrl+マウスホイール、Ctrl/Cmd のプラス・マイナスキーで表示倍率を変更し、Ctrl/Cmd+0 でリセットできます。外観設定からも調整できます。Windows のトレイアイコンからウィンドウを復元したり終了したりできます。ウィンドウを閉じるときは、トレイへの格納または終了を選べます。

## 3 ステップで始める

1. **見つける**：「見つける」を開いてカテゴリーを選ぶか、検索欄にキーワード・リンク・品番を入力します。
2. **読む・見る**：作品を開いてメインボタンをタップ。気に入ったものは「ライブラリ」に追加します。
3. **続きから**：「見つける」上部の「続きから」と「履歴」で前回の位置に戻れます。追いかけている作品は「ライブラリ → 更新」に届きます。

ログインやプロキシが必要なサイトは「その他 → サイト」「その他 → ネットワーク」で設定します。

## 機能

| 機能 | 内容 |
| --- | --- |
| ランキング | 「発見」から同人誌・アニメ・JAVのランキングを開き、サイトと期間を選び、作品を検索したり元サイトを開いたりできます |
| 見つける・検索 | カテゴリー別に閲覧、複数サイトを同時検索、多言語のキーワードで範囲を広げられます。リンクや品番を貼り付けると作品を直接開けます |
| 読む・見る | 漫画は縦スクロール・ページ送り・見開き、動画はエピソード選択・倍速・続きから再生、小説は文字設定・しおり・メモ・読み上げ。3 つのリーダーは同じ操作で使えます |
| ライブラリ | お気に入りのカテゴリー分けと更新通知。作者・チャンネル・キーワードの新着も購読できます |
| ダウンロード | メインナビゲーションの独立したタブで漫画・動画・小説・ゲームのダウンロードを管理。CBZ の取り込みと書き出し。作品メニューから完了した画像の章を PDF として書き出し、アニメーション画像は最初のフレームのみ保存 |
| ゲームリソース | ゲームの紹介・バージョン・ダウンロードリンクを確認 |
| 翻訳とフィルター | タイトル・紹介文・タグを翻訳。タグで作品を非表示 |
| プライバシーとバックアップ | アプリロック、シークレットモード、表紙のぼかし、スクリーンショット防止。お気に入り・進捗・設定をバックアップ |

小説リーダーの「その他 → 全文翻訳」で本文全体を翻訳でき、次の章を開くと翻訳が続きます。原文にも切り替えられます。

閲覧・詳細ページは章とメディアのアドレスを含むキャッシュをすぐに開けます。更新に失敗しても利用可能なキャッシュは保持されます。ホームに戻るとスクロール位置を復元します。カードの長押しで作品や作者をブロックでき、フィルター設定で解除できます。ランキングの条件は保存され、開くたびに最新の結果を取得します。ショート動画の既定サイトは Pornhub Shorties です。ホームとカテゴリ画面のおすすめサイトで、キャッシュを表示しながら更新する場合のみ「最新の作品を取得中」と表示します。通常の読み込みは進捗表示のみで、状態を示す文字は表示しません。

ショート動画は次の動画の先読みと、最近視聴した動画とバッファの保持に対応し、既定ではそれぞれ 2 本です。「マイページ → ショート動画」または再生画面の「その他 → ショート動画の設定」で個別に変更でき、0 で無効になります。キャッシュは再生画面を開いている間のみ有効で、数を増やすとメモリと通信量が増えます。

アプリ内のお気に入りはローカルの書庫に保存されます。サイトでの操作はログイン中のアカウントで、各サイト対応のいいね・ブックマーク・評価を保存します。X のブックマークはサイトのお気に入りです。Pixiv・X・PicACG はいいねとブックマーク、MissAV はブックマーク、EH はお気に入りと評価に対応します。アカウント対応サイトではツールバーの下にログイン・アカウント管理を表示します。Pixiv は未ログインでもおすすめを初期表示し、継続読み込み・作者の他の作品・関連作品に対応します。Pixiv と EH は検索候補に対応します。作品・共有リンクを検索欄に貼り付けるとアプリ内の作品を開けます。

GalgameX は元サイトのお気に入りに対応し、追加時は最初のコレクションに保存します。コレクションがない場合は元サイトで先に作成してください。解除時は全コレクションから作品を削除します。

JAV 作品では配信元が示す字幕・バージョンの違いを確認し、別バージョンへの切り替えや品番によるサイト内・横断検索ができます。お気に入り、再生位置、ダウンロードはバージョンごとに保存されます。

ライトとダークのテーマ、8 つの表示言語に対応。各サイトで使える機能はアプリ内の表示に従います。

## 画像逆検索

| 用途 | サービス |
| --- | --- |
| 総合画像の出典（完全一致） | Google Lens |
| 画像の出典と類似画像 | Yandex、Bing、Baidu 画像検索 |
| アニメ作品・話数・時刻 | trace.moe |
| アニメとGalgameのキャラクター・作品 | AnimeTrace |
| イラストの出典 | IQDB |
| 成人向けギャラリーの出典 | E-Hentai 画像検索 |
| JAV画像から品番を検索 | AVScan |

Bing の画像逆検索には地域制限があります。Baidu は類似画像と掲載元リンクのみを返す場合があります。E-Hentai 画像検索は公開ギャラリーのみが対象で、縮小や切り抜き後は一致しない場合があります。

サービスは汎用・裏アニメ・JAV・画像の分類ごとに縦に表示され、分類をまたいで複数選択できます。

「発見」上部の画像逆検索では、初期状態で Google Lens のみが選択されます。複数のサービスを選んで同時に検索できます。画像を選択し、必要に応じて切り抜いてから検索してください。結果は候補のあるサイトのみを表示し、サイトごとに切り替えて確認できます。元サイトを開くか、作品名・品番でリソースを検索できます。検索を押したときだけ選択したサービスへ画像を送信します。

Google Lens はバックグラウンドで画像をアップロードし、出典を取得します。すべての画像逆検索はアプリ独自の画面に進行状況と結果を表示し、手動認証が必要な場合のみ認証領域を表示します。ネットワークによっては VPN またはプロキシが必要です。

結果は確認が必要な候補で、類似度は確定を意味しません。trace.moeの無料枠には制限があり、IQDBは混雑時に待つ場合があります。AVScanは個人の非商用利用限定です。各サービスの候補、スコア、関連画像を保持します。「元サイトの情報」を開くと時刻、認識領域、タグなどの元の情報を確認できます。全作品の収録は保証せず、キャラクター識別でゲームを直接ダウンロードすることはできません。

## よくある質問

**サイトが開けない、画像や動画が読み込めない**
まずネットワークを確認してください。中国本土では VPN やプロキシが必要なサイトがあります。プロキシは「その他 → ネットワーク」で設定できます。認証画面が出たら、内蔵ブラウザで一度だけ通過してください。

**サイトのアカウントは必要？**
ほとんど不要です。ログインが必要なサイトはサイトページの上部に表示され、「その他 → サイト」のサイト設定からログインできます。Pixiv、X、StoriesOnline のウェブログインは Google や Apple などの外部アカウントに対応していますが、内蔵ブラウザを許可するかは各サービス次第です。

**勝手にサイトへ投稿・返信しますか？**
自動では行いません。次元茶館の一部リソースは返信しないと解除されないため、送信する内容を先に表示し、確認してから送信します。

**機種変更してもお気に入りと進捗を残すには？**
「その他 → バックアップ」で書き出し、新しい端末で復元します。ダウンロードは含まれず、サイトによっては再ログインが必要です。

**翻訳で何が送信されますか？**
タイトル・紹介文・タグ・検索語・選択した文字・小説全文を翻訳すると、その内容が Google 翻訳に送信されます。アカウント・Cookie・読書履歴は送信されません。翻訳先はアプリの言語に従います。

**問題を報告するには？**
[Issues](https://github.com/drdon1234/Hentai-Park/issues) にアプリのバージョン、サイト名、再現手順を書いてください。スクリーンショットではアカウントや個人的な内容を隠してください。
