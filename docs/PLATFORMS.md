# 平台支持与安装

提供 Android 和 Windows 原生客户端。

## 平台功能

不同平台的可用功能和限制如下。

| 能力 | Android | Windows |
| --- | --- | --- |
| 站点加载、隔离脚本、网络、账号、验证码、Cookie 分区 | 支持 | 支持 |
| 漫画、美图、小说、书库、历史、进度、备份、订阅记录 | 支持 | 支持 |
| 小说朗读 | 系统引擎 | 系统引擎 |
| 普通视频、短视频、本地视频、续播 | 支持 | 支持 |
| 网页视频、网页登录 | 系统 WebView | 支持 |
| HLS 下载、取消、恢复及本地播放 | 原生封装 MP4 | 清单与 TS 分片、受限回环播放 |
| 文件导出、备份、导入 | 系统分享/选择 | 目录选择、流式复制 |
| 下载目录 | 应用外部目录 | 用户可选，新任务生效 |
| 通知 | 原生桥 | 支持 |
| 关闭应用后的订阅、下载保活 | 后台订阅检查与下载服务，受系统限制 | 不提供关闭后调度 |
| 应用锁 | 系统认证 | 系统认证 |
| 防截图、音量键翻页、安装 APK | Android 原生能力 | 不适用 |
| 游戏介绍、链接与资源下载 | 支持 | 支持 |
| HTML 游戏及本地资源访问 | 外部链接与资源导出，无内置游戏执行器 | 同 Android |
| 应用更新 | 下载校验与系统安装 | 下载校验并打开安装程序 |

跨平台代码保留证书校验、源域名隔离、Cookie 分区和重定向规则。离线 HLS 不保留远程签名地址；播放仅注册受限回环资源，拒绝任意路径及外部链接。导出 HLS 是包含清单和分片的 ZIP，需要解压后用支持 HLS 的播放器打开；应用尚未提供该 ZIP 的重新导入入口。

桌面下载目录变更不搬动旧文件；旧任务保留原绝对路径。外置盘暂不可用时，新任务退回默认目录且保留用户配置。桌面导出不会覆盖已有同名文件。

## 桌面和平板交互

图片反搜支持拖入图片文件、Ctrl+V 粘贴截图、复制的图片或图片文件，也可通过“粘贴图片”及文件选择按钮输入。下载页可拖入 CBZ / ZIP 漫画；备份页可拖入 .parkbak 文件并确认恢复。作品、章节、标签及下载项的长按操作在桌面也可通过鼠标右键使用。支持下拉刷新的列表在桌面提供刷新按钮、F5 与 Ctrl+R。界面使用系统字体；Windows 根据界面语言选择字体。

桌面始终使用侧边导航，窄窗口收为图标栏；操作面板居中显示，可用 Esc 关闭。Android 手机使用底部导航，横屏保留移动端导航。作品详情通过完整页面打开，内容随窗口宽度重新排版。播放页的推荐在播放器下方排列，桌面为多列网格并随页面整体滚动，手机保留横向预览与固定播放器；足够宽高时仅选集放在右侧栏。桌面最小窗口为 360×480。漫画阅读器支持翻页键、F 切换桌面全屏、Esc 先退出全屏再返回；普通播放器支持空格、左右方向键跳转十秒、F 全屏、Esc 退出全屏；短视频支持上下方向键、PageUp/PageDown、滚轮切换和空格暂停。桌面界面支持 Ctrl+滚轮及 Ctrl 加减键缩放、Ctrl+0 重置，也可在外观设置中调整。Windows 关闭窗口时可选择收起到托盘或退出；托盘支持恢复窗口和退出，托盘不可用时不会隐藏窗口。退出前暂停下载、更新和自动备份，等待数据写入及页面资源释放；失败时保留窗口供重试。

## 安装

- Android：选匹配架构的正式签名 APK；多数手机选 arm64-v8a。
- Windows x64：运行 setup.exe 安装程序，或解压完整 ZIP 后运行 HentaiPark 目录中的 hentai_park.exe，保留全部 DLL 和 data 目录；包内包含 MSVC CRT。应用内确认更新后会下载、校验并打开安装程序，然后正常退出；升级默认沿用当前程序目录，按安装程序提示完成安装。网页登录和插件运行需要 Microsoft Edge WebView2 Runtime；网页视频使用独立临时用户目录，并在缺少私密会话接口时拒绝播放，防止回退到站点 Cookie 存储。Windows 10/11 若未安装，使用微软官方安装器安装，应用不关闭 TLS 或绕过证书检查。

桌面升级不会删除账号、书库、配置和下载；安装完成后重新打开应用。首次从尚不支持应用内安装的旧版升级时，仍需从官方发布页手动下载安装包；新功能随新版生效。
