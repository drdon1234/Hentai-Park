## 中文

### 新功能
- 手动备份可选保存站点登录与确认状态，恢复时一并还原对应站点的会话。
- 本体与插件更新可选择“不再提醒”当前版本；手动检查仍可查看更新。

### 改进
- 插件更新提示区分可直接安装与需要升级本体的版本，避免安装不兼容的插件。
- 调整详情页、书库和阅读设置面板，改善窄屏、大字体、文本展开与操作按钮的显示。
- 优化视频播放控件与进度条布局，直链视频播放使用应用内代理。
- 完善直播播放与录制，支持更多直播格式，并避免将直播误判为播放结束。

### 修复
- 修复登录状态检查失败后误报退出、网页登录完成后仍未确认账号，以及退出后状态未及时更新的问题。
- 修复部分站点的搜索筛选与推荐加载，并改善直播间可用状态识别。
- 修复备份恢复时站点会话与配置不同步的问题。

## English

### New
- Optionally include site sign-in and verification state in manual backups, and restore the corresponding site sessions together.
- Ignore notifications for the current app or plugin version while keeping updates visible in manual checks.

### Improvements
- Separate compatible plugin updates from those requiring a newer app to prevent incompatible installations.
- Refine detail pages, library and reader settings panels for narrow screens, large text, expandable descriptions and action buttons.
- Improve video controls and progress bar layouts; direct video playback now uses the in-app proxy.
- Improve live playback and recording with support for more stream formats, and prevent live streams from being treated as completed videos.

### Fixes
- Fix false sign-out states after failed account checks, unconfirmed accounts after web sign-in, and delayed state updates after sign-out.
- Fix search filters and recommendation loading on some sites, and improve live room availability detection.
- Fix site sessions and settings becoming inconsistent during backup restoration.
