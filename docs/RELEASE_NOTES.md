## 中文

### 改进
- 移除互动立绘内容域及其相关插件与入口。

### 修复
- 修复已安装误发高版本后无法发现官方最新版本更新的问题；官方最新版本号较低时允许更新，并在安装前明确提示版本号回退。
- 修复音声与在线游戏插件的最低应用版本要求错误，恢复在 0.13.0 及以上版本中的安装与使用。

### 插件更新
- Hentai ASMR 0.0.2、ASMRHoney 0.0.2、Literotica Audio 0.0.2、JASMR 0.0.2、ASMR Gay 0.0.2、ASMR Moon 0.0.2、EroASMR 0.0.2：修正最低应用版本要求。
- itch.io 0.0.2、Gamcore 0.0.2：修正最低应用版本要求。

## English

### Improvements
- Removed the interactive artwork domain and its related plugins and entry points.

### Fixes
- Fixed update detection after installing an accidentally published higher version; updates to the latest official release are now available even when its version number is lower, with an explicit rollback notice before installation.
- Corrected the minimum app version requirements for audio and online game plugins, restoring installation and use on 0.13.0 and later.

### Plugin updates
- Hentai ASMR 0.0.2, ASMRHoney 0.0.2, Literotica Audio 0.0.2, JASMR 0.0.2, ASMR Gay 0.0.2, ASMR Moon 0.0.2, EroASMR 0.0.2: Corrected the minimum app version requirements.
- itch.io 0.0.2, Gamcore 0.0.2: Corrected the minimum app version requirements.
