## 中文

### 新功能
- 新增音声内容域，支持目录筛选、连续播放、同步字幕与可选后台播放。
- 新增在线游戏内容域，支持网页游戏、全屏与虚拟按键。
- 新增互动立绘内容域，支持动态立绘浏览与原站交互。

### 改进
- 排行榜与作品资料统一使用资料插件更新频道。

### 修复
- 移除已停用的排行榜频道请求，避免影响官方插件更新与撤回检查。
- 修复备份恢复、书库写入失败重试及阅读状态同步问题。
- 修复离线导出遗漏、更换目录后旧导出不可见和录制内容离线读取问题。
- 修复订阅分页、帖子定位与错误标记已读的问题。
- 修复直播初始化、浏览器超时、朗读语言及筛选联动问题。
- 登录凭据默认隐藏，支持显隐切换与正确的自动填充类型。

### 插件更新
- Telegram 0.0.12：修复服务消息导致分页提前结束的问题。

## English

### New
- Added the audio domain with directory filters, continuous playback, synchronized subtitles and optional background playback.
- Added online games with fullscreen and virtual controls.
- Added interactive artwork with animated artwork and original-site interactions.

### Improvements
- Rankings and work information now share the metadata plugin update channel.

### Fixes
- Removed requests to the retired rankings channel so it no longer affects official plugin updates and withdrawal checks.
- Fixed backup restoration, library write retries and reading-state synchronization.
- Fixed incomplete exports, missing previous exports after directory changes and offline access to recordings.
- Fixed subscription pagination, post navigation and premature read marking.
- Fixed live playback initialization, browser timeouts, speech languages and dependent filters.
- Login credentials are hidden by default with visibility controls and appropriate autofill types.

### Plugin updates
- Telegram 0.0.12: Fixed pagination stopping early on service messages.
