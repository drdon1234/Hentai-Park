# Web 平台设计准则

遵循[公共设计准则](../DESIGN.md)。工程与发布见[Web 开发说明](../web/DEVELOPMENT.md)，验证范围见[验收边界](../web/ACCEPTANCE.md)。

## Overview

内容占据主体，导航提供清楚的目的地，操作按任务与重要性组织。JAV Pilot 是全端视觉和 Web 交互参考；安卓基线提供领域关系、功能与移动使用心智，不另设一套移动配色或控件皮肤。

浏览和管理采用清晰、克制的操作界面；正文与媒体消费减少外围干扰。真实能力决定入口，不用占位控件、虚构数据或隐藏功能弥补实现缺口。本文替代旧有按轮次追加的设计规则；验收范围以实际证据清单为准。

## Colors

`src/tokens.css` 与 `src/refactor-ux.css` 使用 `@layer reset, tokens, base, components, utilities;` 管理样式优先级，断点不重新定义配色。浅深主题分别确定背景、表面、文字与边界。

主要操作使用 `--action` 和根据亮度选择的 `--on-action`；自定义主题色来自已有 `seedColor`（由 `computeSeedPalette` 派生符合对比度要求的浅深主题强调色，并同步更新 `<meta name="theme-color">`）。普通筛选胶囊与二级操作采用无描边色调填充（Tonal Pill），`:hover` 统一包裹在 `@media (hover: hover) and (pointer: fine)` 中，触控设备使用 `:active` 微缩放反馈。导航选中使用中性 `--navigation-selected`，成功、警告与危险不得借用导航选中色。

阅读内容的纸张、夜间和护眼主题仅作用于正文。工具面板跟随应用表面，不从阅读画布继承一整组深色输入令牌。视频画面保留暗色舞台；画内设置使用应用表面。

## Typography

系统无衬线字体栈全端共用，桌面主体 14px，标题通常 28px。移动输入保持可读字号及触控面积，正文阅读字号、字体与行距保留用户偏好。长标题自然换行；封面卡片摘要可截断，链接可访问名称保留完整标题。技术标识仅用于诊断、授权和必要的资源判断。

## Layout

桌面在 840px 起使用常驻侧栏，支持用户收起；手机使用紧凑根导航与抽屉。导航树：

- 浏览：发现、搜索、内容站点；内容域按真实站点类别提供独立链接。
- 我的内容：收藏、历史、下载、订阅。
- 管理：站点管理、设置。

手机四根入口（发现／收藏／下载／我的）使用 `<KeepAliveView>` 保活已挂载状态与滚动位置，其余二级目的地通过 `React.lazy()` 按需加载，并通过相同命名的域页、工具及导航抽屉进入。PWA 壳层配置 `viewport-fit=cover`、`100dvh` 与安全区域内边距，支持桌面与移动端独立窗口安装；Service Worker 仅缓存静态资源，严禁缓存 `/api/*`。

列表保留真实来源分区、筛选和分页。浏览封面卡片（`BrowseCoverCard`）采用精简封面主体加底部渐变浮层与 `AdaptiveSheet` 快捷抽屉，不堆叠常驻三按钮底栏；点击模糊封面可直接原地切换清晰态。返回依据站内导航深度栈与可信来路，无来路时回退实际父级路由，严禁误退到外部历史。应用锁（`AppLockGate`）以毛玻璃遮罩覆盖在活动视图上方，解锁后完整保留正在阅读或播放的进度。所有破坏性操作统一通过 `ConfirmProvider` / `confirmAction` 异步确认，禁止调用原生 `window.confirm()`。

## Shapes

控件 8px 圆角，内容表面通常 16px，桌面导航 20px。控件边界与正文分区用途不同，不将全部操作画成同样的描边按钮。组内间距 8–12px，独立任务区通常 24px。

## Elevation & Depth

玻璃用于导航和浮层表达空间关系；表单、正文工具与媒体资料使用稳定实色表面。局部阴影强调覆盖关系。减少透明与强制色使用可读的实色回退。

## Components

主操作是保存、发送、阅读或播放；普通执行为中性控件，导航为轻量链接，危险操作保留危险色与已有确认。禁用、失败、加载、重试和权限限制必须独立表达。

原生 details 保留键盘语义，统一使用整行标题和加减状态，移除默认三角。复杂阅读设置使用局部覆盖面板，手机阅读工具使用已有底部覆盖结构；打开工具不改变正文分页几何。章节、页码、书签与标注继续走真实数据与定位逻辑。自动滚动和朗读停止应直接可达。

`MediaSurface` 为原生在线、音声、短视频、直播与离线媒体提供共享播放、进度、音量、设置与全屏控制。媒体加载、授权和进度由原调用者负责。横竖比例来自元数据；竖屏限制宽度，不固定套用 16:9。浏览器控制是显式降级入口。网页远程播放器保留自身能力边界，不伪造本机控制。

相册在本页调整列数和默认收起并持久化，类型与日期筛选继续使用真实集合。预览关闭恢复焦点，视频关闭释放原媒体组件。游戏按真实类型区分在线运行与下载，资源说明按需展开。

酒馆会话以消息区为主体，输入区位于消息区下方；消息独立滚动，阅读旧消息时不强制追随新流。会话配置局部打开；连接未配置时提供引导。角色资源资料保留独立入口。

标签包默认展示已安装内容；检查更新与新增、文件导入为独立任务；版本与更新动作同组，导出和删除收纳到管理。索引校验成功为辅助反馈，失败提供实际原因与恢复途径。

## Do's and Don'ts

- 保留权限、插件协议、缓存、分页和持久化语义；只对实际修改范围回归。
- 不在响应式断点切换设计语言，不用高优先级追加覆盖替代删除冲突根规则。
- 不用扫描通过或构建成功代替截图目检；正文与工具展开态都需检查。
- 生产构建验收记录源码和产物哈希。测试、截图和受控媒体统一放根 `test/`，不得加入 Git。
- 受控素材、供应商模拟与实际设备验证分别记录，不将测试样本当作外站可用证明。
