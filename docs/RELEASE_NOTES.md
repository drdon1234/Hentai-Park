## 中文

### 新功能
- 新增图片反搜入口，支持选择图片、裁剪范围和切换反搜服务；识别出作品名或番号后可继续搜索资源。
- 接入 trace.moe、AnimeTrace、IQDB 和 AVScan，分别查找动画集数与时间点、动画及游戏角色、插画出处和 JAV 番号。

### 注意事项
- 仅在点击搜索后向所选服务上传图片；各服务可能受免费额度、排队或网络访问限制。
- 反搜结果为候选信息，请核对出处；游戏角色识别不直接提供游戏下载，AVScan 仅限个人非商业使用。

## English

### New
- Add reverse image search with image selection, cropping and service switching; continue searching for resources when a work title or video code is identified.
- Add trace.moe, AnimeTrace, IQDB and AVScan to find anime episodes and timestamps, anime and game characters, illustration sources and JAV codes respectively.

### Notes
- Images are uploaded to the selected service only after you tap Search; free quotas, queues or network restrictions may apply.
- Results are candidates and require source verification; game character identification does not directly provide game downloads, and AVScan is for personal, non-commercial use only.
