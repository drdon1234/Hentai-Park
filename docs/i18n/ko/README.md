## 다운로드 및 시작하기

**[최신 버전](https://github.com/drdon1234/Hentai-Park/releases/latest)** 에서 Android APK를 내려받아 설치하세요. 대부분의 휴대폰과 태블릿은 `arm64-v8a`, 에뮬레이터는 보통 `x86_64`를 선택하면 됩니다.

1. **콘텐츠 찾기**: 발견에서 분류와 사이트를 선택하거나 바로 검색하세요.
2. **읽고 보기**: 작품을 열어 읽거나 재생하고, 마음에 드는 작품은 책장에 저장하세요.
3. **이어서 보기**: 최근 기록에서 이어 보거나 책장과 업데이트에서 즐겨찾기와 새 콘텐츠를 확인하세요.

로그인이 필요한 사이트는 내 정보 → 소스 관리에서 설정하세요. 일부 사이트에는 VPN이나 프록시가 필요할 수 있습니다.

AI 드라마는 위아래로 넘기는 동안 재생을 유지하고 다음 회차를 미리 불러옵니다. 화면을 탭해 밝기와 음량 막대를 표시하고 막대 안에서 위아래로 드래그하여 조절합니다. 자동 포스터는 백그라운드에서 불러오며 사이트 탐색을 우선합니다. 설정을 변경하면 이전 설정의 읽기 요청을 취소합니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| **탐색과 검색** | 분류별 탐색, 여러 사이트 통합 검색, 다국어 키워드로 검색 범위 확대 |
| **읽기와 시청** | 만화 스크롤·페이지 넘기기·두 쪽 보기, 동영상 회차·배속·이어 재생, 소설 레이아웃 조절과 읽어주기 |
| **즐겨찾기와 구독** | 즐겨찾기 분류, 진행 상태 저장, 작품·키워드·작가·채널 업데이트 구독 |
| **오프라인** | 지원되는 만화·동영상·소설 다운로드, CBZ 만화 가져오기와 내보내기 |
| **게임 자료** | 게임 소개·버전·다운로드 링크 확인, 내려받은 파일 저장과 내보내기 |
| **번역과 필터** | 제목·소개·태그 번역, 원치 않는 콘텐츠 차단 |
| **개인정보와 백업** | 앱 잠금·시크릿 모드·표지 흐림·화면 캡처 방지, 즐겨찾기·진행 상태·설정 백업 |

밝은 테마와 어두운 테마, 8개 표시 언어를 지원합니다. 사이트별 사용 가능한 기능은 앱에 표시된 메뉴를 확인하세요.

## 자주 묻는 질문

**사이트나 이미지·동영상이 열리지 않나요?** 인터넷 연결을 확인하고 필요한 경우 VPN을 사용하거나 네트워크 설정에 프록시를 지정하세요. 웹 인증이 나타나면 완료한 뒤 다시 시도하세요.

**사이트 계정이 필요한가요?** 일부 사이트는 로그인이나 접근 권한이 필요하며 앱에서 안내합니다. 내 정보 → 소스 관리에서 해당 사이트 설정을 여세요.

**업데이트 알림은 어떻게 받나요?** 작품 상세나 발견 → 구독에서 구독을 추가하고, 내 정보 → 구독 및 알림 설정에서 알림을 켠 뒤 Android 알림 권한을 허용하세요.

**기기를 바꿔도 즐겨찾기와 진행 상태를 유지하려면?** 내 정보 → 백업 및 복원에서 백업을 내보내고 새 기기에서 복원하세요. 오프라인 다운로드는 따로 보관하고, 사이트 계정은 다시 로그인해야 할 수 있습니다.

**문제를 신고하려면?** [Issues](https://github.com/drdon1234/Hentai-Park/issues) 에 앱 버전, 사이트 이름, 재현 단계를 적어 주세요. 스크린샷의 계정 정보와 개인 콘텐츠는 숨겨 주세요.
