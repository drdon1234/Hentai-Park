## はじめ方

1. 「見つける」でカテゴリとサイトを選ぶか、作品、タグ、リンク、品番で検索します。
2. 作品を開いて読む・観る。気に入った作品は「お気に入り」に追加し、オフライン用にダウンロードできます。
3. ホームの「続きから → すべて」で再開し、「お気に入り → 更新」で新しい章を確認します。

必要に応じて「その他 → サイト」でログイン、「その他 → ネットワーク」でプロキシを設定します。

## 制限と FAQ

酒場には自分の OpenAI 互換 AI サービスが必要です。メッセージ、キャラクター設定、ユーザーペルソナと一致した世界設定をサービスへ送信し、料金が発生する場合があります。対応ルールと読み込み・書き出しは[サイトとサービス](SITES.md)をご覧ください。保存済みリソースと会話は暗号化されない書庫バックアップに含まれ、AI 設定とキーは含まれません。

閲覧、再生、コメント、購読、ダウンロードの対応はサイトごとに異なります。アプリ内の表示を確認してください。サイト更新にはアプリの更新が必要な場合があります。

画像検索では選択したサービスに画像を送信します。端末内の画像検索履歴は暗号化されません。手動ログインではパスワードと Cookie が表示されるため、画面共有にご注意ください。

**サイトやコンテンツにアクセスできない場合は？**

接続を確認し、案内に従ってログイン、年齢確認、サイト認証を行ってください。地域によって VPN やプロキシが必要です。内容と利用権限は配信元が管理します。 対応する誕生日確認は、端末内で成人確認済みの場合に限り固定日付 1999-12-31 を使用し、実際の誕生日は読み取りません。

**コメントや弾幕を送信できますか？**

コメント、返信、ライブ弾幕は閲覧専用です。ゲームのリンク解放に返信が必要な場合は、内容を表示し、確認後にのみ送信します。

**お気に入りと進捗を保存するには？**

「その他 → バックアップ」で .parkbak を保存・復元します。復元はデータを統合し、ダウンロード済みファイルは含みません。Cookie などのサイトのログイン・確認状態は任意で保存でき、別の端末でも利用できます。有効期限切れや端末に紐づくセッションは再確認が必要な場合があります。バックアップは暗号化されません。安全に保管してください。 オンラインゲームのセーブデータは .parkbak に含まれません。ゲーム内の個別入出力は localStorage のみで、IndexedDB は含まれず、出力ファイルは暗号化されません。

**問題を報告するには？**

Issues にバージョン、サイト、再現手順を記載してください。アカウント、Cookie、Token、バックアップ、署名付き URL 全体は公開しないでください。
