- 新增吃瓜域，接入 51cg1.com、155.fun 和 mrdsk.com，支持分类、标签筛选、搜索及图文与视频阅读。

## English

### New
- Added the Gossip category with 51cg1.com, 155.fun and mrdsk.com, including categories, tag filters, search, illustrated articles and video.

### Improvements
- Gossip lists and articles follow the app design, with text selection and translation, image viewing, favorites and history.
- Work information previews load thumbnails first and open the corresponding full-size images when selected.

### Fixes
- Fixed invalid page numbers being treated as the first page on gossip sites.

### Plugin updates
- FANZA 0.0.12, DLsite 0.0.8, FC2 0.0.12, MGStage 0.0.8, Uncensored studios 0.0.10, JavBus 0.0.4 and JavDB 0.0.3: distinguish preview thumbnails from full-size images and improve image display.
