# 平台说明

本项目提供 Android、iOS 原生客户端与自托管 Web 客户端。

## Android

Android 7.0 及以上为当前支持平台。具体能力、安装限制和设备要求以实际版本和应用内提示为准。

## Web

Web 目前处于 **Beta 阶段**，使用体验仍在持续优化。它通过桌面或手机浏览器使用，可在电脑上本机运行，或通过 Docker 自托管。远程访问需要 HTTPS 地址和访问凭据；当前 Docker 镜像支持 Linux x86_64（amd64）。详见 [Web 部署](../clients/web/DEPLOYMENT.md)。

Web 为单用户实例，使用独立数据目录与 JSON 备份，不支持 Android 数据库或 `.parkbak` 导入，也不提供跨端自动同步。站点验证、播放和下载等功能可能受浏览器、设备及原站限制。

## iOS

iOS 工程最低要求 iOS 15，使用与 Android 相同的 Flutter 页面、站点插件、阅读、收藏、翻译、酒馆与备份业务。已接入应用锁、相册保存、分享、通知、视频亮度与音量调节、音声后台播放及订阅任务。

IPA 必须签名后安装。文件名含 `unsigned` 的包供侧载工具重新签名；已签名包的安装资格取决于描述文件，App Store 类型的包不能直接侧载。覆盖安装应保持 Bundle ID 与签名身份，避免失去原有数据或钥匙串访问权限。当前不提供 iOS 应用内自动安装更新。

iOS 与 Android 的主要差异：

- 系统可暂停或终止后台下载、录制与翻译；长任务建议保持前台。后台订阅由系统安排，不保证按设定间隔执行；应用被强制退出后可能不再执行。
- HLS 离线资源保留为本地播放清单与分段，不提供 Android 的 TS 转 MP4 封装。
- HTML 在线游戏需要 iOS 17 及以上以隔离每个作品的存档；不支持 Flash。虚拟按键仅作用于当前主文档，依赖真实键盘或跨域框架输入的游戏可能无法响应。
- 不支持通用防截屏、音量键翻页或手动选择屏幕刷新率；应用锁会遮盖任务切换器快照。
- WebKit 无法复用 Android 的原生验证点击能力。年龄确认仍使用共用规则；需要原生输入的站点验证尚未对齐，站点登录、播放和下载还受 WebKit 与系统媒体格式限制。
