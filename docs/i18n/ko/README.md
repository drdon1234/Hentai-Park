## 다운로드 및 플랫폼

**[다운로드](https://github.com/drdon1234/Hentai-Park/releases/latest)**

**Android 7.0+와 Windows**를 지원합니다. 일반 Android 기기는 `arm64-v8a`를 선택하고 Windows 포터블 ZIP은 전체 압축을 풀어 주세요.

프로젝트의 대상 플랫폼은 Android, Windows, Web으로 한정됩니다. Web 버전은 계획 중이며 아직 이용할 수 없습니다.

Windows에서는 앱 내 업데이트를 확인하면 설치 파일을 다운로드하고 검증한 뒤 설치 프로그램을 열고 앱을 종료합니다. 시스템 안내에 따라 설치를 완료하세요. 포터블 ZIP의 최상위 폴더는 `HentaiPark`입니다.

## 시작하기

1. 「탐색」에서 분류와 사이트를 선택하거나 작품, 태그, 링크 또는 품번으로 검색하세요.
2. 작품을 열어 읽거나 재생하세요. 좋아하는 작품을 「즐겨찾기」에 추가하거나 오프라인으로 다운로드하세요.
3. 홈의 「이어 보기 → 전체」에서 이어 보고 「즐겨찾기 → 업데이트」에서 새 장을 확인하세요.

필요하면 「더 보기 → 사이트」에서 로그인하고 「더 보기 → 네트워크」에서 프록시를 설정하세요.

## 주요 기능

| 기능 | 사용 경험 |
| --- | --- |
| 탐색과 검색 | 2D, 3D 및 미디어 유형 필터와 여러 사이트 검색. 링크나 품번으로 작품에 바로 이동합니다. |
| 읽기와 감상 | 만화 스크롤·페이지·양면 보기, 영상 회차·배속·이어 보기, 소설 책갈피·주석·읽어주기. |
| 즐겨찾기와 업데이트 | 그룹 정리, 진행 상황 저장, 새 장 확인과 작가·채널·키워드 구독. |
| 오프라인과 내보내기 | 만화, 영상, 소설, 게임 리소스 다운로드. CBZ 가져오기·내보내기와 완료한 화보 장의 PDF 내보내기. |
| 순위와 역검색 | 동인지, 성인 애니메이션, JAV 순위와 이미지로 작품 후보 찾기. |
| 작품 정보 | JAV 순위 상세에서 출연자, 출시 정보, 미리보기 이미지와 마그넷을 확인한 뒤 앱 내 JAV 사이트를 검색합니다. |
| 원본 댓글과 채팅 | 지원 사이트의 댓글·답글·이미지를 읽고 지원 라이브 방송의 채팅을 표시합니다. |
| 번역과 필터 | 제목, 소개, 태그와 소설 본문 번역. 태그로 콘텐츠를 숨깁니다. |
| 개인정보와 백업 | 앱 잠금, 시크릿 탐색, 표지 흐림과 지원 플랫폼의 화면 캡처 차단. 즐겨찾기, 진행 상황, 구독과 설정 백업. |

검색은 기본적으로 차단된 콘텐츠를 숨깁니다. 눈 아이콘으로 일시 표시할 수 있으며 각 사이트 검색 페이지에서도 전환할 수 있습니다. 필터 아이콘은 사이트에서 미리보기 전용으로 명시한 결과만 숨깁니다. 상태가 불명확한 결과는 유지합니다. 콘텐츠 차단에 AI 생성 기본 그룹이 추가되었습니다.

이미지 검색 기록은 최근 이미지 20장을 저장하며 다시 불러와 검색하거나 개별 삭제 및 전체 삭제할 수 있습니다. 시크릿 모드는 기록하지 않습니다. 기록 이미지는 기기에 암호화 없이 저장되며 앱 백업에 포함되지 않습니다. 플레이어에서 같은 시리즈로 이동할 수 있습니다. 재생된 데이터는 임시 캐시되며 재생 화면을 닫으면 삭제됩니다. 용량 제한으로 오래된 부분은 다시 로드할 수 있습니다.

## 제한 사항 및 FAQ

읽기, 재생, 댓글, 구독과 다운로드 지원은 사이트마다 다릅니다. 앱 내 표시를 확인하세요. 사이트 업데이트에 앱 업그레이드가 필요할 수 있습니다.

**사이트나 콘텐츠가 열리지 않나요?**

네트워크를 확인하고 안내에 따라 로그인, 연령 확인 또는 사이트 인증을 완료하세요. 지역에 따라 VPN이나 프록시가 필요할 수 있으며 콘텐츠와 접근 권한은 원본 사이트에서 결정합니다.

**댓글이나 채팅을 보낼 수 있나요?**

댓글, 답글, 라이브 채팅은 읽기 전용입니다. 게임 리소스 해제에 답글이 필요하면 내용을 먼저 보여 주고 확인 후에만 전송합니다.

**즐겨찾기와 진행 상황을 보관하려면?**

「더 보기 → 백업」에서 .parkbak을 내보내거나 복원하세요. 복원은 데이터를 병합하며 다운로드 파일은 포함하지 않습니다. Cookie 등 사이트 로그인·확인 상태는 선택적으로 포함하여 다른 기기에서도 사용할 수 있습니다. 만료되거나 기기에 연결된 세션은 다시 확인해야 할 수 있습니다. 백업은 암호화되지 않으므로 안전하게 보관하세요.

**문제를 제보하려면?**

Issues에 앱 버전, 사이트와 재현 단계를 알려 주세요. 계정, Cookie, Token, 백업과 전체 서명 URL은 숨겨 주세요.
