## Descarga y plataformas

**[Descargar](https://github.com/drdon1234/Hentai-Park/releases/latest)**

Disponible para **Android 7.0+ y Windows**. La mayoría de dispositivos Android usan `arm64-v8a`; extrae los archivos ZIP portátiles de Windows por completo.

El proyecto se centra únicamente en Android, Windows y Web. La versión Web está prevista, pero todavía no está disponible.

En Windows, al confirmar una actualización se descarga y verifica el instalador, se abre y se cierra la aplicación. Sigue las indicaciones del sistema para completar la instalación. Los archivos ZIP portátiles contienen una carpeta fija `HentaiPark`.

## Primeros pasos

1. En Explorar, elige una categoría y un sitio, o busca por obra, etiqueta, enlace o código.
2. Abre una obra para leerla o verla. Guárdala en Favoritos o descárgala para usarla sin conexión.
3. Retoma desde Inicio → Continuar → Todo y consulta capítulos nuevos en Favoritos → Actualizaciones.

Configura el acceso en Más → Sitios y el proxy en Más → Red cuando sea necesario.

## Limitaciones y preguntas

La lectura, reproducción, comentarios, suscripciones y descargas dependen de cada sitio. Consulta las opciones disponibles en la app. Las actualizaciones de sitios pueden exigir actualizar la app.

**¿No puedes abrir un sitio o contenido?**

Comprueba la conexión y sigue las indicaciones para iniciar sesión, confirmar tu edad o superar la verificación del sitio. En algunas regiones puede ser necesario un VPN o proxy; el sitio original controla el contenido y los permisos.

**¿Puedo enviar comentarios o chat?**

Los comentarios, respuestas y chat son de solo lectura. Si un recurso de juego requiere una respuesta para desbloquearse, se muestra el texto y solo se envía tras tu confirmación.

**¿Cómo guardo favoritos y progreso?**

Exporta o restaura .parkbak en Más → Copia de seguridad. La restauración combina los datos y excluye las descargas. Puedes incluir opcionalmente el estado de acceso y confirmación de los sitios, incluidas las cookies, para usarlo en otro dispositivo. Las sesiones caducadas o vinculadas al dispositivo pueden requerir una nueva verificación. Las copias no están cifradas; guárdalas de forma segura.

**¿Cómo informo de un problema?**

Usa Issues e indica versión, sitio y pasos. Oculta cuentas, cookies, tokens, copias y URL firmadas completas.
