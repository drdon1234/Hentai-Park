# السجلات والإبلاغ عن المشاكل

تسجل السجلات العادية الأخطاء والمحاولات التلقائية ونتائج استدعاء المواقع وتغيرات حالة التطبيق. حدّث سجلات التشغيل أو صدّرها من الإعدادات وأرفق خطوات إعادة المشكلة في Issue.

للمشاكل الصعبة، فعّل debug لهذه الجلسة فقط لإعادة المشكلة الآن، أو لبدء التشغيل التالي فقط لتسجيل عملية البدء كاملة. يظهر تنبيه عند تفعيل الخيار المجدول. ينتهي debug عند الخروج، ويُستهلك الخيار المجدول مرة واحدة.

السجلات الدائمة معطلة افتراضيًا، ويستبدل كل تشغيل السجلات الحديثة. عند تفعيلها تُضاف السجلات عبر مرات التشغيل ولا تُحذف الأقدم إلا عند بلوغ 100 MiB. يؤدي تعطيلها إلى استبدال سجل التشغيل السابق فورًا. لا يتأثر سجل الأعطال المستقل.

يضيف debug أزمنة الطلبات والمحاولات وذاكرة التخزين وحالة التشغيل، دون الحسابات أو Cookie أو Token أو المحتوى أو المسارات المحلية أو الروابط الموقعة الكاملة. تعرض الصفحة السجلات الحديثة ويشمل التصدير جميع سجلات التشغيل المحتفظ بها. يخفي وضع التنقيح أيضًا المضيفين وإصدارات النظام التفصيلية. راجع الملفات قبل مشاركتها.
