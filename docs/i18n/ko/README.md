## 다운로드

**[최신 릴리스](https://github.com/drdon1234/Hentai-Park/releases/latest)**에서 플랫폼에 맞는 패키지를 받으세요. Android 휴대폰과 태블릿은 보통 `arm64-v8a`, 에뮬레이터는 `x86_64`입니다. 데스크톱 패키지는 전체를 압축 해제하세요. [설치 방법과 플랫폼 제한](../../PLATFORMS.md)을 확인하세요.

Android, Windows, macOS, Linux 클라이언트를 제공합니다. iOS/iPadOS는 현재 시뮬레이터용만 제공하며 Web은 지원하지 않습니다. [설치 방법과 제한](../../PLATFORMS.md)을 확인하세요.

데스크톱에서는 Ctrl+마우스 휠 또는 Ctrl/Cmd 더하기·빼기 키로 화면 배율을 조절하고 Ctrl/Cmd+0으로 초기화할 수 있습니다. 모양 설정에서도 조절할 수 있습니다. Windows 트레이 아이콘으로 창을 복원하거나 앱을 종료할 수 있습니다. 창을 닫을 때 트레이로 숨기거나 종료하도록 선택할 수 있습니다.

## 세 단계로 시작하기

1. **탐색**: '탐색'을 열고 분류를 고르거나, 검색창에 키워드·링크·품번을 입력합니다.
2. **읽기와 보기**: 작품을 열고 주 버튼을 누릅니다. 마음에 드는 작품은 '즐겨찾기'에 추가하세요.
3. **이어 보기**: '탐색 → 이어 보기 → 전체'에서 기록을 확인하고, 새 회차는 '즐겨찾기 → 업데이트'에서 볼 수 있습니다.

로그인이나 프록시가 필요한 사이트는 '더 보기 → 사이트'와 '더 보기 → 네트워크'에서 설정합니다.

플러그인 업데이트는 바로 업데이트할 수 있는 개수와 앱 업그레이드가 필요한 개수 및 최소 버전을 표시합니다. 호환되지 않으면 설치된 플러그인을 유지합니다. 앱과 플러그인 업데이트에서 다시 알리지 않기를 선택하면 해당 버전 알림만 중지합니다. 수동 확인에서는 계속 표시되며 새 버전은 다시 알립니다.

Windows, macOS 및 Debian 계열 Linux에서는 앱 내 업데이트를 확인하면 설치 파일을 다운로드하고 검증한 뒤 설치 프로그램을 열고 앱을 종료합니다. 시스템 안내에 따라 설치를 완료하세요. 다른 Linux 배포판에서는 압축 파일을 직접 다운로드하세요. Windows 포터블 ZIP과 Linux tar.gz의 최상위 폴더는 `HentaiPark`이며, macOS ZIP에는 `HentaiPark.app`이 들어 있습니다.

SOOP은 라이브, 숏폼, 다시보기를 별도 소스로 제공합니다. 섹시 댄스, 섹시캠, 비키니 또는 란제리 태그가 명시된 관련 콘텐츠만 포함하며 일반 예능은 제외합니다. 일부 동영상은 원본 사이트의 인증 또는 구독이 필요합니다.

라이브는 3차원에 속하며 녹화와 크리에이터 커뮤니티 사이에 표시됩니다. 홈과 카테고리 카드는 이미지만 표시합니다. 라이브 다운로드는 제공하지 않습니다. 상세 페이지나 플레이어에서 녹화를 시작하거나 중지하고 다운로드에서 관리할 수 있습니다. 녹화를 시작한 뒤 생성된 새 세그먼트만 저장합니다. Android는 백그라운드 녹화를 지원하고 데스크톱은 창을 숨겨도 계속 녹화합니다. 앱을 종료하면 중지되며 다시 실행해도 자동 재개하지 않습니다. 중단 전에 저장한 내용은 유지됩니다. 백그라운드 녹화는 시스템 절전 정책과 포그라운드 서비스 시간 제한을 받으며 중단 시 저장된 내용은 유지됩니다. iOS는 지속적인 백그라운드 녹화를 지원하지 않습니다. TS 및 fMP4 형식의 라이브 재생과 녹화를 지원합니다.

발견 화면에서 2D, 3D 또는 전체로 분류를 필터링하며 선택은 저장됩니다. 게임은 2D, 소설은 3D에 속하고 창작 커뮤니티는 항상 표시됩니다.

크리에이터 커뮤니티는 Pixiv, Reddit, X, myfans.jp, pixivFANBOX, Telegram 순이며 로그인하지 않은 사이트도 표시합니다. Pixiv와 myfans.jp는 익명 검색과 순위를 제공합니다. X 익명 검색이 제한되면 로그인 후 다시 시도하세요. 공개 작가나 채널의 이름 또는 링크를 입력한 뒤 열기를 누르세요. myfans.jp는 제공된 전체 영상을 우선 재생하고 없으면 공개 미리보기를 재생합니다. 제한된 사진은 원본 사이트의 흐림 효과를 유지합니다. 원본 사이트 로그인만 제공하는 경우 회원 콘텐츠는 해당 사이트에서 확인하세요. myfans.jp는 기본적으로 일반 성인 모드를 사용하며, 홈에는 공식 사이트의 Pickup 엄선 콘텐츠를, 순위에는 일간 순위를 표시합니다.

Reddit 커뮤니티 구독 추가를 확정하면 현재 계정으로 원본 사이트의 커뮤니티에 가입합니다. X 작가 구독 추가를 확정하면 X에서 해당 작가를 팔로우합니다. X 커뮤니티를 보기만 해서는 가입하지 않습니다.

홈과 크리에이터 커뮤니티 페이지에서 앨범을 열어 원본 사이트에서 제공하는 사진과 동영상을 이어서 볼 수 있습니다. 유형과 날짜로 필터링하고 행당 개수를 선택하거나 같은 게시물의 미디어를 접을 수 있습니다. 동영상은 썸네일로 표시합니다. 작품에서 돌아오면 앨범 위치가 유지됩니다.

소설 목록은 제목, 작가, 소개, 날짜, 분류 태그를 통일된 형식으로 표시하며 원본 사이트에 없는 정보는 생략합니다.

'더 보기 → 사이트'에서 사이트를 켜고, 순서를 바꾸고, 업데이트하거나 추가할 수 있습니다.

사이트 화면에서 원본 사이트가 지원하는 분류, 태그, 등급과 정렬을 사용하고 검색 화면에서도 해당 필터를 이용할 수 있습니다. 큰 목록은 범위나 그룹을 먼저 선택하세요. 상위 조건을 바꾸면 하위 선택이 지워집니다. 목록 로드 실패는 재시도할 수 있으며 로그인과 인증 등 원본 접근 조건은 그대로 적용됩니다.

## 이미지 역검색

| 용도 | 서비스 |
| --- | --- |
| 종합 이미지 출처 (완전 일치) | Google Lens |
| 종합 이미지 출처와 유사 이미지 | Yandex, Baidu |
| 애니메이션 작품·회차·시간 | trace.moe |
| 애니메이션 및 Galgame 캐릭터·작품 | AnimeTrace |
| 일러스트 출처 | IQDB |
| 성인 갤러리 출처 | E-Hentai |
| JAV 장면으로 품번 검색 | AVScan |

Baidu는 유사 이미지와 출처 링크만 반환할 수 있습니다. E-Hentai은 공개 갤러리만 검색하며 크기 조절이나 자르기 후에는 일치하지 않을 수 있습니다.

서비스를 일반, 동인지, 성인 애니, JAV 분류로 세로 배치하며, 분류에 걸쳐 여러 서비스를 선택할 수 있습니다.

발견 상단에서 이미지 역검색을 열면 기본으로 Google Lens만 선택됩니다. 여러 서비스를 선택해 함께 검색할 수 있습니다. 이미지를 선택하고 필요하면 자른 후 검색하세요. 후보가 있는 사이트만 표시되며 사이트를 전환해 각 결과를 볼 수 있습니다. 원본 사이트를 열거나 작품명·품번으로 리소스를 검색할 수 있습니다. 검색 버튼을 누를 때만 선택한 서비스에 이미지가 업로드됩니다.

각 사이트는 기본으로 후보 20개를 표시하며, 전체 결과 보기를 선택하면 나머지를 불러옵니다.

Google Lens는 백그라운드에서 이미지를 업로드하고 출처를 가져옵니다. 모든 이미지 역검색은 앱 화면에 진행 상황과 결과를 표시하며 사이트 인증도 백그라운드에서 시도합니다. 완료되지 않으면 앱 안에서 재시도할 수 있습니다. 일부 네트워크에서는 VPN 또는 프록시가 필요할 수 있습니다.

결과는 확인이 필요한 후보이며 유사도가 확정을 뜻하지 않습니다. trace.moe는 무료 할당량이 제한되고 IQDB는 혼잡 시 대기할 수 있습니다. AVScan은 개인 비상업 용도에 한합니다. 각 서비스의 후보, 제공된 점수 및 관련 이미지를 유지합니다. 원본 사이트 정보를 펼치면 시간대, 인식 영역, 태그 등 원본 필드를 볼 수 있습니다. 모든 작품의 수록을 보장하지 않으며 캐릭터 인식이 게임 다운로드를 제공하지는 않습니다.

## 순위

| 분류 | 사이트 |
| --- | --- |
| 판매 순위 | FANZA、MGStage、FC2、天然むすめ、パコパコママ、Caribbeancom、一本道、DLsite、Toranoana |
| 사이트 순위 | E-Hentai、JM、nhentai、WNACG、Hanime1、MissAV、JableTV、SupJav、JavMenu |

작품·배우·판매자·분류별 판매 순위와 각 사이트의 인기 순위를 제공합니다. 작품 검색, 상세 정보 및 원본 사이트를 이용할 수 있습니다.

순위에서 필터와 제목 번역을 사용할 수 있습니다. 표지는 원래 비율을 유지하며 긴 제목은 클릭하여 펼칠 수 있습니다.

iXXX와 TubeSafari의 지원되는 출처는 네이티브 재생을 우선하며 이어 보기와 오프라인 저장을 지원합니다. 지원되지 않는 출처는 앱 내 웹 재생을 사용합니다. 웹 재생은 사이트 확인이 필요할 수 있으며 앱 다운로드와 정확한 이어 보기를 지원하지 않습니다. Android 웹 재생에는 격리 세션을 지원하는 최신 Android System WebView가 필요합니다.

SWAG 무료 숏폼은 네이티브 플레이어로 화질 선택, 이어보기 및 오프라인 저장을 지원합니다. 유료 잠금 해제가 필요한 영상은 제외됩니다.

## 자주 묻는 질문

**사이트가 열리지 않거나 이미지·동영상을 불러오지 못해요.**
먼저 네트워크를 확인하세요. 중국 본토에서는 VPN이나 프록시가 필요한 사이트가 있으며 더 보기 → 네트워크에서 설정할 수 있습니다. 사이트 인증은 백그라운드에서 자동 시도하며 완료되지 않으면 앱 안에서 재시도할 수 있습니다.

처음 사용할 때 면책 고지를 읽고 성인임을 확인하며, 확인은 기기에 저장됩니다. 지원하는 연령 확인과 Cloudflare 인증은 백그라운드에서 처리하고 로그인만 사이트 화면 조작이 필요합니다. Windows는 표준 Cloudflare 체크박스 자동 클릭을 지원합니다. 다른 플랫폼은 자동 인증을 시도하며 실패하면 앱 안에서 재시도합니다.

JM과 PicACG는 사용 가능한 연결 경로를 자동으로 탐색합니다. 외부 IP가 이전과 같다고 확인된 경우에만 저장된 경로를 재사용하며, 변경되었거나 확인할 수 없으면 다시 탐색합니다. 제3자 공용 IP 조회 서비스를 사용하지 않습니다. 서버를 직접 선택할 수도 있습니다.

**사이트 계정이 필요한가요?**
대부분 필요 없습니다. 로그인이 필요한 사이트는 사이트 페이지 상단에 안내가 나오며, '더 보기 → 사이트'의 사이트 설정에서 로그인할 수 있습니다. Pixiv, X, StoriesOnline의 웹 로그인은 Google, Apple 등 외부 계정을 지원하지만, 내장 브라우저 허용 여부는 각 서비스가 결정합니다.

**앱이 대신 글이나 댓글을 올리나요?**
자동으로는 하지 않습니다. 차원 찻집의 일부 자료는 댓글을 달아야 열리는데, 앱이 보낼 내용을 먼저 보여 주고 확인한 뒤에만 보냅니다.

**휴대폰을 바꿔도 즐겨찾기와 진행 상황을 유지하려면?**
'더 보기 → 백업'에서 `.parkbak` 파일을 내보내고 복원하세요. 백업 생성 시 '사이트 로그인 및 인증 상태'를 선택하면 Cookie, Token 및 사이트 인증 상태도 저장됩니다. 파일은 암호화되지 않으므로 안전하게 보관하세요. 다운로드는 포함되지 않으며 만료되거나 기기에 연결된 세션은 다시 인증해야 할 수 있습니다.

**번역할 때 무엇이 전송되나요?**
제목, 소개, 태그, 검색어, 선택한 텍스트 또는 소설 전문을 번역하면 해당 내용이 Google 번역으로 전송됩니다. 계정, 쿠키 및 읽기 기록은 전송되지 않습니다. 대상 언어는 앱 언어를 따릅니다.

**문제를 신고하려면?**
[Issues](https://github.com/drdon1234/Hentai-Park/issues)에 앱 버전, 사이트 이름, 재현 방법을 적어 주세요. 스크린샷에서는 계정과 개인적인 내용을 가려 주세요.

공개 제보에 비밀번호, Cookie, Token, 세션 내보내기, 앱 백업, 네트워크 캡처 또는 서명 매개변수가 있는 전체 링크를 첨부하지 마세요. 로그는 앱에서 내보낸 민감 정보 제거 보고서만 공유하세요.
