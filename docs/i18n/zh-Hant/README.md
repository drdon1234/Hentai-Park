## 下載

在 **[最新版本](https://github.com/drdon1234/Hentai-Park/releases/latest)** 下載 Android APK。大多數手機和平板選 `arm64-v8a`，模擬器一般選 `x86_64`。

## 三步上手

1. **發現**：開啟「發現」，選一個分類，或在搜尋框輸入關鍵字、貼上連結或番號。
2. **閱讀與播放**：開啟作品，點主按鈕開始；喜歡的加入「書架」。
3. **接著看**：「發現」頂部的「繼續看」和「歷史」會帶你回到上次的位置；追更的作品在「書架 → 更新」。

需要登入或代理的站點，在「我的 → 站點」和「我的 → 網路」中設定。

## 功能

| 功能 | 說明 |
| --- | --- |
| 排行榜 | 從「發現」開啟本子、里番、JAV 榜單，切換站點與週期，搜尋作品或開啟原站 |
| 發現與搜尋 | 依分類瀏覽，多站同時搜尋，可用多種語言的關鍵字擴大範圍；貼上連結或番號直達作品 |
| 閱讀與觀看 | 漫畫捲動、翻頁或雙頁；影片選集、倍速與續播；小說排版、書籤、標註與朗讀。三種閱讀器使用同一套控制層 |
| 書架 | 收藏分類、更新提醒、下載管理集中在「書架」；訂閱作者、頻道或關鍵字的新內容 |
| 離線 | 下載漫畫、影片與小說；匯入、匯出 CBZ |
| 遊戲資源 | 查看遊戲介紹、版本與下載連結 |
| 翻譯與過濾 | 翻譯標題、簡介與標籤；依標籤遮蔽內容 |
| 隱私與備份 | 應用鎖、無痕模式、封面模糊、防截圖；備份收藏、進度與設定 |

淺色與深色主題，八種介面語言。每個站點可用的功能以應用內顯示為準。

商業榜來源包含 FANZA、FC2、MGStage、四個無碼廠商、DLsite 同人漫畫與成年漫畫、虎之穴。銷量、廠商人氣和站內熱度分別標示。商業榜提供對應分類搜尋與商品原站連結，閱讀和播放以搜尋到的內容站點為準。

原始碼繼續在主分支維護，普通插件由 `sources` 分發，獨立排行榜插件由 `rankings` 分發。兩分支只保存指向固定原始碼提交並含 SHA-256 的索引。工作流分別驗證和發布兩頻道；應用獨立讀取，拒絕頻道標記不符與重複 key，沿用更新確認流程。

iXXX、TubeSafari 使用應用程式內網頁播放。播放頁可能仍需站點確認；播放控制由上游頁面提供，暫不支援應用程式的下載與精確續播。Android 需要支援獨立工作階段的較新版本 Android System WebView。

## 常見問題

**站點打不開，或圖片、影片載入失敗？**
先檢查網路。部分站點在中國大陸可能需要 VPN 或代理，可在「我的 → 網路」設定代理。遇到網頁驗證時，依提示在內建瀏覽器中完成一次即可。

**需要站點帳號嗎？**
大多數不需要。需要登入的站點會在站點頁頂部提示，也可在「我的 → 站點」開啟該站點的設定登入。Pixiv、X、StoriesOnline 的網頁登入支援 Google、Apple 等第三方帳號授權，是否放行內嵌瀏覽器由第三方平台決定。

**會替我在站點上發文或回覆嗎？**
不會自動這樣做。次元茶館的部分資源需要回覆才能解鎖，應用會先顯示將要發送的內容，經你確認後才發送。

**換手機怎樣保留收藏和進度？**
在「我的 → 備份」匯出備份，在新裝置上恢復。離線下載不在備份中，站點帳號可能需要重新登入。

**翻譯會上傳什麼？**
只有你點了翻譯的標題、簡介和標籤會傳送給所選的翻譯服務。「我的 → 搜尋與翻譯」中寫明了資料去向。

**怎樣回報問題？**
在 [Issues](https://github.com/drdon1234/Hentai-Park/issues) 寫明應用版本、站點名稱和重現步驟；截圖前請隱藏帳號和私人內容。
