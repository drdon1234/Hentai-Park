## 酒場の会話

Chub AI、Character Tavern、RisuRealm から取得したり、「保存済みと会話」から PNG／JSON カード、JSON 世界設定集、本アプリの会話ファイルを個別に読み込んだりできます。Character Tavern は並べ替え、タグの包含・除外、トークン長、ワールドブックとオリジナルコンテンツの絞り込みに対応します。RisuRealm は公開検索ページと公式のゲスト用ダウンロード API のみを使用し、独立した NSFW フィルターは公開されていないため原サイトの成人表示を保持します。

酒場のライブラリではキャラクターカードとワールドブックを作成し、読み込んだ素材も編集できます。AI 作成では説明と修正対象の下書きを選択したモデルへ送信します。追加の変更を依頼し、下書きを確認してから保存できます。ワールドブックでは例文で発動条件をテストできます。会話設定では記憶の編集と、今回開いてから最後に送ったプロンプトの確認ができます。 編集中の下書きはこの端末に保存され、同じバージョンを開くと再開できます。世界書は構成案を作ってから項目を複数回に分けて生成し、採用する変更を個別に選べます。発動テストには一致したキーワードと項目が選ばれなかった理由が表示されます。

キャラクターには PNG 画像を設定でき、AI で個別の項目を書き直せます。他の世界書の項目を下書きに取り込めます。直近 8 件のテキスト変更履歴から変更項目を確認し、下書きに戻して保存できます。会話ごとに話者、タグ、メモ、記憶を設定できます。要約を生成するとメッセージと既存の記憶が選択したモデルに送信され、適用すると記憶が更新されます。

OpenAI 互換の AI サービスを設定すると、挨拶、会話ごとの名前とペルソナ、ワールドブックを選べます。メッセージ編集、指定箇所以降の削除、分岐、再生成、返信候補の切り替え、最後の返信の続きに対応します。Markdown を表示しますが、スクリプトや画像の自動読み込みは実行しません。会話の書き出しにはキャラクター、ワールドブック、ペルソナとメッセージが含まれ、API キーは含まれません。ファイルは暗号化されないため、安全に保管してください。

シークレットモードでは新規・既存の会話の変更を保存しません。一度有効にした会話では解除後も私的なメッセージを書き戻しません。明示的な読み込み、書き出し、リソース保存はデータを書き込みます。メッセージ、キャラクター設定、ペルソナと該当するワールドブック内容は選択した AI サービスへ送信され、料金が発生する場合があります。コンテキストは入力と出力を含み、履歴は保守的な推定で削減します。出力上限の警告が出たら設定を調整して再試行または続きを生成できます。

キーワード、常時有効、大文字小文字、単語一致、副キーワード論理、確率、検索深度、再帰、予算、優先度、キャラクター設定前後への挿入に対応します。正規表現キー、グループ、クールダウン、遅延、持続やその他の挿入位置は未対応で、検出時に警告します。元データは保持されます。複雑な SillyTavern 拡張カードは同じ動作を保証しません。

通常モードでは会話と入力下書きを自動保存し、履歴やキャラクターカードから再開できます。巻き戻しは選択したメッセージを残して以降を削除し、分岐は元の会話を残して独立した会話を作成します。システム Prompt を編集でき、初期値は画面の言語での返信を指定します。既定値はコンテキスト 65,536、出力 4,096 Token で、保存済みの上限は変更しません。強制終了では直近の未保存内容が失われる場合があります。

独立した世界設定の詳細からローカル保存と元ファイルの書き出しができます。お気に入り登録とは別の操作です。会話の世界設定選択画面で JSON を読み込むと自動選択され、保存を確定すると関連付けられます。オンライン閲覧中に新しく保存した世界設定も、戻ると自動選択され、保存を確定すると関連付けられます。選択を取り消しても、読み込み済み・保存済みのリソースは削除されません。
