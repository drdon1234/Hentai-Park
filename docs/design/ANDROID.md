# 安卓设计准则

本文件记录 Android 手机与平板的具体设计规则，与[公共设计准则](../DESIGN.md)共同使用。公共准则负责任务、语义、状态与设计方法，本文件负责视觉令牌、组件、页面结构及安卓交互；这些细则不作为 Web 或 Windows 的已验收设计。

规则依据当前安卓实现和已确认的设计整理；后续替换方案直接修改对应条目，不并存已经废止的设计。工程实现与数据契约见[开发说明](../DEVELOPMENT.md)及[插件协议](../SOURCE_API.md)。

## 视觉方向

- 内容使用暖中性背景与逐级表面色，阴影用于详情封面、菜单和浮动阅读面板；不用装饰性渐变与大面积色块。
- 一个强调色用于主要动作、进度、未读及选择态；未选中的控件采用中性填充。
- 控件用胶囊，封面用小圆角，成组列表用中圆角，弹层用大圆角；同类组件保持一致。
- 大标题、作品标题和小说正文使用衬线，控件与元数据使用无衬线。

令牌与组件位于 `lib/ui/theme.dart` 和 `lib/ui/kit/`；`tools/check_styles.mjs` 约束 Flutter 界面使用现有令牌。检查通过不代表其他平台已经完成设计或验收。

## 令牌

### 颜色

界面表面、文字与状态颜色来自 `ColorScheme`（由 `ParkTheme` 手写），界面代码只用角色名（`surface`、`onSurfaceVariant`、`primary`…），不写色值。`SourceAvatar` 可使用插件声明的站点品牌色识别内容来源，并按亮度选择前景；品牌色不用于页面表面、操作或选择态。

| 角色 | 暗色（默认） | 亮色 |
| --- | --- | --- |
| 背景 `surface` | `#11100F` | `#F5F3EF` |
| 卡片与成组列表 `cardColor` | `#1E1D1A` | `#FFFFFF` |
| 表面（逐级 low / container / high / highest） | `#181715` / `#1E1D1A` / `#272522` / `#312F2B` | `#EFEDE8` / `#EAE7E1` / `#E4E1DA` / `#DCD8D0` |
| 正文 `onSurface` | `#ECE9E3` | `#1F1E1C` |
| 次要文字 `onSurfaceVariant` | `#A39E94` | `#625E57` |
| 细线 `outlineVariant` | `#34322E` | `#E0DCD4` |

- 浅色填充（次级按钮、未选中的芯片与分段、输入框）在暗色主题用 `surfaceContainerHighest`，亮色主题用 `surfaceContainerHigh`；选中状态统一用 `secondaryContainer` / `onSecondaryContainer`（强调色调）。
- 选择型下拉菜单不显示勾号，也不为勾号预留空间；当前选项统一使用 `secondaryContainer` / `onSecondaryContainer` 着色。纯操作菜单不显示选择态。
- 弹层、对话框和菜单在暗色主题用 `surfaceContainerHigh`，亮色主题用白色，比页面高一级。

- 强调色默认“陶土”（种子色 `#C96442`），用户可在“我的 → 外观”中换成琥珀、青苔、靛蓝、梅紫、樱粉。`ParkTheme` 按明暗主题自动调整 `primary` / `onPrimary`，保证强调色小字在界面表面上，以及实心按钮文字的对比度达到 WCAG AA（4.5:1）。
- 应用自定义的非配色方案固定色只有两类，定义在 `kit/tokens.dart`：`Scrims`（图片与视频上的遮罩、遮罩上的白色文字，以及浮在画面上的半透明控件 `control`）和 `ReaderPalette`（阅读器背景、护眼暖光、小说主题）；站点品牌色属于插件内容数据。
- `Colors.black`、`Colors.white`、`Colors.transparent` 只用于图片遮罩和沉浸式阅读器。

### 文字

- 字号只用 `TextTheme` 的样式（`headlineSmall`、`titleMedium`、`bodyMedium`、`labelSmall`…），不写 `fontSize`。小说正文的字号来自阅读设置，通过 `ParkText.novel(...)` 生成。
- 字重最高 600，不用 bold / w700 以上。
- 正文和控件使用 Android 平台默认字体，并保留系统字符回退。
- `ParkText.serif(style)`：页面大标题（`PageHeader`）、作品标题、空状态标题等，使用对应平台及语言的衬线字体与系统回退。
- `ParkText.mono(style)`：日志、Cookie、校验值。
- 按钮、页签、筛选项、菜单项和有独立长按操作的列表项使用 `SelectionContainer.disabled` 排除文字选择；简介、正文、日志和输入框保留复制能力。
- 默认页面不创建全页文字选择区；仅在详情简介、帖子详情正文、小说及日志等确有复制需求的内容边界内创建选择区。使用 `TextSelectionGuard` 限制起选位置，仅从实际文字行框开始选择，空白处和行尾空白不得吸附到其他区域；起选后保留内容区域内的跨行、跨段拖选。

### 间距、圆角、动效

| 令牌 | 值 |
| --- | --- |
| `Gap.xs` / `s` / `m` / `l` / `xl` / `xxl` | 4 / 8 / 12 / 16 / 24 / 32 |
| `Gap.page` | 16：页面左右边距 |
| `Radii.tiny` / `small` / `medium` / `large` | 6（角标、小标签）/ 10（封面、缩略图）/ 16（成组列表、卡片、输入框）/ 24（底部弹层、对话框、阅读器底栏） |
| `Radii.pill` | 胶囊：按钮、筛选项、搜索框、分段 |
| `Motion.short` / `medium` / `long` | 150 / 250 / 380 ms |
| `Motion.curve` / `emphasized` | 退出与普通变化用 `curve`（easeOutCubic）；进入、展开与弹层用 `emphasized`，快起慢落 |

普通页面的内容与操作统一保留左右 `Gap.page` 留白，并使用同一对齐边界。横向书架、域导航和关键词栏通过 `PageGutter` 将留白放在滚动视口外，滚动过程中也不得侵入两侧留白；已有外边距的嵌套内容不重复添加。沉浸式阅读与播放画面沿用各自的控制层规范。

动效时长通过 `Motion.of(context, …)` 取得，系统开启“移除动画”时为零。动效只表达状态：页面进入、弹层出现、控制层显隐、选中切换、空状态出现（`FadeIn`）；不做装饰性循环动画。

## 组件

| 组件 | 用途 |
| --- | --- |
| `PageHeader` | 一级页面的标题栏：衬线大标题 + 右侧动作。需要附加信息时放在 `bottom` 里，不要改变标题行的位置 |
| `HeaderTabs` | 标题位置的分段（如收藏页的“收藏 · 更新”），可带未读数 |
| `SectionHeader` | 区块标题，右侧可放“更多”“全部”等文字按钮 |
| `ListRow` / `RowGroup` | 设置和列表的行；`RowGroup` 把一组行放在一块圆角表面上，行间用细线分隔，标题在表面上方，可带 `footer` 说明。页面已有左右边距时传 `margin: EdgeInsets.zero`，内部行仍保留 `Gap.page` 内边距 |
| `HairlineItem` | 可拖动排序列表中的一行（带细线） |
| `CoverTile` / `CoverTileSkeleton` | 作品封面：封面上最多一层角标，标题与元数据在封面下方；有进度时显示进度条；封面带极淡的内描边 |
| `Tag` | 小标签（分类、状态）：浅色填充；在封面上用遮罩底色 |
| `MenuChip` | 打开选项菜单的胶囊（历史、搜索的分类与站点范围，相册每行数量）；已收窄范围时用强调色调 |
| `ToolbarButton` | 页面工具区的轻量文字操作，可带 18 dp 图标；统一字号、间距和至少 48 dp 点击区域，用于媒体模式入口、日期、显示切换、批量操作、简介展开等 |
| `EmptyState` | 空状态与错误状态：圆形底色中的图标 + 衬线标题 + 说明 + 可选操作，出现时淡入；`compact` 用于页面中的区块 |
| `ParkSearchField` | 发现页和搜索页共用的搜索框；只读时作为入口 |
| `confirmAction` | 确认对话框；删除等不可撤销操作用 `destructive: true` |
| `showChoiceSheet` | 从一组选项中选一个的底部弹层（清晰度、倍速、设置项的取值） |
| `ParkRefresh` | 下拉刷新，开始刷新时轻触感，不额外占用内容上方的一行 |
| `ReaderChrome` | 漫画、小说的沉浸控制层：点中间显示，顶部标题与动作，底部进度放在离开屏幕边缘的圆角浮动面板中（带细边与轻投影，深色页面上也能看清）；叠加在内容上，不重排正文 |
| `VideoControls` | 视频独立控制层：顶部标题、中央圆形播放键（多集全屏时两侧为上一集、下一集）、底部时间轴与操作；遮罩从屏幕边缘多段渐隐，清晰度与倍速是无描边的半透明胶囊，直播显示红点“直播”标记 |
| `ImmersiveRegion` | 阅读器和短视频页面登记为沉浸页面，期间应用不在系统导航栏下方画自己的底色条，由页面背景延伸到屏幕底部 |
| `ReaderProgress` / `ReaderBadge` / `ReaderChapterEnd` | 阅读器底部进度、页码角标、章节末尾 |

## 按钮

页面工具区使用 `ToolbarButton`，统一名称、图标、字号与点击区域；标题栏带名称的动作复用同一组件，放不下时进入“更多”。只需图标的工具使用带提示的 `IconButton`。提交、确认、错误恢复及可选择的筛选项保留各自层级。

- **主按钮**（`FilledButton`，强调色胶囊）：每屏最多一个，用于最主要的动作（继续/阅读/播放、保存）。
- **次级按钮**（`OutlinedButton` 的主题样式）：浅色填充的胶囊，不画描边，靠底色形成边界；键盘焦点时显示强调色描边。详情页的收藏、下载、更多是同样填充的圆形按钮，激活时换成强调色调。加载、重试等内容区恢复操作使用可辨识的填充边界；区块的“全部”“更多”、简介展开和批量操作遵循工具按钮层级，相邻按钮留出间隔。
- 画在图片、视频或阅读背景上的次级按钮不用应用主题的填充色，改用前景色约 10% 的半透明填充（视频上用 `Scrims.control`），保证在任何画面与阅读主题上都协调。
- **文字按钮**（`TextButton`）：用于平台原生对话框、导航及低优先级文字操作；页面工具操作遵循 `ToolbarButton` 的中性前景样式，其他文字操作使用可辨识的强调色；不把与正文同色的裸文字作为内容区唯一入口。原生返回、搜索等工具栏图标保留平台形态；可进入的设置或章节行使用箭头、播放图标等提示。
- 可点击控件靠浅色填充与文字本身识别，开关未选中时的轨道轮廓使用 `outline`。静态标签用更小的圆角与更淡的填充，分隔线使用 `outlineVariant`，避免与可点击控件混淆。禁用状态降低对比度，键盘焦点使用加粗强调色边框。
- 文字选择项统一使用 `SelectionChip`，文字居中，不为勾号预留空白；选中状态通过强调色调填充、强调色文字与加粗共同表达，保留读屏选中语义，切换时不得改变按钮尺寸或使同组选项换行。原生筛选按钮遵循同一主题规则；站点、颜色等有实际含义的图标正常保留。分段按钮是一条浅色轨道，选中段用强调色调填充，不画描边与分隔线；保留各项的功能图标，不用勾号替换。
- **图标按钮**：只用于通用图标，必须提供 `tooltip`。
- 标签按用途区分：`Tag` 为无交互的小号元数据（小圆角）；`ActionTag` 为可搜索、可长按的内容标签，胶囊形，约 28 dp 的紧凑视觉与点击区域，组间留白保持可辨识；`SelectionChip` 为紧凑筛选项，选中时使用强调色调。标签不承担保存、更新等页面操作。
- 破坏性操作的确认按钮用错误色。

## 页面与交互

### 导航与通用布局

- 一级导航四项：发现 / 收藏 / 下载 / 我的。完整浏览历史从发现页“继续看 → 全部”进入。Android 手机使用底部导航，平板在宽度 ≥ 840 dp 且短边 ≥ 600 dp 时使用侧栏。手机横屏不因宽度增加而变成侧栏导航。作品详情通过完整路由打开，宽屏下封面、元信息和正文按可用空间重新排版。
- Android 使用 Material 控件。一级大标题与二级标题栏保持左对齐；工具栏放不下时收进带文字的“更多”菜单，不能挤掉标题或让操作消失。紧凑窗口的选择与操作面板采用底部弹层，宽屏面板居中，长内容在面板内滚动。
- 一级页面用 `PageHeader`，二级页面用普通 `AppBar` 或页面自己的头部（详情页）。
- 页面左右边距统一 `Gap.page`。窄屏、大字体、文本展开和长列表滚动都要检查。
- 同页的说明、区块标题、筛选项和列表使用同一内容边界；外层已设置页面边距时，内部列表行不再重复叠加页面边距。控件内部间距和图标触摸区域独立处理。
- 同一行的短标签、按钮与图标按垂直中心对齐；正文段落与多行说明按阅读顺序排列。相关操作与正文之间使用一致的 `Gap.m`，相邻按钮至少留出 `Gap.s`，标题与右侧操作留出 `Gap.m`，不能紧贴或依赖文字自身空白。
- 操作区优先形成规整的一行或整行按钮，统一左右边界、按钮高度与组内间距，避免短按钮、悬空标签和不同缩进拼成零碎结构。简介展开与收起按钮独占整行且内容居中，按钮到上方正文和下方元信息均为 `Gap.m`；作者等标签与对应可点击标签居中对齐。
- 手机与平板使用一致的内容密度与留白标准。区块高度由内容决定，不用固定大高度、重复边距或弹性占位拉开相关信息；空状态靠近页面内容起点，说明与下一步操作成组出现。宽屏使用合适的列数、分栏及内容最大宽度，不能把手机结构放大后留下无用途的空洞；内容自然结束后的剩余视口不靠装饰或无关内容填充。短文本弹层按内容收紧，长文本限制高度并在正文区滚动；阅读与收藏设置的分页面板随当前页内容收紧，长页独立滚动并保留位置，滑动方向遵循界面语言；页面已有刷新入口时，共享组件不为同一操作另占一行。

### 发现与站点浏览

- 默认域顺序为三次元美图、二次元美图、本子、里番、JAV、成人视频、短视频、AI短剧、录播、直播、创作社区、小说、游戏。直播归入三次元。主页和域页的直播卡片只显示封面，不叠加文字、角标或点播进度，也不预留标题高度。详情和播放器提供开始、停止录制入口；直播不显示下载、倍速或可拖动进度。录制独立于播放器，离开播放页或切到后台后继续，停止或退出应用后结束；下载页显示录制状态和已保存内容，支持分卷回放与删除。
- 主页固定筛选栏与下方滚动内容之间保留至少 `Gap.s` 的不滚动留白。总览在“全部站点”与首个域之间展示可横向滚动的域卡片，订阅卡片固定在首位；进入域或订阅后保留可切回总览的域导航。
- 发现页在域导航上方并排提供“内容范围”和“媒体类型”两个下拉筛选，同时作用于主页域展示与聚合搜索范围，默认均为全部并记住选择。内容范围为全部、二次元、三次元，媒体类型为全部、图片、视频、其他；菜单使用统一选择态。窄屏和大字体时，各入口内部的标题与当前值可上下排列，不挤掉另一入口。三次元美图在二次元美图之前，游戏归二次元，小说归三次元，创作社区不限维度；切换后当前域不匹配则回到总览，外部打开隐藏域时恢复全部筛选。
- 主页各域默认只展示首个站点，可独立展开为全部站点并记住选择；保留首站选择及进入域页的入口。主页和域页通过眼睛按钮控制各站作品的显示与自动加载，设置在两处同步；关闭后使用带恢复按钮的紧凑站点行，不预留封面、标题或骨架卡片的空间。省流量模式仍只显示站点入口。
- “全部站点”按域纵向分组，域标题右侧复用主页的“进入域”按钮；点击切换到发现页的对应域，保留已有域页状态。
- 站点浏览页在入口页签右侧提供漏斗筛选、仅预览作品显示与卡片/单行切换，控制项不独占内容行。默认卡片，单行列表在封面右侧展示标题、作者、分类、语言、页数或时长、评分、标签和更新时间等已有信息，缺失字段不占位；切换展示不重新请求内容。屏蔽、预览和站点可见性等开关立即显示底部悬浮提示，约三秒后消失，连续操作只展示最新状态。
- 相册、短视频模式入口只在创作社区按站点声明的能力显示，站点浏览、站内搜索、订阅与主页入口一致；其他域不因视频类型而出现帖子媒体模式。入口采用小图标加名称的轻量文字按钮；浏览页与筛选排序按钮共用左对齐、可换行的工具区。
- 站点管理提供手动单次测速：只调整资源站点在发现、站点列表及全站搜索中的显示顺序，不改写默认或手动顺序，排行榜与图片反搜不参与。完整探测后统一应用，允许取消及恢复原显示顺序；结果仅当前运行有效，主页手动指定首站仍优先。启动、恢复前台及网络变化均不自动探测。

### 搜索、筛选与图片反搜

- 搜索页的多语言搜索按钮始终与输入框同行，使用 `g_translate_rounded`；搜索页不显示内容自动翻译入口，也不自动翻译结果。漏斗仅表示站点筛选；仅预览作品开关使用预览图标并说明它控制没有完整内容的作品。筛选面板复用于站内搜索与浏览入口，条件按站点及入口分别声明。联想候选显示原站关键词，只有支持命名空间的站点才插入前缀，聚合候选标注来源并进入对应站点搜索。
- 关键词联想采用防抖、取消和请求代次校验；输入法组词期间不发起联想，相同输入不重复请求，联想失败不阻止正常搜索。筛选面板支持草稿、应用与恢复默认，数字条件直接输入，关闭未应用的面板保持原条件。
- 图片反搜服务按通用、本子、里番、JAV纵向分组，分组标题和服务选项直接展开，允许跨分类多选；服务选择区提供全局全选，每组另提供仅影响当前组的全选，全部选中时均切换为取消全选。站点名称使用英文品牌名，不重复添加识图后缀。
- 反搜站点说明与网络提示绑定对应站点，通过长按查看，不在选择区底部堆叠说明或显示无归属的网络提示。已选图片区域仍可点击换图，新图准备成功后才替换原图与清除原识别结果。结果区接入统一内容翻译与划词翻译，搜索词和原站链接保留原值。
- 反搜结果每站默认显示前 20 条，较多结果提供“查看全部结果”，只续载当前站点且按站点保留展开状态；失败时保留预览并提供重试。

### 详情、排行榜与资料

- 普通手机默认字号下，竖版封面与作品信息并排，使首屏能直接看到阅读、收藏等操作；实际可用宽度不足或字体放大后再上下排列。横版视频封面在手机上独占一行，宽屏按内容重新排版。
- 宽屏详情把标题、操作、简介和元信息集中放在封面旁，封面按比例限制尺寸，避免高封面把正文与按钮整体推到下方、右侧只剩空白。字体放大或窗口缩窄后按阅读顺序恢复纵向排列。
- 排行榜作品条目直接提供“详情”和独立榜单的“搜索”文字按钮，原站使用与站点设置相同的外链图标按钮，位于作品信息右上角并提供“打开原站”提示。排行榜不单独显示评论入口；支持评论的 JAV 榜单作品在“详情”内查看原榜单站点评论，切换到其他作品后不沿用旧评论。作品封面与“详情”按钮使用同一个入口；没有详情入口时封面不触发搜索。“详情”和“搜索”操作保持同行、等宽、垂直居中，文案或字号放大导致封面右侧空间不足时，整组移到封面与信息下方；不得将常用操作收进菜单或留下孤立的“原站”文字按钮。JAV 作品进入应用内资料页，由独立资料插件解析封面、番号、发行信息、演员、标签、预览图和磁链，缺失字段不占位。资料与磁链分开加载、报错和重试；多个候选由用户选择。页面提供“搜索 JAV 站点”，使用真实番号限定在应用内 JAV 分类搜索；磁链提供复制与调用外部应用打开。其他分类继续打开已有作品详情或原站介绍，人物榜与卖家榜保留“原站”入口。

### 漫画、小说与翻译

- 小说使用无封面的统一作品行，依次显示标题、作者、简介和日期、分类标签，缺失字段不占位。
- 主页和域页的小说推荐纵向预览三部作品，以细线分隔，标题完整换行、简介最多三行；通过“全部”进入完整列表。
- 小说阅读器提供全文翻译并保存、随滚动翻译、随滚动翻译并保存。随滚动翻译默认仅保存在内存，逐段更新并保留原文位置；显示原文或切到后台不取消已启动的全文任务。离开阅读器结束任务，已保存片段可在下次阅读时复用。
- 阅读器仅在前台、未锁定且未被弹层遮挡时接收翻页按键；输入框及带修饰键的组合键不触发翻页。小说从章首向前翻页进入上一章末页。
- 标签翻译包通过与升级一致的弹窗提示下载，提供不再提醒、稍后和立即下载；内容页不放独立下载按钮。统一在“我的 → 搜索与翻译 → 翻译包管理”按站点和语言下载、更新或删除。
- 原生与网页播放页共用内容翻译入口；作品信息、简介和推荐文字沿用全局翻译设置，显示译文不改写原站数据。

### 长视频、短剧与直播

- 播放页的作品信息、同系列和推荐始终位于播放器下方；宽屏平板推荐展开为随空间与字号调整列数的网格，手机保留横向预览。选集统一使用播放器右上角入口，不另设选集栏或播放器同系列切换按钮。手机固定播放器并滚动下方内容；全屏与窗口切换保留播放器状态。
- 视频控制采用顶部标题、中央播放/暂停、底部完整时间轴及操作栏；横竖屏切换与全屏均提供独立的直接按钮，横竖屏按钮在横屏与竖屏全屏间切换，全屏按钮进入或退出全屏并默认按视频比例选择方向。清晰度和倍速位于底栏，仅在窄屏及大字体时收入更多菜单，不重复展示；选集使用右上角带播放列表图标的文字按钮。多集点播全屏在中央提供上一集和下一集。菜单和选择面板打开期间不自动隐藏控制层，播放结束显示重播入口。直播不展示倍速和点播时间轴。
- AI 短剧竖屏全屏滑动吸附完成后才切集；新集稳定播放两秒后释放旧集，期间滑回沿用原进度，缓冲、暂停或后台不计入这两秒。退出全屏始终展示当前集，尚未准备完成时显示加载指示；全屏切换与前后台恢复保留当前画面绑定。亮度、音量调节栏出现时直接显示当前百分比，无需拖动。
- 直播弹幕从右向左滚动，同轨保留间距，文字不截获播放器触摸。播放器“更多 → 弹幕显示区域”提供上方四分之一、上半屏、下半屏与全屏，默认上半屏并保存选择。区域按扣除上下控制栏后的可用画面划分，大字号至少容纳一条完整文字；切换区域清空旧轨道，新消息按所选区域排布。系统移除动画时在同一区域静止显示。
- 内置视频画面双击播放/暂停，单击显示或隐藏控制层，横向滑动调整进度。按住播放器画面临时以 2 倍速播放，松开后恢复原倍速。外接键盘在播放器获得焦点时支持空格或 K 播放/暂停、左右方向键跳转十秒、上下方向键调整 5% 音量、M 静音、F 全屏和 Esc 退出全屏；输入框、弹层和带修饰键的组合键不触发快捷键，播放、静音和全屏切换不响应按键长按重复，直播忽略进度跳转。
- 长视频简介默认显示三行，可展开并重新收起。短视频标题和简介默认分别最多三行和两行；展开后内容区域可滚动，收起按钮始终可见。
- 播放器菜单、清晰度、倍速和选集弹层不暂停播放，操作期间保持控制条；进入其他完整页面时保存进度并释放原页播放器、预加载和媒体会话，返回时重新加载并恢复位置；菜单和弹层不触发释放，后台仍只暂停。换集、换线路保持音量及静音状态。

### 短视频

- 短视频右下角提供“仅视频 / 带信息”轻量按钮，与进度条同排并避开系统安全区；顶部翻译、搜索与更多保持同行。仅视频时隐藏作品信息、收藏、评论、原站互动及其遮罩，保留返回、模式切换、播放与进度操作；切换按钮始终可见以恢复详情。切换不重建播放器、不改变进度，滑到下一条时保留当前显示模式。
- 短视频简介与进度条紧邻排列，随内容高度自然布局；底部操作避开系统安全区。Android 保持系统导航栏可见，黑色播放背景使用浅色导航图标。
- 当前播放优先于预加载，快速滑动时取消与销毁中的资源仍计入额度；清屏、切换显示模式与打开菜单不重建播放器。完整页面覆盖时释放播放窗口，返回后按当前条目重建，临时暂停保留缓冲。

### 收藏、历史、下载与订阅

- 下载页的显示方式、导出和批量操作位于标题下方，按页面左边界排列，窄屏及大字体自动换行，不挤占标题。
- 漫画、视频和小说的下载条目点击封面进入详情，点击标题及主体空白处直接打开已完成的本地内容并恢复进度；暂停、删除、更多等独立按钮只执行各自操作。本地文件缺失时明确提示，不自动联网代替本地内容。
- “继续阅读”列表默认点击整行续读；勾选框或长按进入选择，选择期间点击切换选中状态。删除下载章节须确认，取消保留文件与选择。
- 详情已有下载任务时，下载入口表示移除；确认后停止任务并删除本作品已下载内容，取消保持原样。章节选择中的下载用于补充内容。
- 漫画未下载完成时允许边下边读，已下载页用本地文件，缺页联网加载；只有全部章节图片完成才标记完整离线。该入口与明确打开已完成本地内容的行为区分。
- 订阅更新列表提供单条删除，管理菜单提供全部标为已读和清空。删除与清空需要确认，仅移除更新记录，保留订阅和检查去重状态。
- 订阅条目直接打开对应站点内容；关键词与筛选订阅复用站内搜索页，帖子直接展示正文和媒体。更新记录保留独立入口。支持媒体模式的站点提供相册或短视频入口，切换和分页保留当前订阅范围。

### 设置与首次使用

- 设置与管理类列表用 `RowGroup` 成组放在圆角表面上；历史、章节等长内容列表用细线分隔的行，网格用 `CoverTile`；不要在 `RowGroup` 外再套卡片。
- “我的”首页的设置入口图标放在强调色调的小圆角方块中，便于按形状扫视。
- 站点设置按账号、站点设置、网络、维护分组；选择项与文本项分别显示标题、说明和整行描边取值入口，行操作提供箭头或编辑提示。登录表单与其他设置使用相同页面边界，不额外嵌套卡片。
- “我的”及设置表单统一使用 `SettingsBody`，内容居中且最大宽度为 760 dp；作品网格和阅读区域按各自内容布局。设置入口名称允许完整换行，摘要可以省略。
- 首次使用引导顶部显示步骤进度（胶囊点），每步标题使用衬线大字，要点前用强调色调圆形图标；主操作占底部操作行的主要宽度，次要操作在其左侧。

### 异步反馈与恢复

- 可见性检测包含当前路由状态，隐藏页面不触发自动分页或互动推荐；可翻译标题超过单次请求长度时分段处理，失败保留原文并在底部提示，同一轮不重复提示。
- 推荐首屏可先展示稳定入口快照，再刷新并重建分页；主页和分类域页共享站点推荐会话。账号、插件、站点配置及代理变化后使对应旧会话失效，旧请求不得回填新结果。
- 保存失败持续显示可重试提示，实际落盘后才消失；初始化失败保留数据，从失败步骤继续重试。下载删除失败保留可重试状态，不伪装成删除完成。

## 触感

- 只在确认用户动作已生效时给轻触感：切换导航、分段与多选（`selectionClick`），收藏（`lightImpact`），下拉刷新开始（`mediumImpact`）。
- 不给滚动、普通点击和自动发生的变化加触感。

## 无障碍

- 图标按钮必须有 `tooltip`（读屏也会读出）；纯装饰的图片和图标排除在语义树之外。
- `CoverTile` 等复合组件提供合并后的语义标签（标题、站点、角标、进度）；封面角标用 `CoverBadge` 同时给出读屏文字。
- 文字与背景的对比度至少 4.5:1；不要只用颜色传达状态。
- 尊重系统的字体缩放和“移除动画”设置。
- 主要按钮与工具操作的触控区域至少 48 × 48 dp；强调色色块保留 36 dp 视觉尺寸，外侧留出可点击区域。`ActionTag` 当前采用约 28 dp 的紧凑视觉与点击区域，是内容标签的明确例外，不能据此缩小主要操作，也不能宣称全部控件均达到 48 dp。
- 仅展示 Android 已实现的设备能力；切换设备或恢复备份时保留配置，但不显示无效果的开关。

## 安卓界面验收

- 首先检查正常屏幕、默认字号的真实画面，再检查窄屏、大字体等压力场景。手机基线包含 360×800、393×852、412×915 dp 与 1 倍字号；明暗主题分别检查。
- 每页同时检查信息层级、封面与文字比例、间距、按钮辨识度、首次使用路径、空状态引导及点击反馈；没有溢出只能证明布局可容纳，不能作为美观度与易用性验收结论。
- 组件截图补充 Android 原生运行截图；使用演示数据，保留系统字体、系统栏、键盘与平台导航，实际点击主要入口和展开、收起操作。记录实际覆盖的设备、系统、页面和场景，不能将平台模式模拟视为对应设备验收。
- 额外检查系统返回、键盘出现与收起、通知权限、系统栏、旋转、锁屏与前后台恢复；覆盖菜单与完整页面的不同播放行为，以及快速滑动、切集、刷新和取消后的状态。
- 手机验收结果不自动覆盖平板；侧栏条件、宽屏详情和弹层需要分别记录验证范围。
