## 中文

### 改进
- 缩小继续阅读卡片，同屏可查看多个作品，保留章节、阅读进度和播放时间，并适配大字体。

### 修复
- Google Lens 和其他图片反搜统一在应用自建界面显示进度、错误与结果，不再自动跳转原网页；仅需手动验证时显示验证区域。
- 修复 Android 上 Google Lens 可能一直转圈的问题；请求失败或超时后可重新搜索，人机验证期间保留当前会话。

### 插件更新
- Google Lens 0.0.2：没有完全匹配时正常显示无匹配结果。

### 注意事项
- 已安装此前 0.8.2 的用户需从发布页重新下载安装包，覆盖更新。

## English

### Improvements
- Make Continue cards more compact so multiple works are visible at once, while keeping chapter details, reading progress and playback time with support for larger text.

### Fixes
- Google Lens and other reverse image searches now show progress, errors and results in the app's own interface without automatically opening the original webpage; a verification area appears only when manual verification is needed.
- Fix Google Lens searches that could keep spinning on Android; failed or timed-out requests can be retried, and the current session is preserved during manual verification.

### Plugin updates
- Google Lens 0.0.2: Show an empty result when no exact matches are found.

### Notes
- If you installed the earlier 0.8.2 release, download the installer from the release page again and install it over the existing app.
