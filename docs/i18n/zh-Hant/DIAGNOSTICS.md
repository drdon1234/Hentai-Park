# 執行日誌與問題回報

普通日誌預設記錄故障、自動重試、站點呼叫結果及前後景變化。可在設定的執行日誌中重新整理、匯出，並附上重現步驟提交 Issues。

疑難問題可開啟 debug 日誌：「僅本次開啟」立即記錄目前重現；「僅下次開啟」從下次啟動記錄完整啟動過程，啟動後會提示。debug 模式於退出應用程式後關閉，預約只生效一次。

長效日誌預設關閉，每次啟動覆寫最近執行記錄。開啟後跨啟動追加保存，達到 100 MiB 才淘汰最早記錄；關閉後立即覆寫歷史執行日誌。獨立當機歷史不受影響。

debug 額外記錄請求耗時、重試、快取及播放狀態，仍不記錄帳號、Cookie、Token、正文、本機路徑或完整簽名連結。頁面顯示最近記錄，匯出包含全部保留的執行日誌；去識別模式另隱藏目標主機及系統詳細版本。分享前仍請檢查匯出內容。
