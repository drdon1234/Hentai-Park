## ダウンロードと対応環境

**[ダウンロード](https://github.com/drdon1234/Hentai-Park/releases/latest)**

**Android 7.0+ と Windows** に対応。通常の Android 端末は `arm64-v8a` を選択し、Windows ポータブル ZIP は全体を展開してください。

対象プラットフォームは Android、Windows、Web のみです。Web 版は計画中で、まだ利用できません。

Windows では、アプリ内で更新を確認するとインストーラーをダウンロード・検証して開き、アプリを終了します。システムの案内に従ってインストールを完了してください。ポータブル ZIP の最上位フォルダーは `HentaiPark` です。

## はじめ方

1. 「見つける」でカテゴリとサイトを選ぶか、作品、タグ、リンク、品番で検索します。
2. 作品を開いて読む・観る。気に入った作品は「お気に入り」に追加し、オフライン用にダウンロードできます。
3. ホームの「続きから → すべて」で再開し、「お気に入り → 更新」で新しい章を確認します。

必要に応じて「その他 → サイト」でログイン、「その他 → ネットワーク」でプロキシを設定します。

## 制限と FAQ

閲覧、再生、コメント、購読、ダウンロードの対応はサイトごとに異なります。アプリ内の表示を確認してください。サイト更新にはアプリの更新が必要な場合があります。

**サイトやコンテンツにアクセスできない場合は？**

接続を確認し、案内に従ってログイン、年齢確認、サイト認証を行ってください。地域によって VPN やプロキシが必要です。内容と利用権限は配信元が管理します。

**コメントや弾幕を送信できますか？**

コメント、返信、ライブ弾幕は閲覧専用です。ゲームのリンク解放に返信が必要な場合は、内容を表示し、確認後にのみ送信します。

**お気に入りと進捗を保存するには？**

「その他 → バックアップ」で .parkbak を保存・復元します。復元はデータを統合し、ダウンロード済みファイルは含みません。Cookie などのサイトのログイン・確認状態は任意で保存でき、別の端末でも利用できます。有効期限切れや端末に紐づくセッションは再確認が必要な場合があります。バックアップは暗号化されません。安全に保管してください。

**問題を報告するには？**

Issues にバージョン、サイト、再現手順を記載してください。アカウント、Cookie、Token、バックアップ、署名付き URL 全体は公開しないでください。
