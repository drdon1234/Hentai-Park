## 中文

### 新功能
- 支持小说正文翻译与分段阅读，翻译设置可在阅读器中调整。
- 视频播放支持更多手势、音量控制和清晰度切换，离开页面后可保持播放状态。

### 改进
- 优化详情页、设置页、视频播放器和小说阅读器在窄屏与大字体下的布局。
- 完善网页登录验证、站点管理和播放页面的状态恢复。
- 改进诊断信息与崩溃日志的脱敏处理，减少无关的本地信息记录。

### 修复
- 修复部分视频页面切换、返回和全屏操作后播放状态不同步的问题。
- 修复小说翻译、下载任务和站点会话在特定状态下未及时更新的问题。

### 插件更新
- Hanime.tv 0.0.8、SupJav 0.0.9、Fansly 0.0.8、KoreanBJ.club 录播 0.0.4、SOOP 录播 0.0.4、SOOP 0.0.4、SinParty 0.0.5、Telegram 0.0.7、Canovel 0.0.8。

### 注意事项
- 本次插件更新需要 HentaiPark 0.9.2 或更高版本。

## English

### New
- Translate novel chapters and read them by section, with translation settings available in the reader.
- Add more video gestures, volume controls and quality switching while preserving playback state when leaving the page.

### Improvements
- Refine detail, settings, video player and novel reader layouts for narrow screens and large text.
- Improve web sign-in verification, source management and playback state restoration.
- Improve diagnostic and crash log redaction to reduce unrelated local information.

### Fixes
- Fix video playback state getting out of sync after page changes, back navigation and fullscreen actions.
- Fix novel translation, download tasks and site sessions not updating promptly in some states.

### Plugin updates
- Hanime.tv 0.0.8, SupJav 0.0.9, Fansly 0.0.8, KoreanBJ.club Recording 0.0.4, SOOP Recording 0.0.4, SOOP 0.0.4, SinParty 0.0.5, Telegram 0.0.7, Canovel 0.0.8.

### Notes
- These plugin updates require HentaiPark 0.9.2 or later.
