# 运行日志与问题反馈

普通日志默认记录故障、自动重试、站点调用结果和前后台变化。遇到问题后可在设置的运行日志中刷新、导出，并随复现步骤提交 Issues。

疑难问题可开启 debug 日志：选择“仅本次开启”可立即记录当前复现；选择“仅下次开启”可从下一次启动记录完整启动过程，启动后会提示已开启 debug 模式。debug 模式退出应用后关闭，预约只生效一次。

长效日志默认关闭，每次启动覆盖最近运行记录。开启后跨启动追加保存，达到 100 MiB 才淘汰最早记录；关闭后立即覆盖历史运行日志。独立崩溃历史不受此开关影响。

debug 额外记录请求耗时、重试、缓存和播放状态，仍不记录账号、Cookie、Token、正文、本机路径或完整签名链接。页面显示最近记录，导出包含全部保留的运行日志；脱敏模式还会隐藏目标主机和系统详细版本。提交前仍请检查导出内容。
