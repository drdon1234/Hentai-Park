## サポートされているオリジン サイト

|元のサイト |タイプ |説明 |
|------|------|------|
| E-Hentai / ExHentai |コミック | Webページにログイン後、サイトを切り替えることができます |
| nhentai |コミック | |
| JMComic |コミック |作品IDによる直接表示とAPI接続先の自動切り替えに対応 |
| WNACG（紳士漫画） | コミック | アカウント不要で閲覧でき、作品内の各話の選択と接続先の自動切り替えに対応 |
| PicACG |コミック |独自のアカウントを設定するか、確認後に専用アカウントを自動的に登録します |
| Hanime1 |ビデオ |初めて使用する場合は、Cloudflare の認証が必要になる場合があります。 |

ソース サイトはプラグインとして読み込まれ、サードパーティのソースを設定で追加できます。

## 機能

- **集約検索**: すべてのソース サイトを一度に検索します。リンクを貼り付けるか、作品ID（`JM350234`など）を入力して作品を直接開きます
- **多言語検索**: キーワードを中国語/日本語/韓国語/英語などの言語に自動翻訳して同時検索します。
- **本棚と更新**: マルチカテゴリのコレクション。シリアル更新を自動的にチェックしてプッシュ通知を送信し、新しい章を自動的にダウンロードできます。
- **リーダー**: 縦スクロール、左右のページめくり、右から左への読書、見開き表示、白余白のトリミング、目に優しい色調、音量キーでのページめくり
- **ビデオ再生**: 画質と再生速度の選択、再生位置の保存。画面の左側を上下に動かすと明るさ、右側では音量を調整し、横方向にドラッグすると再生位置を変更できます。縦・横の全画面表示と上下反転に対応します。
- **ダウンロード**: 章ごとにコミックをダウンロードし、画質を選んでビデオをダウンロードします。 CBZ のインポートとエクスポートをサポート
- **ソース変更移行**: コレクションを別のソースに移行し、読み取りの進行状況を保持します。
- **ブロックタグ**: ブロックをカスタマイズし、オンデマンドで有効にできるプリセットグループを提供します。
- **プライバシー保護**: アプリロック、シークレットモード、カバーブラー、スクリーンショット防止
- **バックアップとリカバリ**: ライブラリ、進行状況、設定をワンクリックでバックアップし、スケジュールされた自動バックアップをサポートします。
- **8 か国語インターフェイス**: 簡体字中国語、繁体字中国語、日本語、韓国語、英語、スペイン語、ロシア語、アラビア語。システムへの追従と即時切り替えをサポート、アラビア語は右から左へのレイアウトを採用

## ダウンロード

[Releases](https://github.com/drdon1234/Hentai-Park/releases/latest) に移動して、最新バージョンをダウンロードします。どれを選択すればよいかわからない場合は、ほとんどの電話ではバージョン `arm64-v8a` を選択してください。

## 始めましょう

1. 「見つける」でソースサイトを選択するか、検索バーを使用して作品を検索し、作品へのリンクを貼り付け、作品IDを入力します。多言語検索では、元のキーワードと検出されたソース言語が保持され、翻訳されたキーワードが表示されます。
2. 「その他 → 言語 → 表示言語」で言語を選択します。デフォルトではシステムに従います。変更はすぐに有効になり、ローカルに保存されます。作品の元のタイトル、タグ、保存されたユーザー データには影響しません。
3. 「その他 → ソース管理」でオリジンサイトを有効化、並べ替え、設定します。 PicACG アカウントが構成されていない場合、「見つける」にプロンプ​​トが表示され、自己構成を入力するか、専用の自動メンテナンス アカウントを有効にすることができます。
4. PicACG「専用の自動メンテナンスアカウントを使用する」をオンにすると、登録確認のポップアップが表示されます。確認後、専用アカウントを作成し、すぐにログインします。以降のログインステータスはアプリケーションによって維持されます。スイッチをオフにしても専用アカウントは保持されます。再度オンにすると再利用でき、既存の手動アカウントは上書きされません。登録に失敗した場合は、同じアカウントで再試行できます。
5. コミックの詳細ページで、章を収集、カテゴリを選択し、ダウンロードできます。 「本棚」ではコレクションを整理し、「更新」では新しい章を確認し、「履歴」では読み続けて進行状況を復元します。 「その他 → バックアップとリカバリ」では、データをエクスポートし、復元中に現在のデータと結合できます。

ビデオ ページの左側を上下にスワイプして明るさを調整し、右側を上下にスライドして音量を調整し、水平にスライドして進行状況をプレビューし、放した後にジャンプします。再生コントロールにより、画面を水平および垂直に拡張でき、画面を回転すると表示方向に合わせて操作領域が調整されます。リーダーは、上下のスクロール、左から右または右から左へのページめくりをサポートしており、読書方向はリーダーの設定によって決まります。

## よくある質問

**PicACG / ExHentai は使用できませんか?**
PicACG は、アカウントを自分で設定するか、専用の自動メンテナンス アカウントの登録を確認する必要があります。 ExHentai には Web ログインが必要で、アカウント自体にサイト権限が必要です。

**画像の読み込みが遅い、または失敗していますか?**
設定で HTTP プロキシを構成できます。 JMComic / PicACG は画像サーバーの切り替えを試みることができます。

**Hanime1 ぐるぐる回り続けますか?**
プロンプトに従って、内蔵ブラウザで Cloudflare の検証を完了します。

## 開発

```bash
flutter pub get
flutter build apk --release --split-per-abi
```

新しいサイトのソース プラグインを作成するには、[ソースプラグイン開発ガイド](SOURCE_API.md) を参照してください。組み込みのソース プラグインのバージョンは `0.0.1` から始まります。アプリケーションのバージョンとプラグインのバージョンは別々に管理されます。
