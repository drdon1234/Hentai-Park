## 中文

### 新功能
- 新增 Danbooru 美图站点，以及 Yandex、Bing、百度识图和 E-Hentai 识图服务。
- 图片反搜支持按分类选择多个服务并行查询、切换查看结果和单独重试；反搜插件通过独立渠道更新。
- 搜索框支持粘贴作品或分享链接，识别后直接打开应用内作品。
- 短视频可分别设置预加载数量和保留已看视频数量，设为 0 可关闭。

### 改进
- 区分应用内收藏与原站点赞、收藏和评分，支持的站点提供账号入口与原站互动。
- 统一设置页面与站点管理布局，改善窄屏、大字体、横屏及跨行文字选择体验。
- 小说列表统一展示作者、简介、标签和日期；优化继续阅读卡片与加载提示。
- 运行日志支持刷新与脱敏查看，并补充 Android 异常退出记录。

### 修复
- 修复搜索筛选、登录状态切换和关联作品加载中的界面与状态问题。
- 修复短视频切换、返回和后台暂停时的播放及缓存释放问题。

### 插件更新
- Google Lens 0.0.4、trace.moe 0.0.3、AnimeTrace 0.0.3、IQDB 0.0.3、AVScan 0.0.3：完善多站反搜与分类。
- Pixiv 0.0.7、E-Hentai 0.0.8、哔咔漫画 0.0.7、X / Twitter 0.0.8、MissAV 0.0.9、GalgameX 0.0.6：完善原站互动与浏览体验。
- Book18 0.0.6、Cool18 0.0.5、Canovel 0.0.5、Literotica 0.0.6、Lush Stories 0.0.5、StoriesOnline 0.0.6、69story 0.0.5：完善小说信息展示。
- iXXX 0.0.8、TubeSafari 0.0.5：完善访问确认提示。

### 注意事项
- Bing 识图在部分地区不可用，遇到地区限制时需更换网络或使用其他反搜服务。

## English

### New
- Add the Danbooru gallery source and Yandex, Bing, Baidu Image Search and E-Hentai Image Search services.
- Select reverse image search services by category, query several services in parallel, switch between results and retry individual services; reverse search plugins update through a separate channel.
- Paste work or shared links into search fields to open recognized works directly in the app.
- Configure how many short videos to preload and retain after watching; set either value to 0 to disable it.

### Improvements
- Distinguish local app favorites from likes, favorites and ratings on the original site, with account access and interactions where supported.
- Unify settings and source management layouts, improving narrow screens, large text, landscape layouts and text selection across lines.
- Standardize novel authors, descriptions, tags and dates, and improve Continue cards and loading indicators.
- Refresh and redact runtime logs, with additional Android abnormal exit records.

### Fixes
- Fix interface and state issues with search filters, account changes and related works.
- Fix playback and cache cleanup when switching short videos, returning to the player or pausing in the background.

### Plugin updates
- Google Lens 0.0.4, trace.moe 0.0.3, AnimeTrace 0.0.3, IQDB 0.0.3 and AVScan 0.0.3: Improve multi-service reverse search and categories.
- Pixiv 0.0.7, E-Hentai 0.0.8, Pica 0.0.7, X / Twitter 0.0.8, MissAV 0.0.9 and GalgameX 0.0.6: Improve original-site interactions and browsing.
- Book18 0.0.6, Cool18 0.0.5, Canovel 0.0.5, Literotica 0.0.6, Lush Stories 0.0.5, StoriesOnline 0.0.6 and 69story 0.0.5: Improve novel information display.
- iXXX 0.0.8 and TubeSafari 0.0.5: Improve access confirmation prompts.

### Notes
- Bing Image Search is unavailable in some regions; switch networks or use another reverse search service when a regional restriction appears.
