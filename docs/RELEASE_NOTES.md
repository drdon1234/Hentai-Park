## 中文

### 新功能
- 酒馆支持自建和编辑角色卡、PNG 头像与世界书，可用 AI 分轮创作、生成世界书大纲，并逐个采纳字段或词条。
- 酒馆编辑器可恢复本机草稿、回看文本版本，并用示例消息查看世界书词条命中或跳过的原因。
- 酒馆会话可切换发言角色，保存标签、笔记与记忆，生成摘要并查看本轮提示词。

### 改进
- 酒馆资源可按名称和标签搜索、置顶、另存副本，也可从其他世界书导入词条。
- 站内搜索的数值筛选支持直接输入；启动时优先展示应用更新，再处理插件更新。

### 插件更新
- RisuRealm 0.0.4：增加成人内容显示开关，改进世界书筛选。

## English

### New
- Create and edit Tavern character cards, PNG portraits and world books. Work with AI over multiple rounds, generate a world book outline and accept individual fields or entries.
- Resume local editor drafts, review text revisions and test a sample message to see why world book entries matched or were skipped.
- Switch speakers in Tavern conversations, keep tags, notes and story memory, generate summaries and inspect the current prompt.

### Improvements
- Search Tavern resources by name or tag, pin items, save copies and import entries from another world book.
- Enter numeric search filters directly. At startup, app updates appear before plugin updates.

### Plugin updates
- RisuRealm 0.0.4 adds an adult-content visibility setting and improves world book filtering.
