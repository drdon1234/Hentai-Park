## 下載

在 **[最新版本](https://github.com/drdon1234/Hentai-Park/releases/latest)** 下載 Android APK。大多數手機和平板選 `arm64-v8a`，模擬器一般選 `x86_64`。

提供 Android、Windows、macOS 和 Linux 客戶端；iOS/iPadOS 目前僅提供模擬器包，Web 暫不支援。安裝方式與平台限制見 [平台說明](../../PLATFORMS.md)。

桌面支援 Ctrl+滾輪、Ctrl/Cmd 加減鍵縮放介面，Ctrl/Cmd+0 恢復預設，也可在外觀設定中調整。Windows 系統匣圖示可恢復視窗或結束；關閉視窗時可選擇收起到系統匣或結束應用程式。

## 三步上手

1. **發現**：開啟「發現」，選一個分類，或在搜尋框輸入關鍵字、貼上連結或番號。
2. **閱讀與播放**：開啟作品，點主按鈕開始；喜歡的加入「書架」。
3. **接著看**：「發現」頂部的「繼續看」和「歷史」會帶你回到上次的位置；追更的作品在「書架 → 更新」。

需要登入或代理的站點，在「我的 → 站點」和「我的 → 網路」中設定。

## 功能

| 功能 | 說明 |
| --- | --- |
| 排行榜 | 從「發現」開啟本子、里番、JAV 榜單，切換站點與週期，搜尋作品或開啟原站 |
| 發現與搜尋 | 依分類瀏覽，多站同時搜尋，可用多種語言的關鍵字擴大範圍；貼上連結或番號直達作品 |
| 閱讀與觀看 | 漫畫捲動、翻頁或雙頁；影片選集、倍速與續播；小說排版、書籤、標註與朗讀。三種閱讀器使用同一套控制層 |
| 書架 | 收藏分類、更新提醒；訂閱作者、頻道或關鍵字的新內容 |
| 下載 | 獨立主導覽入口，管理漫畫、影片、小說與遊戲下載；匯入、匯出 CBZ；在作品選單按已完成章節匯出 PDF，動圖僅保留第一幀 |
| 遊戲資源 | 查看遊戲介紹、版本與下載連結 |
| 翻譯與過濾 | 翻譯標題、簡介與標籤；依標籤遮蔽內容 |
| 隱私與備份 | 應用鎖、無痕模式、封面模糊、防截圖；備份收藏、進度與設定 |

在「我的 → 網路與儲存 → 省流量模式」選擇：一般省流只在主頁和域頁顯示緊湊站點入口，進入站點後才載入作品；超級省流在站點頁也不自動載入，提交搜尋後才取得作品。不支援搜尋的站點會顯示說明。

小說閱讀頁「更多 → 全文翻譯」可翻譯完整正文，並隨閱讀繼續翻譯後續章節，支援切回原文。

瀏覽頁與詳情頁先顯示可直接開啟的本機快取，保留章節及媒體位址，並提示正在取得最新作品；更新失敗時仍保留可存取內容。返回首頁會保留原捲動位置。長按作品卡片可封鎖作品或作者，在內容篩選設定中取消。排行榜保留篩選條件，每次進入仍取得對應的最新榜單。短影片預設使用 Pornhub Shorties。

在支援的站點，詳情頁「更多」或作品卡片長按選單中的「原站喜好」使用應用程式內登入帳號儲存喜好：MissAV 支援原站收藏，EH 支援評分，與本機收藏分開。Pixiv 未登入預設進入排行榜，登入後預設進入推薦；推薦頁需要登入。Pixiv 與 EH 的站內搜尋支援原站關鍵字聯想。

JAV 作品可查看原站標註的字幕與版本差異，切換原站提供的版本，或按番號在站內、跨站查找；各版本的收藏、進度與下載獨立儲存。

淺色與深色主題，八種介面語言。每個站點可用的功能以應用內顯示為準。

## 排行榜

| 分類 | 站點 |
| --- | --- |
| 市場榜 | FANZA、FC2、MGStage、一本道、天然むすめ、パコパコママ、Caribbeancom、DLsite、Toranoana |

市場榜提供作品、女優、賣家和分類榜單；站點榜顯示各站熱門內容。可搜尋作品、開啟詳情或前往原站。

排行榜支援篩選及標題翻譯；封面保留原始比例，長標題可點按展開。

iXXX、TubeSafari 使用應用程式內網頁播放。播放頁可能仍需站點確認；播放控制由上游頁面提供，暫不支援應用程式的下載與精確續播。Android 需要支援獨立工作階段的較新版本 Android System WebView。

## 常見問題

**站點打不開，或圖片、影片載入失敗？**
先檢查網路。部分站點在中國大陸可能需要 VPN 或代理，可在「我的 → 網路」設定代理。遇到網頁驗證時，依提示在內建瀏覽器中完成一次即可。

**需要站點帳號嗎？**
大多數不需要。需要登入的站點會在站點頁頂部提示，也可在「我的 → 站點」開啟該站點的設定登入。Pixiv、X、StoriesOnline 的網頁登入支援 Google、Apple 等第三方帳號授權，是否放行內嵌瀏覽器由第三方平台決定。

**會替我在站點上發文或回覆嗎？**
不會自動這樣做。次元茶館的部分資源需要回覆才能解鎖，應用會先顯示將要發送的內容，經你確認後才發送。

**換手機怎樣保留收藏和進度？**
在「我的 → 備份」匯出備份，在新裝置上恢復。離線下載不在備份中，站點帳號可能需要重新登入。

**翻譯會上傳什麼？**
翻譯標題、簡介、標籤、搜尋詞、選取文字或小說全文時，相應內容會傳送給 Google 翻譯；不會傳送帳號、Cookie 或閱讀紀錄。目標語言跟隨應用程式語言。

**怎樣回報問題？**
在 [Issues](https://github.com/drdon1234/Hentai-Park/issues) 寫明應用版本、站點名稱和重現步驟；截圖前請隱藏帳號和私人內容。
