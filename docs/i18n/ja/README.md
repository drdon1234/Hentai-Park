## ダウンロード

**[最新リリース](https://github.com/drdon1234/Hentai-Park/releases/latest)** から利用するプラットフォームのパッケージを取得してください。Android は通常 `arm64-v8a`、エミュレーターは `x86_64` を選びます。デスクトップ版はすべて展開してください。[インストール方法と制限](../../PLATFORMS.md)もご確認ください。

Android・Windows・macOS・Linux に対応します。iOS/iPadOS は現在シミュレーター用のみで、Web 版はありません。[インストール方法と制限](../../PLATFORMS.md)をご覧ください。

デスクトップでは Ctrl+マウスホイール、Ctrl/Cmd のプラス・マイナスキーで表示倍率を変更し、Ctrl/Cmd+0 でリセットできます。外観設定からも調整できます。Windows のトレイアイコンからウィンドウを復元したり終了したりできます。ウィンドウを閉じるときは、トレイへの格納または終了を選べます。

## 3 ステップで始める

1. **見つける**：「見つける」を開いてカテゴリーを選ぶか、検索欄にキーワード・リンク・品番を入力します。
2. **読む・見る**：作品を開いてメインボタンをタップ。気に入ったものは「お気に入り」に追加します。
3. **続きから**：「見つける → 続きから → すべて」から履歴を確認できます。新しい話は「お気に入り → 更新」に表示されます。

ログインやプロキシが必要なサイトは「その他 → サイト」「その他 → ネットワーク」で設定します。

プラグイン更新では、すぐに更新できる件数と、アプリの更新が必要な件数・最低バージョンを表示します。互換性がない場合はインストール済みのプラグインを保持します。アプリとプラグインの更新で「今後通知しない」を選ぶと、そのバージョンの通知を停止します。手動確認では引き続き表示され、次の新バージョンでは再び通知します。

Windows、macOS、Debian 系 Linux では、アプリ内で更新を確認するとインストーラーをダウンロード・検証して開き、アプリを終了します。システムの案内に従ってインストールを完了してください。他の Linux ディストリビューションでは圧縮ファイルを手動でダウンロードしてください。Windows ポータブル ZIP と Linux tar.gz の最上位フォルダーは `HentaiPark`、macOS ZIP 内は `HentaiPark.app` です。

コメントとライブチャットは閲覧専用です。サイトへのコメント・返信・チャット送信には対応していません。取得できる内容や並び順は各サイトによって異なります。一部のコンテンツではログイン、年齢確認、サイト認証が必要です。元の投稿でコメントが明示的に無効な場合は入口を表示しません。有効な投稿では、まだコメントがなくてもコメント画面を開けます。

小説リーダーの「その他 → 全文翻訳」で本文全体を翻訳でき、次の章を開くと翻訳が続きます。原文にも切り替えられます。

閲覧・詳細ページでは端末のキャッシュを先に表示できます。メディアリンクが期限切れの場合は更新してください。ホームに戻るとスクロール位置を復元します。作品を長押しすると作品や作者をブロックでき、フィルター設定で解除できます。ランキングの条件は保存され、開くたびに最新結果を取得します。ショート動画の既定サイトは RedGifs です。

Reddit と X のサイトホーム、Reddit コミュニティ、X コミュニティでショート動画モードを開くと、その範囲の投稿動画を上下スワイプで再生できます。Reddit のホスト動画と RedGifs の動画リンクに対応しています。同じ投稿の複数動画も個別に再生します。X のサイトページの「コミュニティ」からリンクを入力するか、参加済みのコミュニティを選べます。閲覧権限は元サイトに従います。

ショート動画は次の動画の先読みと、最近視聴した動画とバッファの保持に対応し、既定ではそれぞれ 2 本です。「マイページ → ショート動画」または再生画面の「その他 → ショート動画の設定」で個別に変更でき、0 で無効になります。キャッシュは再生画面を開いている間のみ有効で、数を増やすとメモリと通信量が増えます。

アプリ内のお気に入りはローカルの書庫に保存されます。サイトでの操作はログイン中のアカウントで、各サイト対応のいいね・ブックマーク・評価を保存します。X のブックマークはサイトのお気に入りです。Pixiv・X・PicACG はいいねとブックマーク、MissAV はブックマーク、EH はお気に入りと評価に対応します。アカウント対応サイトではツールバーの下にログイン・アカウント管理を表示します。Pixiv は未ログインでもおすすめを初期表示し、継続読み込み・作者の他の作品・関連作品に対応します。Pixiv と EH は検索候補に対応します。作品・共有リンクを検索欄に貼り付けるとアプリ内の作品を開けます。

GalgameX は元サイトのお気に入りに対応し、追加時は最初のコレクションに保存します。コレクションがない場合は元サイトで先に作成してください。解除時は全コレクションから作品を削除します。

JAV 作品では配信元が示す字幕・バージョンの違いを確認し、別バージョンへの切り替えや品番によるサイト内・横断検索ができます。お気に入り、再生位置、ダウンロードはバージョンごとに保存されます。

ライトとダークのテーマ、8 つの表示言語に対応。各サイトで使える機能はアプリ内の表示に従います。

サイト画面では原サイトに応じたカテゴリ、タグ、レーティング、並べ替えを利用でき、検索画面にも対応するフィルターがあります。大きな目録は範囲やグループを先に選びます。親条件の変更で子の選択が解除されます。読込失敗は再試行でき、ログインや認証など原サイトの条件は引き続き適用されます。

作品・女優・販売者・カテゴリ別のランキングと、各サイトの人気ランキングを利用できます。作品検索、詳細表示、元サイトへの移動に対応します。

ランキングでは絞り込みとタイトル翻訳が使えます。表紙は縦横比を維持し、長いタイトルはクリックで展開できます。

iXXX と TubeSafari の対応済み配信元はネイティブ再生を優先し、続き再生とオフライン保存に対応します。未対応の配信元はアプリ内ウェブ再生を使用します。ウェブ再生ではサイトの確認が必要な場合があり、アプリのダウンロードと正確な続き再生には対応しません。Android のウェブ再生には独立セッション対応の新しい Android System WebView が必要です。

SWAG の無料ショート動画はネイティブプレーヤーを使用し、画質切替、続き再生、オフライン保存に対応します。有料ロック解除が必要な動画は含みません。

## よくある質問

**サイトが開けない、画像や動画が読み込めない**
まずネットワークを確認してください。中国本土では VPN やプロキシが必要なサイトがあります。「その他 → ネットワーク」でプロキシを設定できます。サイト認証はバックグラウンドで自動的に試行し、完了しない場合はアプリ内で再試行できます。

初回は免責事項を読み、成年であることを確認してください。確認は端末内に保存されます。対応する年齢確認と Cloudflare 認証はバックグラウンドで処理し、サイト画面の操作が必要なのはログインのみです。Windows は標準 Cloudflare チェックボックスの自動クリックに対応し、他の環境では自動認証を試行します。失敗時はアプリ内で再試行できます。

JM と PicACG は利用可能な接続先を自動検出できます。送信元のグローバル IP が前回と同じと確認できた場合のみ保存済みの接続先を再利用し、変化した場合や確認できない場合は再検出します。第三者の公開 IP 確認サービスは使用しません。接続先の手動選択も可能です。

**サイトのアカウントは必要？**
ほとんど不要です。ログインが必要なサイトはサイトページの上部に表示され、「その他 → サイト」のサイト設定からログインできます。Pixiv、X、StoriesOnline のウェブログインは Google や Apple などの外部アカウントに対応していますが、内蔵ブラウザを許可するかは各サービス次第です。

**勝手にサイトへ投稿・返信しますか？**
自動では行いません。次元茶館の一部リソースは返信しないと解除されないため、送信する内容を先に表示し、確認してから送信します。

**機種変更してもお気に入りと進捗を残すには？**
「その他 → バックアップ」で `.parkbak` ファイルを書き出し・復元できます。作成時に「サイトのログイン・確認状態」を選ぶと、Cookie、Token、サイトの確認状態も保存します。ファイルは暗号化されないため、安全に保管してください。ダウンロードは含まれず、期限切れや端末に紐づいたセッションは再確認が必要な場合があります。

**翻訳で何が送信されますか？**
タイトル・紹介文・タグ・検索語・選択した文字・小説全文を翻訳すると、その内容が Google 翻訳に送信されます。アカウント・Cookie・読書履歴は送信されません。翻訳先はアプリの言語に従います。

**問題を報告するには？**
[Issues](https://github.com/drdon1234/Hentai-Park/issues) にアプリのバージョン、サイト名、再現手順を書いてください。スクリーンショットではアカウントや個人的な内容を隠してください。

公開の報告にパスワード、Cookie、トークン、セッションのエクスポート、アプリのバックアップ、通信キャプチャ、署名付きの完全なリンクを添付しないでください。ログはアプリが出力するマスキング済みレポートのみを共有してください。
