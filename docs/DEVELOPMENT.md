## 环境与构建

`lib/engine/access/` 不依赖 Flutter，集中维护页面识别、年龄确认、文档状态和输入校验。原生客户端由 `WebViewInteractionHost` 接入，核心按宿主能力选择输入方式。

Android 的 `android/build.gradle.kts` 在构建副本中让带游戏标记的 WebView 在插件初始化前绑定作品 Profile，加载前再校验实际 Profile；不支持或绑定失败时拒绝运行。依赖升级改变创建流程时构建明确失败，需要重新核对绑定时序。此步骤不修改 Pub 缓存。

Windows 的 `windows/webview_lifecycle.cmake` 将 WebView 共享图形资源的释放移到插件析构阶段，按视图、合成器、D3D、DispatcherQueue、WinRT 的顺序关闭，避免 DLL 卸载期间访问图形驱动。构建只生成一个修正后的翻译单元，不修改 Pub 缓存。依赖升级导致对应源码结构变化时构建明确失败，必须核对释放顺序后更新集成。

`windows/webview_cookies.cmake` 在同一构建边界统一单项和批量 Cookie 读取：将 CDP 的 Unix 秒转换为 Flutter 接口约定的毫秒，并将会话 Cookie 的有效期设为空，避免网页认证状态在导入时被误判为过期。同样只生成构建副本；依赖升级后必须核对对应读取实现。

Windows 的 `windows/webview_bridge_lifetime.cmake` 在构建副本中约束 JS 桥接回调的视图生命周期：视图销毁后忽略尚未返回的结果和错误，避免请求超时、页面关闭后回调访问已释放的原生视图。依赖升级改变回调结构时构建明确失败，需要重新核对所有权。

Windows 同时在管理器生成副本中接入 `windows/webview_user_agent.h`，补齐 `getDefaultUserAgent`：从未覆盖标识的临时 WebView 读取当前 WebView2 的默认值，供网页验证与后续请求共同使用，避免桌面端退回手机标识并读取到不同的页面布局。

Windows 通过 `lib/video/desktop_video_player.dart` 将共享 `video_player` 控制器接入 `media_kit`；Android 使用系统实现。桌面桥先返回可释放的播放器标识，原生创建及打开结果通过事件交付；初始化失败也必须释放控制器。升级媒体依赖时需检查创建失败、切集、重播及关闭中的资源释放。

- 工具链：Flutter 3.47.7（Dart 3.13.5）、JDK 17、Node.js 22。CI 固定这个 Flutter 版本。
- WebView 使用 beta 依赖，用于现有的浏览器桥能力；升级前必须验证 Cookie 分区、验证页和媒体传输。`flutter_tts` 仍使用外部 Kotlin 插件，升级 Flutter 前要核对插件的内置 Kotlin 支持。
- Android 与 Windows 由 GitHub Actions 执行构建检查；实际设备运行仍需单独验证，详见 [平台矩阵](PLATFORMS.md)。

### Android SDK

Flutter 的 `android-sdk` 与 `android/local.properties` 的 `sdk.dir` 都应指向包含 `platforms`、`build-tools`、`platform-tools`、`ndk` 的那一层，把 `<Android SDK 目录>` 换成本机实际路径：

```powershell
flutter config --android-sdk '<Android SDK 目录>'
flutter doctor -v
```

`local.properties` 由 Flutter 构建按此配置重写，不提交。更换 SDK 后如果 Lint 使用旧缓存，执行 `:app:lintVitalAnalyzeRelease --rerun`，不要关闭检查规则。

### 构建

```powershell
flutter pub get
flutter build apk --release --split-per-abi
```

- 正式构建要求 `android/key.properties` 配置 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`，缺少就失败，不回退到 debug 签名。
- 只检查能否编译时用 `flutter build apk --release --split-per-abi --android-project-arg=verifyUnsignedBuild=true`，输出无签名 APK，不能安装或发布。显式传参是为了避免 Windows 上 Dart 把环境变量名转成大写，导致 Gradle 认不出属性。
- `flutter pub get` 必须成功。Windows 未开启开发者模式时它会中途失败，`GeneratedPluginRegistrant` 缺失会让 APK 一启动就崩溃，不能用 `--no-pub` 绕过。
- 在模拟器上验证时可以构建 profile 包：`flutter build apk --profile --target-platform android-x64`。设备上已装更高的 versionCode 时，加 `--build-number` 指定一个更大的值来覆盖安装，以保留应用数据；不要为此修改 `pubspec.yaml` 的版本。

## 项目结构

| 目录 | 内容 |
| --- | --- |
| `lib/core/` | 模型、设置、国际化（`localization.dart`、`plugin_copy.dart`）、应用锁、诊断 |
| `lib/engine/` | 插件加载与运行时（`source_manager.dart` 及 `source_manager/` 下的各部分）、JS 引擎、网络、Cookie、隔离与原生桥 |
| `lib/images/` | 图片解码、解密与缓存 |
| `lib/library/` | 书库、下载、备份、迁移、`playback_resolver.dart`（“继续”打开什么） |
| `lib/ui/kit/` | Flutter 设计令牌与组件；安卓用法见 [安卓设计准则](design/ANDROID.md) |
| `lib/ui/` | 各页面：`home`、`library`、`history`、`settings`、`detail`、`reader`、`novel`、`video`、`search`… |
| `assets/sources/` | 站点插件，唯一的站点实现；`index.json` 是官方清单 |
| `assets/runtime/park_runtime.js` | 插件运行时（应用与 Node 共用） |
| `assets/i18n/` | 八种语言的界面文案，键为简体中文原文 |
| `tools/` | 检查、发布与构建脚本 |

插件运行时按需启动：应用启动时只读取按“脚本 SHA-256 + 运行时版本”缓存的 manifest（`source_manifests.json`），第一次调用某个站点时才为它启动无界面 WebView；空闲 5 分钟或同时运行超过 6 个时回收最久未用的。账号状态按站点缓存，只在首次使用、登录、退出、网页登录后以及超过 10 分钟时刷新。声明必须登录的站点在读取内容或缓存前等待账号确认；已知未登录时直接提示登录，不发起列表请求。

设置与书库都按范围通知，界面只订阅自己用到的部分，不监听整个对象：

- `AppSettings.domain(SettingsDomain.x)` 在该领域（外观、漫画阅读、小说、网络、隐私、书库、订阅、搜索、过滤、维护）任一键变化时通知；`AppSettings.watch(keys)` 用于跨领域的少数键。所有值仍存在同一个 `settings.json` 里，存储格式和备份不变；新增设置键必须归入一个领域（调试模式下会断言）。
- 内容屏蔽在展示时按当前规则重新匹配，原始缓存保留。`blockedTags` 保存原词，`blockedTagAliases` 按原词保存已确认的普通词别名（含显式空列表，表示不使用内置别名）；预设中相同的分组数据保存在 `blockPresets.<组名>.aliases`。删除原词同时删除其别名。别名沿用原词的 `title:` 或标签命名空间。内置同义词只做确认过的词义关联，不把整个预设分组当作同义词。翻译与已安装词包仅生成候选，用户选择后保存；不依赖界面翻译状态，浏览匹配不联网。已自定义的预设词表不自动覆盖，新增默认词可手动添加或恢复默认。
- 屏蔽语法：普通词完整匹配标签；`namespace:词` 限定标签分类；`title:词` 匹配标题；`*` 匹配任意长度，`?` 匹配一个字符（标签完整匹配，标题片段匹配）；`regex:表达式` 使用不区分大小写的正则，可组合为 `female:regex:^step.*mother$` 或 `title:regex:继[母父]`，表达式中的大小写转义保持原样。标题中的纯英文词按整词匹配。预设标题匹配由独立开关控制；无效显式正则不得导致列表无法显示。机器翻译不处理通配符与正则。
- 默认预设用显式正则合并繁简、英文词形和分隔符变体；英文变体限制词边界，避免命中普通单词内部。男同、女同规则排除“同学”“同事”，蕾丝只匹配完整标签或完整标题，避免屏蔽蕾丝衣物。每组的 `strong` 开关默认关闭，宽泛亲属词、`*妈`、`*母`、单一性别阵容等歧义规则只在强力模式生效；标题匹配独立控制。旧配置中保留的同名内置宽泛词也受该开关约束，自定义词表原文不丢失。
- 收藏更新默认跳过已确认单篇，图文帖子、直播、短视频和游戏不参与章节更新；同人本、动画、AI 短剧、小说保留首次检查，其他分类仅在已知多章时检查。用户显式关闭“只检查多章节作品”时仍允许重新检查单篇。
- `Library.instance.work(uid)` 只在这部作品的收藏、历史、进度或章节状态变化时通知；`Library.instance.collection(LibraryCollection.x)` 按收藏、分类、历史、章节分别通知。
- 书库排队写入按顺序逐项事务提交；失败项及其后的操作保留，后续写入或 `flush()` 重试，未全部落盘不得报告刷新成功。目录同步与读取先排空写入；已读状态按最近一次漫画或视频进度动作合并，不能用逻辑或覆盖较新的未读标记。
- 大页面按职责拆分：视频页的播放会话在 `VideoSession`，播放区在 `VideoStage`，手势在 `video_page_gestures.dart`；漫画和小说阅读器的翻页、输入、排版与菜单动作分别在各自的 `part` 文件中，共享状态放在抽象基类里。

## 运行与资源生命周期

### 页面与媒体资源

- 原生媒体的 DNS 地址校验同时接受代理 fake-ip 使用的基准测试地址段 `198.18.0.0/15` 与 `2001:2::/48`，IPv4 映射 IPv6 按其 IPv4 地址检查；其余内网、回环、链路本地及已屏蔽的保留地址仍拒绝。连接使用已校验地址，TLS 保留原域名的 SNI 与证书校验。
- 普通聚合搜索和换源迁移排除资料与独立榜单插件；资料聚合搜索只使用资料插件的普通搜索能力，保留其分页、筛选及进入资料详情的语义。

- Flutter 的 `RouteAware`、实际视口检测、请求取消与代次校验共同约束页面工作；`mounted` 只证明组件仍存在，不能单独授权自动分页、翻译或播放。
- `VideoSession` 保存恢复信息后释放被完整页面覆盖的播放器、预加载和媒体会话；`PlaybackRelease` 让新播放器等待旧资源关闭。临时弹层和应用后台按各自的状态处理，具体交互见安卓设计准则。
- 短视频播放池区分当前条目、预加载、最近播放和销毁中资源；未完成关闭的资源仍占额度，当前初始化优先。图片和浏览器资源也按各自所有者与额度管理。
- 可重试媒体连接失败时，原生传输先重建连接池，再使用既有的有限重试；旧池正常结束进行中的并发请求。直链代理仅对连接异常或超时额外重建一次，不重放取消、证书失败或非瞬时错误。
- `request_retry.dart` 统一原生与浏览器传输的可重放读取判断：无请求体的 GET / HEAD，或插件显式声明只读的文本 POST；不据页面名称推断写操作安全，不重放二进制上传。
- 吃瓜站的发布页和正文规则由各自插件声明，共用运行时负责验证候选、限制同源跳转和缓存可用来源；新来源不自动获得浏览器 Cookie 或媒体来源权限。图文正文只在当前详情会话中使用，临时媒体地址不写入普通详情或播放缓存。

- 在线游戏通过 `onlineGame` 获取当次地址，以站点 key 和稳定 `storageId` 计算独立浏览器配置名。Android 在加载前绑定系统多配置文件，缺少该能力时拒绝启动；Windows 的 WebView2 配置放在应用持久数据目录。退出只销毁视图，不清除配置。Ruffle 使用拦截的同源文档加载站点提供的脚本和 SWF；游戏主框架限于该游戏主机，子框架另允许精确的 Cloudflare 验证域，弹窗、下载和网页权限被拒绝。游戏文档使用共享验证交互，源会话与游戏配置不共享 Cookie。访问状态检查使用原生脚本求值，不依赖被禁用的网页 JavaScript 桥；回调按底层控制器与文档代次核对，不能比较插件临时创建的 Dart 包装对象。缓存遵循浏览器及服务端策略，来源主机改变不会自动迁移存档。

- 站点声明出生日期年龄门时，共享验证框架仅在本机已确认成年、日期控件和按钮唯一且属于同一同源表单、没有其他可提交输入时填写固定日期 1999-12-31；完成仍以站点内容与 Cookie 为准。该日期不代表用户真实生日，也不替代本机成年确认。

### 后台下载与本地清单

- 漫画、视频、小说与游戏直链共用下载调度额度。`downloadSiteConcurrency` 限制同时活动站点数（默认 3），`downloadTaskConcurrency` 限制每站同时活动作品任务数（默认 1）；两者均可在下载页与书架与下载设置中配置为 1–8。`downloadConcurrency` 仍仅控制每个漫画任务内同时下载的图片页数（默认 3）。调低限制不会中断运行任务，取消中的任务在完全退出前仍占用额度；队列补位按当前限制执行。

- Android 中正在执行的软件安装包、站点插件、媒体、游戏及词包下载共用数据同步前台服务和 CPU 唤醒锁，切后台和锁屏后继续执行；通知不显示作品或账号信息，已知全部任务总量时显示实际完成进度。队列交接保留短暂服务窗口，所有任务结束后自动停止。系统停止服务或 Android 的后台时间额度耗尽时取消正在执行的下载；用户强停、移除应用任务或系统回收进程后不承诺继续，重新打开后按各下载队列已有规则恢复或重试。插件安装保留原有事务恢复机制。

- 漫画下载先原子写入 `pending.json`，完成后发布 `pages.json`；`localChapter(allowIncomplete: true)` 按原序号合并有效本地图片与待联网页面，全部完成后才声明完整离线。阅读和下载共享图片任务，阅读优先；调用者独立取消，最后一个使用者离开后才终止共享请求。
- 导出遇到已完成章节清单缺失或为空必须失败，零文件结果不得标成功。更换下载位置前，将新旧导出目录原子登记到本机 `export_directories.json`；导出管理同时读取这些位置，文件不迁移，该本机路径登记不进入备份。
- HLS 下载与录制共用本地资源命名校验：数字分片及 `init.mp4` 初始化段；离线播放和打包导出使用同一规则，仍拒绝外部地址、目录穿越和越界符号链接。

- 漫画任务中任一并发页失败时，立即取消同任务的其他页并等待退出，保留首个失败原因后释放调度额度；继续下载使用新的取消令牌，复用已写入的有效图片。EH 章节页数取自画廊页面，图片 API 的会话 key 失效或返回非 JSON 时重新读取原图片页并更新 key；明确的封禁、认证和 HTTP 错误正常报告，不循环重试。

### 推荐会话与缓存

- 发现主页和分类域页由 `FeedSessions` 持有共享默认入口会话，保存作品、分页进度及在途请求。配置在创建时取快照；刷新和身份变化取消旧请求并拒绝迟到结果。`hasNext`、游标集合、去重集合和有限补页共同约束分页，异常时停止并允许重建会话。具体推荐布局与展示开关见安卓设计准则。

- 源站页码跳转使用原始分页语义；游标链按顺序推进，只保留目标页用于展示。卡片高度按内容修订和布局约束缓存，滚动时不重复测量整份列表。
- 自动内容翻译失败保留原文且不弹全局错误；主动翻译的限流提示明确标记翻译服务，避免与站点加载故障混淆。

- 推荐首屏另存稳定入口快照，重开应用先展示上次内容，再刷新并重新建立分页会话；账号、插件和站点配置变化及移除站点时清除对应快照，仍受作品缓存容量限制与清理入口管理。备份读取和运行时重启不撤销正在下载的图片会话。

### 筛选候选与播放地址

- 帖子附件和吃瓜正文的图片、视频共用横向浏览器，按原帖顺序编号；只挂载当前媒体页的视频播放器，邻页显示预览。视频页嵌入横向浏览时把横向手势留给翻页，进度条仍可拖动；独立全屏播放保留原有手势。远程媒体仍经过通用媒体会话的域名、重定向、TLS 和 Cookie 分区校验。
- 漫画每次加载章节创建独立的可见位置监听器及滚动视图身份，旧章节回调不能更新新章节页码。视频在没有同步目录时也立即建立分集位置缓存；需要历史恢复的点播会话初始化时从数据库读取章节状态。

- 动态分类只用于原站会变化或需要按上下文发现的候选；稳定枚举继续随插件声明。框架缓存经校验的动态候选 30 分钟，最多 128 个上下文，跨筛选面板复用。键包含插件脚本、入口、关键词、直接父条件、配置、账号代次、Cookie 代次与代理；读取缓存前等待站点变更与账号检查，取消结果不缓存。
- 浏览与搜索只声明原站实际支持的条件；普通分类与最新入口可复用搜索条件，原站独立热门和榜单不伪造筛选能力。界面共用筛选面板，普通条件使用独立标题，文本和数字输入不使用浮动标题。
- 播放地址每次打开由插件重新获取，不从元数据磁盘缓存复用临时签名；媒体权限及 HLS 解析仍统一校验。媒体启动文档与站点读取共用可信验证交互，输入成功不代表验证通过，仍检查当前代次文档实际状态。

### 运行诊断

- 运行日志（设置 → 关于 → 运行日志）按时间从新到旧展示，堆栈跟随事件且保持调用顺序；运行时间线与独立崩溃历史按事件身份去重。报告包含应用版本、是否设置应用代理、涉及的插件版本和安全诊断事件；页面展示最近 2000 条运行事件，导出包含全部保留的运行日志。

- 自动诊断在采集入口按白名单校验，仅保留时间、站点与操作、错误代码、HTTP 状态、网络原因、传输方式、目标主机、异常类型、应用或插件文案键的固定错误模板（不含占位符值），以及 `package:`/`dart:` 代码位置。不采集异常正文、账号、凭据、作品信息、本地路径、签名 URL 或原始原生堆栈。白名单见 `lib/core/diagnostics.dart`。完整模式展示安全诊断信息；脱敏模式额外隐藏目标主机与系统详细版本，模式选择同时作用于页面与导出。普通日志记录生命周期、站点调用结果、重试与故障；debug 额外记录启动步骤、请求编号、方法、耗时、读取字节数、缓存命中与播放状态变化，不记录逐帧播放事件。历史异常按相同事件合并；WebView 控制台输出不记录。

- debug 可选择仅本次或仅下次开启；仅下次标志在数据库与插件初始化前消费，启动后提示，退出即关闭。偏好独立保存在 `log_preferences.json`，不混入账号及备份设置。日志存储故障不阻断业务或启动。
- 运行日志使用白名单净化后的 JSONL，内存最多 2000 条，按 250 ms 或 512 条批量异步落盘。普通模式每次启动覆盖，最多 2 × 1 MiB；长效模式跨启动追加，最多 20 × 5 MiB，达到 100 MiB 后才淘汰最老块。关闭长效模式立即移除历史运行日志，随后覆盖保留本次最近记录。以下崩溃历史独立保留，不受运行日志开关控制。

- Flutter/Dart 未捕获错误在退出前同步写入 `logs/crash.log`（JSON 行，256 KB 轮换）；目录初始化前的异常暂存并在路径可用后补写。启动时将现有日志及轮换文件通过白名单重写，读取时再次校验。Android 在 Application 启动时接入 Java/Kotlin 未捕获异常，保留系统原处理器，仅将结构化事件写入应用私有目录的 `logs/native_crash.log`；Android 11 起收集系统历史退出原因和退出状态，不读取退出描述、ANR 文本或 tombstone。Android 历史日志同样在启动与读取时净化。强杀、断电等退出不能保证产生诊断记录。


3. `flutter analyze lib`：静态检查，规则见 `analysis_options.yaml`。
4. `dart format`：格式检查。手写 JS 使用两空格、多行函数与单引号；生成文件按生成器格式保留。
5. `tools/publish_sources.mjs`：官方插件离线校验；提供 `videos` 的插件必须声明有效的 `media`，已有媒体与图片声明也会检查传输方式、来源、域名和会话范围，避免发布后才因缺少权限而无法播放。

- 默认只运行与改动相关的测试。修复要有能复现原问题的针对性验证；完成说明附上新鲜的测试或实际请求证据，并写明没有验证到的部分。

- 离线校验不能代替真实请求。修改插件后用共享运行时（见 SOURCE_API.md 的“在 Node 中试跑”）真实请求首页、分页、搜索、详情、封面解码，以及漫画章节或视频分集/媒体。

## 发布

- 插件必须显式声明 `minAppVersion`，与官方清单一致；仅在使用了更高版本体能力时提高要求。协议为 `apiVersion: 2`，旧协议客户端会拒绝新版官方索引并保留已安装插件。自动提示将可直接更新与需先升级本体的插件分开计数；“不再提醒”按本体版本或插件标识与版本持久化，手动检查仍显示全部更新。
- 插件版本与应用版本分开管理。修改插件脚本时同时提高插件版本并更新 `assets/sources/index.json`；不擅自提高应用版本。
- 软件更新只以官方 GitHub `/releases/latest` 返回的稳定发布为最新版本，不从历史发布中按版本号取最大值。仅 latest 允许版本号低于已安装版本时提供更新，并在安装确认框中明确提示版本号回退；相同版本忽略构建号后不重复提示。发布页标签必须与返回的版本标签一致。Android 覆盖安装仍要求安装包的 versionCode 高于已安装包，版本号回退不能绕过系统限制。
- 应用版本只取 pubspec.yaml。正式发布通过 GitHub Actions 的标签或明确启用的手动发布，Android 分发使用正式证书；日常编译不要求商业签名。
- 官方插件撤回仅由四个分发频道完整且有效的索引共同判定；缺失频道或无效条目不能触发撤回。更新检查先确认删除撤回插件，再提示版本更新；删除清理脚本、站点配置、私有状态、Cookie 与词包，不修改书库、阅读进度及下载内容。个人安装来源不参与撤回。启动同步不静默删除撤回插件，已确认撤回的内置插件不自动重装。
- 站点运行时及浏览器就绪等待的超时只累计前台运行时间。后台切换影响连接时，缓冲只读请求可在前台恢复后额外重试一次；GET/HEAD 不携带请求体，POST 必须显式声明只读。HTTP 408、500、502、503、504 及瞬时连接失败对安全读取最多额外重试两次，认证失败、其他 HTTP 状态、写操作及用户取消不重放；后台切换恢复额外最多一次。播放媒体读取同样有限重试，退避和播放器初始化只计算聚焦时间，后台下载与录制则继续有界重试；重试耗尽时正常报告。退出、配置变更和取消语义保持有效。
- 官方插件源码与唯一清单均在 `main` 维护。`.github/workflows/publish-sources.yml` 分别发布到 `sources`、`reverse-search` 和 `metadata` 分支：资源站点、独立反搜和独立资料插件分别进入对应频道，排行榜与作品资料统一在 `metadata` 发布；资源站点附带排行榜或反搜能力仍在 `sources`。三个分支只保留固定源码提交地址与摘要的索引，共用版本检查和用户确认更新流程。资料插件不进入片源聚合搜索、收藏、下载或播放链路，解析实现留在插件中，应用负责校验结构、渲染资料与调用外部磁链应用。标签翻译继续通过 `tag-translations` 独立发布，合计四个发布渠道，流程见 SOURCE_API.md 的“发布”。
- 已安装旧版插件的用户在接受官方插件更新之前继续使用旧脚本；插件文案、错误提示等随插件更新生效。应用启动时会提示可用的插件更新，发布说明只在“插件更新”小节列出站点与新版本，不再写更新步骤。
- 官方插件更新最多三个站点并发下载、校验和安装。安装、卸载与恢复内置版本只等待对应站点的操作；其他站点可继续发起请求。同站点的新请求等待自身更新结束。每个站点使用独立的 `source_install_<key>.json` 恢复日志，失败只恢复自身脚本、配置与 Cookie；启动时先恢复未完成事务。全量备份、导入仍使用全局一致性屏障。
- 启用状态表达用户选择，与加载失败分开保存。停用插件更新仍校验脚本、声明和应用兼容性，但不启动其运行时；启用插件安装等待初始化成功再提交。已安装声明在缓存命中和运行时启动时同样校验应用兼容性。失败回滚恢复原脚本、版本、设置和会话，不改变开关；自动更新候选按站点标识、来源与版本判断是否仍有效，不能因事务恢复重建记录对象而拒绝重试。

### 发布说明

GitHub Release 正文就是应用内“发现软件新版本”对话框里的更新内容，由 `AppRelease.notesFor`（`lib/engine/app_updater.dart`）解析。格式固定，所有历史版本保持一致：

```markdown
## 中文

### 新功能
- 一条一个用户能感知的变化，一行写完。

### 改进
- …

### 修复
- …

### 插件更新
- MissAV 0.0.5、123AV 0.0.6：详情页显示站点的相关推荐。

### 注意事项
- 只写用户必须知道或自己操作的事项，例如无法覆盖安装、某个操作会以用户账号发帖。

## English

### New
- …

### Improvements
### Fixes
### Plugin updates
### Notes
```

- 正文只有 `## 中文` 和 `## English` 两个二级标题，顺序固定，标题前不写内容。简体中文和繁体中文界面显示 `## 中文`，其他语言显示 `## English`；两节内容一一对应。
- 小节只用上面五个三级标题并按此顺序，没有内容的小节省略。新增站点写在“新功能”；“插件更新”只列已有插件的新版本及其变化，不与其他小节重复。条目以 `- ` 开头、一条一行；不用表格、链接、行内代码、代码块、粗体、分隔线或多级列表，应用按纯文本显示。
- 发布标题统一为 `HentaiPark vX.Y.Z`，不加副标题。
- 只写用户需要关心的内容：功能、体验、修复和需要用户操作的事项。不写实现细节、测试与验证数量、构建号、签名、内部重构、APK 架构选择（见 README 的“下载”）或泛泛的提醒（例如“部分站点可能需要 VPN”）。
- 修改格式时同步 `notesFor`、本节以及 `AGENTS.md` 的发布约束，并按新格式重写全部历史 Release 正文。

## 数据语义

- 目录音声的详情刷新保留历史中最近播放的同级曲目表、媒体类型和字幕关联；新的目录播放替换该快照，不从整个作品的章节缓存拼装播放列表。分页未完成时允许打开已加载曲目，播放快照标记目录不完整。
- 音声后台服务使用 Android MediaSession 和媒体通知，将播放／暂停命令按会话身份送回 Flutter；页面隐藏、应用锁和关闭会话均使控制失效。通知使用通用音声文案，不包含作品信息。Windows 游戏复用 WebView2 暂停／恢复能力，页面覆盖、后台和应用锁均参与可见性判断。

- 启动初始化失败时保留原有数据并显示重试和诊断信息入口；重试从失败步骤继续，已完成步骤不会重复注册监听。无法读取文件的访问错误不得当作格式损坏而覆盖原文件。
- JSON 保存失败保留最新内存值，显示持续提示并自动重试；显式刷新仍向调用方返回错误，成功落盘后提示消失。
- 删除下载前持久化待删除范围，文件与数据库均处理成功后才从列表移除；失败保留可重试任务，重启后继续未完成的删除。无法解析或身份不符的下载记录在下载页单独显示，保留原始记录与本地文件，禁止同一作品的新任务覆盖；可重试读取或确认仅移除记录。
- 小说正文方向由首个有方向的文字决定，与界面语言独立；显示、分页测量和滚动定位使用一致方向。

### 备份

- 恢复事务先写入文件与 Cookie，再提交数据库标记；重启遇到已提交日志只清理日志，不重放旧快照。前台与 Android 后台均在读取设置、书库或插件前恢复未提交事务。源注册表的 `removedOfficial` 随备份保存，合并恢复保留本机及备份的撤回记录。

- 备份包含书库、进度、标注、订阅目标、全局设置和站点配置；不含离线正文和媒体缓存。勾选“站点登录与确认状态”后，同一 `.parkbak` 文件还包含站点 Cookie、Token、插件私有数据和站点验证状态；默认不勾选，自动备份不包含这些凭据。文件未加密，应妥善保管。
- 恢复时，文件中的站点会话替换对应站点当前会话，与书库及配置一起提交，失败时回滚。Cookie 保留原路径、域、属性和有效期，不延长过期时间；导入前按已安装插件声明校验域名。未安装站点的会话随配置保留，安装后按实际插件声明恢复。过期、绑定设备、浏览器或 IP 的验证可能需要重新完成。
- 成年确认只保存在本机，不进入备份。
- 在线游戏浏览器配置、缓存和 IndexedDB 不进入 `.parkbak`。播放器提供单作品 localStorage JSON 导入导出；导入前原子保存当前 localStorage，失败不清理原配置，导出的文件不加密。
- 自动备份只在启动和回到前台时检查，不在应用关闭后定时运行。
- 桌面退出先暂停订阅、书库更新、备份和下载，等待已接受的备份快照、写盘及恢复任务完成，再释放页面、源运行时与数据库。暂停后迟到的文件选择结果不得创建新备份任务；可逆准备阶段失败后恢复服务，数据库关闭阶段失败只重试退出。
- 备份里有、本机没安装的第三方站点，其配置会保留到后续备份中，安装相同 key 的插件后应用。

### 迁移与缓存

- 章节迁移只复制无歧义的一对一进度；目录不完整时不能删减目标章节，有未匹配的原进度时保留原收藏。
- 发现页实时结果保留插件字段；应用私有的可重建磁盘缓存保存作品元数据、帖子文字、附件访问数据及支持的详情字段，并按站点、账号、配置和请求范围隔离。缓存可能含临时媒体地址，不能替代下载或备份，过期链接需刷新；不进入自动诊断或订阅记录。只有明确的网络或超时错误才降级显示过期缓存；过期列表仅供展示，重试从首页重建分页会话。

### 订阅

- 订阅目标、检查点、已见 ID、更新事件和通知队列保存在书库 SQLite 的独立表中。旧的 `subscriptions.json` 只导入一次并保留原文件；恢复备份时在同一事务中合并目标，保留现有名称与状态，新增目标建立新基线。
- 更新记录按 `(created_at DESC, event_key ASC)` 游标分页，不用固定上限截断可访问历史。帖子事件按目标 ID 顺序查找并打开实际帖子，成功取得目标后才标已读；找不到目标、请求失败或离开页面不消耗未读状态。
- 编辑订阅时，只改备注名称保留检查进度；改目标则保留开关与顺序，为新目标建立基线，旧请求的结果不再写入。重复目标拒绝保存。
- 自动检查默认每 6 小时，可选关闭或 1/3/6/12/24 小时，也在启动、回到前台和手动时检查。两个站点并发、同一站点串行，五分钟的数据库租约防止同一目标被重复检查；事件按站点、类型和稳定 ID 跨目标去重。首次只建立基线不推送；失败记录安全错误码并指数退避。
- Android 后台任务由 JobScheduler 启动独立的 Flutter 引擎和原有沙箱，只加载启用订阅关联的站点，不主动刷新全部账号；前台启动时先等后台任务取消并写完。系统可能推迟任务，不保证实时通知。
- 应用内记录不依赖通知权限。系统通知需要用户开启并授权，默认不显示标题；成功显示后才标记已投递，被拒或频道关闭时稍后重试，稳定的通知 ID 避免叠加。最多保留最近 500 条。移除目标会停止它的通知，历史事件保留。
- 订阅附件与图片共用媒体缓存上限，可在“我的 → 存储”中查看和清理；正在使用的附件受保护。缓存只保存可重建的媒体，不替代下载或备份。

## 跨平台构建与发布

平台功能与安装方法见 [PLATFORMS.md](PLATFORMS.md)。Android 与 Windows 由 check.yml、build.yml、release.yml 统一检查、构建、打包与发布。普通 PR 不传递发布凭据，发布使用受保护的 release 环境；手动 publish 默认 false。

### GitHub Actions

工作流使用标准 GitHub 托管运行器：Android 为 ubuntu-24.04，Windows 为 windows-2022。Flutter 版本与项目 SDK 对齐，依赖按锁文件解析并缓存。

- check.yml：main 推送、PR、手动触发；仅代码、资源、工具和平台文件变动触发，文档变更不触发。生产文案/样式/分析/格式、官方插件离线校验、动态写入被忽略本地目录的离线 HLS 用例；按变动范围决定平台矩阵。跨平台生产代码变动构建全部原生目标，单个平台宿主变动只构建对应平台；源脚本和翻译资源单独变动只做检查。
- build.yml：复用 Android 与 Windows 矩阵构建，配置 Android 签名或无签名编译、Windows NuGet 与安装器编译器。
- release.yml：推送与 pubspec.yaml 对应的 vX.Y.Z 标签，或在 main 手动触发。手动 publish 默认 false，仅构建；启用 publish 或标签触发才创建 Release。生产检查和全部构建成功后才发布。发布前必须更新 docs/RELEASE_NOTES.md，或手动提供仓库内其他双语说明路径。
- 临时产物位于 Actions 的 distribution-平台 artifacts，保留 7 天。正式附件放 GitHub Release，名称含版本、构建号、平台和架构，并附 SHA-256。Windows 提供完整目录 ZIP 和 Inno Setup 生成的 setup.exe，ZIP 内的主目录固定为 HentaiPark，不带版本号；Android 提供分架构签名 APK。
- 应用内安装仅接受对应版本的官方附件地址、平台文件名、有效文件大小和 GitHub 提供的 SHA-256 摘要。Windows 在用户确认后下载并校验安装包；打开安装器成功后复用桌面正常退出流程，不强制终止进程。更新向安装器传入当前程序目录；安装与卸载不清除独立的应用数据和下载目录。

版本标签必须与 pubspec.yaml 一致；没有更新版本时不要重用已有发布标签。Release 正文只含中文和 English 两节，遵守 DEVELOPMENT.md 既有格式。

### Secrets 与外部设置

为 release 环境配置保护规则、允许的发布分支/标签和必要审批；普通 PR 检查不传递发布 Secrets。构建 job 只有 contents:read，只有最终发布 job 有 contents:write；不可信 PR 不得配置为可进入 release 环境。

| Secrets | 用途 | 缺失时 |
| --- | --- | --- |
| ANDROID_KEYSTORE_BASE64、ANDROID_KEYSTORE_PASSWORD、ANDROID_KEY_ALIAS、ANDROID_KEY_PASSWORD | Android 正式签名 | 仅编译，不上传 APK |

Windows 商业签名尚未启用，不阻断普通 ZIP 构建。

仓库需允许 Actions、artifact 上传和 GITHUB_TOKEN 创建 Release；构建环境需能下载 Android 工具链、Windows WebView2/NuGet 和媒体依赖。依赖下载和构建失败会阻止正式发布。

## 播放缓存与反搜历史

播放会话使用最多 2 GiB 的临时磁盘缓存；HLS 缓存填满后循环保留最近分段。写入完成后发布缓存位置，磁盘写入失败不阻断播放。关闭会话清理缓存。

反搜历史单独保存在本机，最多 20 张已重编码图片，无痕不记录；不包含在当前备份范围。常见图片格式在后台 CPU 解码、裁剪及去元数据重编码，其他受系统支持的格式使用平台解码器。

### 排行榜详情与资料浏览

资料插件可复用站点浏览、搜索和动态筛选并保留排行榜，作品卡只进入资料页。排行榜原站详情使用原站 ID 与经校验的榜单上下文；跨站只通过标题或番号搜索，多个候选不自动猜选。详情默认源站优先，也可单选其他同域站点；不维护全域详情优先级。排行榜按域分别保存榜单分组、类型、所选榜单、动态筛选、详情站点和搜索站点。详情与搜索站点通过右上角配置页按全部可用榜单域分组的设置列表单选，榜单内容筛选独立展示。市场资料插件统一以 `catalog-*` 命名，覆盖排行榜、浏览、搜索与作品资料；旧 key 只进行一次性本地配置迁移，不保留运行时别名。搜索站点默认全部，可选域首选项或单站；域首选项取当前显示顺序中该域首个可搜索且显示的站点。资料入口列出各域市场榜单站点及独立资料站点；市场资料插件统一使用应用内列表、搜索、筛选与详情。无码厂商按站点保存作品身份，公开目录按原站分片完整检索并使用游标分页，内存缓存不写入账号配置；精确编号直接请求详情。加勒比搜索按原站 EUC-JP 编码。FC2 支持匿名搜索，不能以账号未登录或通用错误页推断搜索需要登录；仅在请求实际跳转登录入口时报告登录要求，其他错误保留真实状态。年龄问答规则由插件声明，框架仅在成年用户场景中整组精确匹配后提交；验证需使用无预置年龄 Cookie 的隔离设备会话，不能把 Node 返回 200 当作无感交互通过。

- 作品资料图片按原站角色传递：插件 `images` 可提供 `{url, thumbnail}` 配对，大图用于查看器、缩略图用于预览网格。模型对两者执行相同 URL 校验，按大图地址去重并保留缩略图关联。仅有单地址的图片仍可用字符串表达；插件使用图片对象时最低应用版本为 0.10.11，避免已发布应用将对象作为地址解析。
