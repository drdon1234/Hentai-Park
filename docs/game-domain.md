# 游戏资源管理

游戏源按 GalgameX → KUN Galgame → 次元茶馆排序，声明独立 `game` 类型与分类。发现、搜索、收藏、浏览历史复用通用入口；游戏不生成阅读章节或章节更新。GalgameX 与 KUN 默认开启 NSFW，分别使用游客 `content-filter` 接口与 `include_nsfw` 参数。

GalgameX 默认本周热门榜；资源更新列表使用当前前端动态发现的 Next Server Action，动作编号缓存 15 分钟，HTTP 失效后重新发现，不执行远端脚本。详情从 SSR Flight 数据解析，资源使用已验证公开接口。直链和网盘保留独立渠道，临时链接按点击重新获取，直链失败不自动打开网盘。KUN 默认七日浏览排行，采用公开原生 API，资源下载接口按点击调用，避免预取增加站点下载计数。多个网盘链接完整显示。

GalgameX 公开资源的主机和路径哈希作为稳定渠道编号。解析结果会补全存储目录或百度分享路径，因此在重新定位公开渠道后，按主机及文件名／分享编号匹配临时结果，拒绝不匹配或重复匹配；不依赖临时链接数组顺序。KUN 按接口总数遍历资源页，重复页或提前空页报错，不静默截断。

游戏文件由独立流式下载器保存到游戏下载目录，复用应用代理和 Wi-Fi 限制，HTTPS/TLS 及逐跳域名校验开启，不携带源 Cookie。任务只保存稳定编号、元数据、文件路径和密码；临时链接不持久化、不记录日志。取消清理部分文件，重试重新获取链接并从头开始；完成文件不覆盖。下载页面可导出或复制路径，移除任务保留下载文件。

直链下载不提供断点续传；没有包内校验和时只检查传输长度。原站“已测试/未测试/未知”和备注照原样显示，应用不安装或运行游戏包。

## 次元茶馆

次元茶馆使用浏览器模式和独立应用登录，默认 Galgame 资源区热门，支持最新、搜索与分页；列表从首楼附件补封面，封面短时缓存、请求间隔 400ms。资源列表只读，用户点击有明确文本提示的回复解锁按钮后才按完整表单发送“感谢分享，好人一生平安”。已经解锁不发帖，响应不明时保留账号/帖号状态并引导检查原帖，重启也不重复发送。

多网盘按实际渠道与完整链接展示，可逐链接提供不同提取码，保留解压密码。需要脚本动态验证、权限或原帖人工检查时返回源声明的确认页面。协议字段见 [源插件开发指南](SOURCE_API.md)。
