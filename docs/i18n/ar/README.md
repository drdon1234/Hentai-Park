## البدء

1. من «استكشاف»، اختر فئة وموقعاً أو ابحث بالعمل أو الوسم أو الرابط أو الرمز.
2. افتح العمل للقراءة أو المشاهدة. أضفه إلى «المفضلة» أو نزله للاستخدام دون اتصال.
3. تابع من الرئيسية ← متابعة ← الكل، وراجع الفصول الجديدة في المفضلة ← التحديثات.

عند الحاجة، اضبط تسجيل الدخول في المزيد ← المواقع والوكيل في المزيد ← الشبكة.

## القيود والأسئلة الشائعة

تتطلب الحانة خدمة ذكاء اصطناعي خاصة بك متوافقة مع OpenAI. تُرسل الرسائل وإعدادات الشخصية وشخصية المستخدم ومحتوى الكتب المطابق إلى الخدمة وقد تترتب رسوم. راجع [المواقع والخدمات](SITES.md) للقواعد المدعومة والاستيراد والتصدير. تشمل النسخ الاحتياطية غير المشفرة الموارد والمحادثات المحفوظة دون إعدادات الذكاء الاصطناعي ومفاتيحه.

تختلف إمكانات القراءة والتشغيل والتعليقات والاشتراكات والتنزيل حسب الموقع. راجع ما يعرضه التطبيق. قد تتطلب تحديثات المواقع ترقية التطبيق.

يرسل البحث بالصور الصور إلى الخدمة المختارة، وسجله المحلي غير مشفر. تظهر كلمات المرور وملفات Cookie أثناء تسجيل الدخول اليدوي؛ انتبه عند مشاركة الشاشة.

**الموقع أو المحتوى غير متاح؟**

تحقق من الاتصال ثم سجل الدخول أو أكد عمرك أو أكمل تحقق الموقع حسب التعليمات. قد تتطلب بعض المناطق VPN أو وكيلاً؛ يحدد الموقع الأصلي المحتوى والصلاحيات. تستخدم فحوص تاريخ الميلاد المدعومة التاريخ الثابت 1999-12-31 فقط بعد تأكيد البلوغ محلياً، ولا تقرأ تاريخ ميلادك الحقيقي.

**هل يمكن إرسال التعليقات والدردشة؟**

التعليقات والردود ودردشة البث للقراءة فقط. إذا تطلب مورد لعبة رداً لفتح الرابط، يُعرض النص أولاً ولا يُرسل إلا بعد تأكيدك.

**كيف أحفظ المفضلة والتقدم؟**

صدّر أو استعد .parkbak من المزيد ← النسخ الاحتياطي. تدمج الاستعادة البيانات ولا تشمل الملفات المنزلة. يمكنك اختيار تضمين حالة الدخول والتأكيد وملفات Cookie لاستخدامها على جهاز آخر. قد تتطلب الجلسات المنتهية أو المرتبطة بالجهاز تحققاً جديداً. النسخ غير مشفرة؛ احتفظ بها بأمان. لا تشمل .parkbak حفظ الألعاب عبر الإنترنت. يغطي الاستيراد والتصدير المنفصل داخل اللعبة localStorage فقط ولا يشمل IndexedDB؛ الملفات المصدرة غير مشفرة.

**كيف أبلغ عن مشكلة؟**

استخدم Issues مع إصدار التطبيق والموقع وخطوات التكرار. أخفِ الحسابات وCookie وToken والنسخ الاحتياطية والروابط الموقعة الكاملة.
