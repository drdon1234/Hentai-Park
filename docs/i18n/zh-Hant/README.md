## 下載

在 **[最新版本](https://github.com/drdon1234/Hentai-Park/releases/latest)** 下載對應平台的安裝包。Android 多數手機和平板選 `arm64-v8a`，模擬器一般選 `x86_64`。桌面包需完整解壓，安裝方法見 [平台說明](../../PLATFORMS.md)。

提供 Android、Windows、macOS 和 Linux 客戶端；iOS/iPadOS 目前僅提供模擬器包，Web 暫不支援。安裝方式與平台限制見 [平台說明](../../PLATFORMS.md)。

桌面支援 Ctrl+滾輪、Ctrl/Cmd 加減鍵縮放介面，Ctrl/Cmd+0 恢復預設，也可在外觀設定中調整。Windows 系統匣圖示可恢復視窗或結束；關閉視窗時可選擇收起到系統匣或結束應用程式。

## 三步上手

1. **發現**：開啟「發現」，選一個分類，或在搜尋框輸入關鍵字、貼上連結或番號。
2. **閱讀與播放**：開啟作品，點主按鈕開始；喜歡的加入「書架」。
3. **接著看**：「發現」頂部的「繼續看」和「歷史」會帶你回到上次的位置；追更的作品在「書架 → 更新」。

需要登入或代理的站點，在「我的 → 站點」和「我的 → 網路」中設定。

## 功能

| 功能 | 說明 |
| --- | --- |
| 排行榜 | 從「發現」開啟本子、里番、JAV 榜單，切換站點與週期，搜尋作品或開啟原站 |
| 發現與搜尋 | 首頁與分類頁共用推薦內容，支援分頁的站點可向右繼續瀏覽；多站同時搜尋，可用多種語言的關鍵字擴大範圍；貼上連結或番號直達作品 |
| 閱讀與觀看 | 漫畫捲動、翻頁或雙頁；影片選集、倍速與續播；小說排版、書籤、標註與朗讀。三種閱讀器使用同一套控制層 |
| 書架 | 收藏分類、更新提醒；訂閱作者、頻道或關鍵字的新內容 |
| 下載 | 獨立主導覽入口，管理漫畫、影片、小說與遊戲下載；匯入、匯出 CBZ；在作品選單按已完成章節匯出 PDF，動圖僅保留第一幀 |
| 遊戲資源 | 查看遊戲介紹、版本與下載連結 |
| 翻譯與過濾 | 翻譯標題、簡介與標籤；依標籤遮蔽內容 |
| 隱私與備份 | 應用鎖、無痕模式、封面模糊、防截圖；備份收藏、進度與設定 |

在「我的 → 網路 → 省流量模式」選擇：一般省流只在主頁和域頁顯示緊湊站點入口，進入站點後才載入作品；超級省流在站點頁也不自動載入，提交搜尋後才取得作品。不支援搜尋的站點會顯示說明。

小說閱讀頁「更多 → 全文翻譯」可翻譯完整正文，並隨閱讀繼續翻譯後續章節，支援切回原文。

瀏覽與詳情頁可先顯示本機快取；媒體連結過期時需要重新整理。返回首頁會保留捲動位置。長按作品卡片可封鎖作品或作者，在內容過濾設定中解除。排行榜保留篩選條件，每次進入取得最新榜單。短影片預設使用 RedGifs。

Reddit 和 X 的站點首頁、Reddit 社區及 X 社群支援開啟「短影片模式」，上下滑動播放目前範圍內貼文的影片。Reddit 支援自託管影片和 RedGifs 外連影片。同帖多個影片分別播放；X 社群可從站點頁的「社群」入口輸入連結或選擇已加入的社群，存取權限取決於原站。

短影片支援預載及保留最近看過的影片與緩衝，預設各 2 部；可在「我的 → 短影片」或播放頁「更多 → 短影片設定」分別調整，設為 0 可關閉。快取僅在目前播放頁有效，數量越多佔用的記憶體與流量越多。

應用程式內收藏只儲存在本機書庫；「原站互動」使用目前登入帳號，依站點能力提供按讚、收藏/書籤及評分。X 的書籤屬於原站收藏；Pixiv、X、嗶咔支援原站按讚和收藏，MissAV 支援收藏，EH 支援收藏和評分。可登入站點在工具列下顯示登入或帳號管理入口。Pixiv 匿名和登入狀態均預設進入推薦，支援連續載入、作者其他作品及相關推薦；Pixiv 與 EH 站內搜尋支援關鍵詞聯想。搜尋框可貼上作品或分享連結，辨識後直接開啟應用程式內作品。

GalgameX 支援原站收藏：新增收藏儲存至原站的第一個收藏夾，沒有收藏夾時請先在原站建立；取消收藏會從各收藏夾移除該作品。

JAV 作品可查看原站標註的字幕與版本差異，切換原站提供的版本，或按番號在站內、跨站查找；各版本的收藏、進度與下載獨立儲存。

淺色與深色主題，八種介面語言。每個站點可用的功能以應用內顯示為準。

小說列表統一顯示作品標題、作者、簡介、日期及分類標籤；原站未提供的資訊不顯示。

在「我的 → 站點」啟用、排序、更新或新增站點。

站點頁可使用原站支援的分類、標籤、分級和排序；搜尋頁提供對應篩選。大型目錄先選範圍或分組，再選分類；變更上級條件會清除下級選擇。分類讀取失敗可重試，需登入或人機驗證的站點仍受原站存取條件限制。

百度可能僅傳回相似圖片及出處連結。E-Hentai僅查詢公開表站畫廊，縮放或裁剪後可能無法匹配。

反搜服務按通用、本子、裏番、JAV 上下分組顯示，可跨分類多選。

在「發現」頂部開啟「圖片反搜」，預設只選 Google Lens，可複選服務一起搜尋。選擇圖片後可先裁剪，再開始搜尋；結果按站點切換查看，僅顯示有候選的站點。每站預設顯示前 20 筆，可查看全部結果。可造訪原站，或用作品名、番號繼續搜尋資源。圖片僅在點擊搜尋後上傳到所選服務。


Google Lens 會在背景自動上傳圖片並擷取出處；所有反搜服務在應用程式自建介面顯示進度與結果，網站驗證在背景嘗試完成，未完成時可在應用程式內重試。部分網路可能需要 VPN 或代理。

識別結果是候選，需要自行核對；相似度不是確認結論。trace.moe 免費額度有限，IQDB 尖峰時段可能排隊；AVScan 限個人非商業使用。各服務保留原始候選、可用分數和相關圖片；展開「原站資訊」可查看時間片段、識別區域、標籤及其他原始欄位。不保證所有作品均被收錄；角色識別不直接提供遊戲下載。

## 常見問題

**站點打不開，或圖片、影片載入失敗？**
先檢查網路。部分站點在中國大陸可能需要 VPN 或代理，可在「我的 → 網路」設定代理。網站驗證會在背景自動嘗試；尚未完成時可在應用程式內重試。

首次使用需確認成年並閱讀免責聲明，確認儲存在本機。支援的網站年齡確認與 Cloudflare 驗證由應用程式背景處理，僅登入需操作原站頁面。Windows 支援標準 Cloudflare 核取方塊的背景模擬點擊；其他平台嘗試自動驗證，無法完成時在應用程式內提示重試。

JM 和嗶咔支援自動探測可用線路。只有確認出口 IP 與上次相同時才重用線路；出口變化或無法確認時重新探測。探測不使用第三方公共 IP 查詢服務，仍可手動選擇分流。

**需要站點帳號嗎？**
大多數不需要。需要登入的站點會在站點頁頂部提示，也可在「我的 → 站點」開啟該站點的設定登入。Pixiv、X、StoriesOnline 的網頁登入支援 Google、Apple 等第三方帳號授權，是否放行內嵌瀏覽器由第三方平台決定。

**會替我在站點上發文或回覆嗎？**
不會自動這樣做。次元茶館的部分資源需要回覆才能解鎖，應用會先顯示將要發送的內容，經你確認後才發送。

**換手機怎樣保留收藏和進度？**
在「我的 → 備份」匯出備份，在新裝置上恢復。離線下載不在備份中，站點帳號可能需要重新登入。

**翻譯會上傳什麼？**
翻譯標題、簡介、標籤、搜尋詞、選取文字或小說全文時，相應內容會傳送給 Google 翻譯；不會傳送帳號、Cookie 或閱讀紀錄。目標語言跟隨應用程式語言。

**怎樣回報問題？**
在 [Issues](https://github.com/drdon1234/Hentai-Park/issues) 寫明應用版本、站點名稱和重現步驟；截圖前請隱藏帳號和私人內容。

請勿在公開回報中附上帳號密碼、Cookie、Token、工作階段匯出、應用程式備份、封包擷取檔或含簽名參數的完整連結；日誌只使用應用程式匯出的去識別報告。
