## 기능

- **집계 검색**: 모든 소스 사이트를 한 번에 검색합니다. 링크를 붙여넣거나 작품 ID(예: `JM350234`)를 입력하여 작품을 직접 엽니다.
- **다국어 검색**: 키워드를 중국어/일본어/한국어/영어 등 기타 언어로 자동 번역하여 동시 검색
- **책장 및 업데이트**: 다중 카테고리 수집, 연속 업데이트 자동 확인 및 푸시 알림 전송, 새 챕터 자동 다운로드 가능
- **리더**: 세로 스크롤, 왼쪽 또는 오른쪽 방향으로 페이지 넘기기, 두 페이지 표시, 흰색 여백 자르기, 눈 보호 필터, 볼륨 키로 페이지 넘기기
- **비디오 재생**: 화질·재생 속도 선택 및 재생 위치 저장. 화면 왼쪽을 위아래로 밀어 밝기를, 오른쪽을 밀어 볼륨을 조절하고 가로로 드래그하여 재생 위치를 변경합니다. 가로·세로 전체 화면과 상하 반전을 지원합니다.
- **다운로드**: 챕터별 만화 다운로드, 화질별 영상 다운로드, CBZ 가져오기 및 내보내기
- **소스 변경 마이그레이션**: 컬렉션을 다른 소스로 마이그레이션하고 읽기 진행 상황을 유지합니다.
- **차단 태그**: 차단을 사용자 정의하고 필요에 따라 활성화할 수 있는 사전 설정 그룹화 제공
- **개인정보 보호**: 앱 잠금, 시크릿 모드, 커버 블러, 스크린샷 방지
- **백업 및 복구**: 원클릭 라이브러리 백업, 진행 상황 및 설정, 예약된 자동 백업 지원
- **8개 언어 인터페이스**: 중국어 간체, 중국어 번체, 일본어, 한국어, 영어, 스페인어, 러시아어, 아랍어; 시스템 따르기와 즉각적인 전환을 지원하며 아랍어는 오른쪽에서 왼쪽 레이아웃을 채택합니다.

## 다운로드

최신 버전을 다운로드하려면 [Releases](https://github.com/drdon1234/Hentai-Park/releases/latest)로 이동하세요. 무엇을 선택해야 할지 확실하지 않은 경우 대부분의 휴대폰에 대해 버전 `arm64-v8a`를 선택하세요.

## 시작하기

1. "탐색"에서 원본사이트를 선택하거나, 검색창을 이용하여 작품을 검색한 후 해당 작품의 링크를 붙여넣고 작품 ID를 입력합니다. 다국어 검색은 원래 키워드와 감지된 소스 언어를 유지하면서 번역된 키워드를 표시합니다.
2. "더 보기 → 언어 → 앱 언어"에서 언어를 선택하세요. 기본적으로 시스템을 따르십시오. 수정 사항은 작품의 원래 제목, 태그 또는 저장된 사용자 데이터에 영향을 주지 않고 즉시 적용되며 로컬에 저장됩니다.
3. "더 보기 → 소스 관리"에서 원본 사이트를 활성화, 정렬 및 구성합니다. PicACG 계정이 구성되지 않은 경우 "탐색"에 프롬프트가 표시되고 자체 구성을 입력하거나 전용 자동 유지 관리 계정을 활성화할 수 있습니다.
4. PicACG "전용 자동 유지 관리 계정 사용"을 활성화하면 등록 확인 팝업이 뜹니다. 확인 후 전용 계정을 생성하고 즉시 로그인하세요. 이후의 로그인 상태는 애플리케이션에 의해 유지됩니다. 스위치를 끄면 전용 계정이 유지됩니다. 다시 켜면 다시 사용할 수 있으며 기존 수동 계정을 덮어쓰지 않습니다. 등록에 실패하면 동일한 계정으로 다시 시도할 수 있습니다.
5. 만화 세부정보 페이지에서 카테고리를 수집, 선택하고 챕터를 다운로드할 수 있습니다. "책장"은 컬렉션을 정리하고, "업데이트"는 새로운 장을 확인하며, "기록"은 복원 진행 상황을 계속해서 읽습니다. "더 보기 → 백업 및 복구"은 복원 중에 데이터를 내보내고 현재 데이터와 병합할 수 있습니다.

영상 페이지 왼쪽을 위아래로 밀어 밝기를 조절하고, 오른쪽을 위아래로 밀어 볼륨을 조절하고, 가로로 밀어 진행 상황을 미리 보고, 손을 뗀 후 점프하세요. 재생 컨트롤은 수평 및 수직 화면 확장을 제공하며, 화면을 회전하면 표시 방향에 따라 작업 영역이 조정됩니다. 리더는 위아래로 스크롤하고 페이지를 왼쪽에서 오른쪽으로 또는 오른쪽에서 왼쪽으로 넘기는 것을 지원하며 읽기 방향은 리더 설정에 따라 결정됩니다.

## FAQ

**PicACG / ExHentai는 사용할 수 없나요?**
PicACG는 계정을 직접 구성하거나 전용 자동 유지 관리 계정 등록을 확인해야 합니다. ExHentai는 웹 로그인이 필요하며, 계정 자체에 사이트 권한이 있어야 합니다.

**이미지가 느리게 로드되거나 실패합니까?**
설정에서 HTTP 프록시를 구성할 수 있습니다. JMComic / PicACG는 이미지 전환을 시도할 수 있습니다.

**Hanime1 계속 원을 그리며 돌고 있나요?**
프롬프트에 따라 내장 브라우저에서 Cloudflare 확인을 완료하세요.
