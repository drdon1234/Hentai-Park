내 정보 → 네트워크 및 저장소 → 데이터 절약 모드에서 선택합니다. 일반 절약은 홈과 카테고리에 간결한 사이트 목록을 표시하고 사이트를 열면 작품을 불러옵니다. 최대 절약은 사이트에서도 자동으로 불러오지 않고 검색 후에만 작품을 가져옵니다. 검색을 지원하지 않는 사이트에는 안내가 표시됩니다.

## 다운로드

**[최신 릴리스](https://github.com/drdon1234/Hentai-Park/releases/latest)**에서 Android APK를 받으세요. 대부분의 휴대폰과 태블릿은 `arm64-v8a`, 에뮬레이터는 보통 `x86_64`입니다.

Android, Windows, macOS, Linux 클라이언트를 제공합니다. iOS/iPadOS는 현재 시뮬레이터용만 제공하며 Web은 지원하지 않습니다. [설치 방법과 제한](../../PLATFORMS.md)을 확인하세요.

데스크톱에서는 Ctrl+마우스 휠 또는 Ctrl/Cmd 더하기·빼기 키로 화면 배율을 조절하고 Ctrl/Cmd+0으로 초기화할 수 있습니다. 모양 설정에서도 조절할 수 있습니다. Windows 트레이 아이콘으로 창을 복원하거나 앱을 종료할 수 있습니다. 창을 닫을 때 트레이로 숨기거나 종료하도록 선택할 수 있습니다.

## 세 단계로 시작하기

1. **탐색**: '탐색'을 열고 분류를 고르거나, 검색창에 키워드·링크·품번을 입력합니다.
2. **읽기와 보기**: 작품을 열고 주 버튼을 누릅니다. 마음에 드는 작품은 '라이브러리'에 추가하세요.
3. **이어 보기**: '탐색' 상단의 '이어 보기'와 '기록'이 지난번 위치로 데려다 줍니다. 따라가는 작품의 새 회차는 '라이브러리 → 업데이트'에 있습니다.

로그인이나 프록시가 필요한 사이트는 '더 보기 → 사이트'와 '더 보기 → 네트워크'에서 설정합니다.

소설 읽기 화면의 더 보기 → 전문 번역에서 본문 전체를 번역하고 다음 장을 열면 번역을 이어갑니다. 원문으로 전환할 수 있습니다.

탐색 및 상세 화면은 장과 미디어 주소가 포함된 캐시를 바로 열 수 있으며 최신 작품을 불러오는 상태를 안내합니다. 갱신에 실패해도 접근 가능한 캐시는 유지됩니다. 홈으로 돌아오면 스크롤 위치가 복원됩니다. 카드를 길게 눌러 작품이나 작가를 차단하고 필터 설정에서 해제할 수 있습니다. 순위 필터는 저장되며 방문할 때마다 최신 결과를 가져옵니다. 기본 숏폼 사이트는 Pornhub Shorties입니다.

지원 사이트에서는 상세 화면의 더 보기 또는 카드 길게 누르기 메뉴에서 앱 내 계정으로 원본 사이트에 취향을 저장합니다. MissAV는 즐겨찾기, EH는 평점을 지원하며 로컬 즐겨찾기와 구분됩니다. Pixiv는 로그아웃 시 순위, 로그인 시 추천을 기본으로 엽니다. 추천에는 로그인이 필요합니다. Pixiv와 EH의 사이트 내 검색은 키워드 자동 완성을 지원합니다.

JAV 작품에서 원본 사이트가 제공하는 자막과 버전 정보를 확인하고 다른 버전으로 이동하거나 품번으로 사이트 내·통합 검색을 할 수 있습니다. 즐겨찾기, 재생 위치와 다운로드는 버전별로 저장됩니다.

라이트·다크 테마와 8개 언어를 지원합니다. 사이트마다 쓸 수 있는 기능은 앱에 표시된 대로입니다.

## 이미지 역검색

| 용도 | 서비스 |
| --- | --- |
| 종합 이미지 출처 (완전 일치) | Google Lens |
| 애니메이션 작품·회차·시간 | trace.moe |
| 애니메이션 및 Galgame 캐릭터·작품 | AnimeTrace |
| 일러스트 출처 | IQDB |
| JAV 장면으로 품번 검색 | AVScan |

서비스를 일반, 성인 애니, JAV, 이미지 분류로 세로 배치하며, 분류에 걸쳐 여러 서비스를 선택할 수 있습니다.

발견 상단에서 이미지 역검색을 열면 기본으로 Google Lens만 선택됩니다. 여러 서비스를 선택해 함께 검색할 수 있습니다. 이미지를 선택하고 필요하면 자른 후 검색하세요. 후보가 있는 사이트만 표시되며 사이트를 전환해 각 결과를 볼 수 있습니다. 원본 사이트를 열거나 작품명·품번으로 리소스를 검색할 수 있습니다. 검색 버튼을 누를 때만 선택한 서비스에 이미지가 업로드됩니다.

Google Lens는 백그라운드에서 이미지를 업로드하고 출처를 가져옵니다. 모든 이미지 역검색은 앱 자체 화면에 진행 상황과 결과를 표시하며, 수동 인증이 필요한 경우에만 인증 영역을 표시합니다. 일부 네트워크에서는 VPN 또는 프록시가 필요할 수 있습니다.

결과는 확인이 필요한 후보이며 유사도가 확정을 뜻하지 않습니다. trace.moe는 무료 할당량이 제한되고 IQDB는 혼잡 시 대기할 수 있습니다. AVScan은 개인 비상업 용도에 한합니다. 각 서비스의 후보, 제공된 점수 및 관련 이미지를 유지합니다. 원본 사이트 정보를 펼치면 시간대, 인식 영역, 태그 등 원본 필드를 볼 수 있습니다. 모든 작품의 수록을 보장하지 않으며 캐릭터 인식이 게임 다운로드를 제공하지는 않습니다.

순위에서 필터와 제목 번역을 사용할 수 있습니다. 표지는 원래 비율을 유지하며 긴 제목은 클릭하여 펼칠 수 있습니다.

## 자주 묻는 질문

**사이트가 열리지 않거나 이미지·동영상을 불러오지 못해요.**
먼저 네트워크를 확인하세요. 중국 본토에서는 VPN이나 프록시가 필요한 사이트가 있으며, 프록시는 '더 보기 → 네트워크'에서 설정합니다. 웹 인증이 나오면 내장 브라우저에서 한 번만 통과하면 됩니다.

**사이트 계정이 필요한가요?**
대부분 필요 없습니다. 로그인이 필요한 사이트는 사이트 페이지 상단에 안내가 나오며, '더 보기 → 사이트'의 사이트 설정에서 로그인할 수 있습니다. Pixiv, X, StoriesOnline의 웹 로그인은 Google, Apple 등 외부 계정을 지원하지만, 내장 브라우저 허용 여부는 각 서비스가 결정합니다.

**앱이 대신 글이나 댓글을 올리나요?**
자동으로는 하지 않습니다. 차원 찻집의 일부 자료는 댓글을 달아야 열리는데, 앱이 보낼 내용을 먼저 보여 주고 확인한 뒤에만 보냅니다.

**휴대폰을 바꿔도 즐겨찾기와 진행 상황을 유지하려면?**
'더 보기 → 백업'에서 내보낸 뒤 새 기기에서 복원하세요. 다운로드는 포함되지 않으며 일부 사이트는 다시 로그인해야 할 수 있습니다.

**번역할 때 무엇이 전송되나요?**
제목, 소개, 태그, 검색어, 선택한 텍스트 또는 소설 전문을 번역하면 해당 내용이 Google 번역으로 전송됩니다. 계정, 쿠키 및 읽기 기록은 전송되지 않습니다. 대상 언어는 앱 언어를 따릅니다.

**문제를 신고하려면?**
[Issues](https://github.com/drdon1234/Hentai-Park/issues)에 앱 버전, 사이트 이름, 재현 방법을 적어 주세요. 스크린샷에서는 계정과 개인적인 내용을 가려 주세요.
