# Журналы и сообщения об ошибках

Обычные журналы содержат ошибки, автоматические повторы, результаты вызовов сайтов и изменения состояния приложения. Обновите или экспортируйте журнал в настройках и приложите шаги воспроизведения к Issue.

Для сложных проблем включите debug только на текущий сеанс либо только на следующий запуск, чтобы записать весь процесс запуска. При активации запланированного режима появится уведомление. Debug отключается при выходе; расписание действует один раз.

Долговременный журнал по умолчанию отключён: каждый запуск перезаписывает последние записи. При включении записи добавляются между запусками, а самые старые удаляются лишь при достижении 100 MiB. Отключение немедленно перезаписывает историю выполнения. Отдельная история сбоев не меняется.

Debug дополнительно записывает время запросов, повторы, кеш и состояние воспроизведения, но не аккаунты, Cookie, Token, содержимое, локальные пути или полные подписанные ссылки. Страница показывает последние записи, экспорт — все сохранённые. Режим обезличивания также скрывает хосты и подробную версию ОС. Проверьте файлы перед отправкой.
